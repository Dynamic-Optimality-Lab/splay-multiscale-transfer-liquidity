# LIQ0-02 EVENT_MULTIPLICITY - Layer A

Present-key: induction over the bottom-up splay loop. Each loop iteration emits exactly one StepEv whose class carries mu 1 (terminal ZIG) or 2 (LL/RR/LR/RL double). The loop runs while the access node has a parent; a double step consumes two depth levels with mu 2, a terminal ZIG one level with mu 1. Summation gives depth. Absent-key: the descend finds no node, the trace branch returns [], cost is depth-to-leaf + 1, and replay performs zero T7/T5 invocations (zero opportunities). Only the ROT subfamily depends on this identity; FLAT profiles use only boundedness, so a falsification would retire ROT profiles alone (profile-specific gate).

Downstream consumer: WP-4(ROT). Finite differential evidence is Layer-C support, never a premise.
