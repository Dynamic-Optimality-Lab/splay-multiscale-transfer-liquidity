# G02_SOURCE_LIFTABILITY_THEOREM.md — Gate F liftability discipline

TYPE A (source-liftable): closed walks found by source-level replay search are
lifted BY CONSTRUCTION (concrete paired-closed word + replayed semantics +
verified macro weights). All Step-02 cycle evidence is TYPE A by method.
TYPE B (provably abstract-only): requires a proof of non-liftability (none
claimed here). TYPE C (invalid abstract witness): any candidate failing
independent re-verification (none found). TYPE D (unknown liftability): applies
to Z3-only abstract cycles (none produced) and to bounded-search incompleteness
(BFS truncations recorded as UNKNOWN, never promoted). No TYPE A claim is made
for any cycle not replayed end-to-end from a concrete paired-closed original.
