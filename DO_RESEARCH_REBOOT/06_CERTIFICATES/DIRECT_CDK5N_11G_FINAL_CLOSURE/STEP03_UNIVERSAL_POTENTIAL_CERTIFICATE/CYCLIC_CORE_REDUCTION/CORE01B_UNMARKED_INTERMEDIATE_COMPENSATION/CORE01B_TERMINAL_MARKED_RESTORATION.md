# CORE-01B Terminal Marked Restoration (Gate C5/E)

The terminal genuine marked KEEP's splay is nonincreasing on the closure
(eventwise lemma; target marked). It REMOVES members (nodes losing all
marked descendants, e.g. bypassed ancestors) but the removal set is
determined by the concrete ancestor geometry, not by any conservation
law: nothing forces it to remove exactly the intermediate gains. The
"terminal splay cleans everything" hope is FALSE in general (a surviving
unmarked ancestor of a marked key in a side branch untouched by the
terminal path stays). Therefore strong inclusion (G empty) is NOT
derivable from the terminal event alone; it requires the missing
removal guarantee, which the frozen conjuncts do not provide.
