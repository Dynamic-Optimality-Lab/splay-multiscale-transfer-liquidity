# CL-01 Guard-Crossing Count Theorem (PROVED)

For any closed walk C = s0->...->sn=s0, telescoping gives
sum_i [g(s_{i+1})-g(s_i)] = 0, where each difference is in {-1,0,+1}.
Upward crossings (+1, 0->1) and downward crossings (-1, 1->0) therefore
satisfy N_01(C) = N_10(C) exactly (zeros contribute nothing). Holds for:
repeated vertices, parallel edges, zero-weight edges, contracted-high
edges, any length >= 1, disconnected graphs (per-component walks),
no liftability assumption, no weight hypothesis. Pure combinatorics of
vertex-defined binary guards; independent of the potential refutation.
