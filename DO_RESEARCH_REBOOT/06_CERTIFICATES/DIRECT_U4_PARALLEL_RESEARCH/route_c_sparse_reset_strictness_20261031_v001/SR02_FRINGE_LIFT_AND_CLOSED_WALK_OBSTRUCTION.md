# Source-exact lift of the architecture exclusion

Status: PROVED on the stated fringe/periodic family, using the finite-exact 121-case source certificates from SR01 and direct source substitution. This is not a finite fit or a general no-go theorem for FI-only cycles.

## Arbitrary unrequested fringe

Replace the leaf at key 13's right child in diagonal R13 by an arbitrary BST F whose keys are all greater than 13. Retain the same setup D13,D12 and any of the 121 mixed generators from SR00. Every requested key is <=13. No search enters F; source rotations carry it as an unchanged off-path fringe. Substituting F at that leaf therefore commutes with every source request, including the reachability prefix, transient and recurrent cycle.

All A/B depths and grouped event identities on requested keys are unchanged. Actual reset costs, q_i, delta_i, E and C_D are identical. Source keys in F never create an A event or a B demand. Tree equality and inequality of core states are preserved: substitution is injective, since collapsing the distinguished larger-key fringe recovers the core tree. Consequently first paired recurrence, its primitive period and every diagonal/non-diagonal indicator stay unchanged.

The old UD ceiling for a requested payer key y also stays unchanged. Its post-anchor depth h_i(y) and number k_i(j) of genuine intervening B changes are the same; KEEP-less ceilings remain zero. Thus the same old accepting cut and exact source-unit map apply after substitution. The all-size FI theorem remains valid too, but its acceptance is not needed to reject strictness once old UD has an accepting cut.

This proves: for every one of the 121 fixed reset placements and every such F, the corresponding recurrent source cycle is already UD-covered and cannot be a strict FI\UD witness. Reflection gives the analogous left-fringe family; order-preserving relabeling can put any finite ordered key set into rank labels. No larger finite key size was evaluated.

## Rotations and powers do not create a hidden strict witness

Every cycle certificate names an old-UD successful physical block cut. Rotating the input merely permutes that set of cuts, so its closed-walk membership is unchanged.

For a positive integer k, concatenate k copies of a certified primitive cycle, with each physical occurrence and unit independently indexed. Use the same successful phase as the cut. In the first period run the old certificate. In every subsequent period, its within-period positive source facts are identical to those of the isolated old run, while retained earlier-period facts can only reduce the minimum own-work ceiling. Thus certified spare pools do not shrink. At a position before that period's first positive, the isolated run has no debt; its additional old history cannot harm completion. The total-debt induction clears each period by its endpoint. No unit is borrowed from a preceding or future period; distinct occurrence identities keep budgets separate. Hence all positive powers remain old-UD-covered.

For the recurrent mixed word, a source state determines its phase. After each KEEP both roots equal that unique skeleton key, and the thirteen KEEP targets are distinct within a period. After the DELETE roots differ, so its state cannot be mistaken for a KEEP phase. The primitive-cycle source states are independently distinct. Therefore any actual closed subwalk of the recurrent source trajectory is a rotation of a power of that certified primitive cycle. It is old-UD-covered by the argument above.

An actual repeated state along the transient would force the same periodic future because phase and source inputs are then identical. It therefore joins the same recurrence; it does not supply a second unrelated closed cycle. The stored first boundary return and distinct recurrent source states make the recurrent classification exact for the declared reachable trajectories. This statement concerns the continuation after the fixed setup prefix, not arbitrary cycles formed by adding new DELETEs or changing the seed.

## Meaning of the exclusion

One-reset periodic injection successfully creates nowhere-diagonal cycles in 31 source cases, so the earlier KEEP-only synchronization obstruction has been escaped in that sense. Every resulting cycle nevertheless has enough certified KEEP-less capacity to cover its positive excess. Retiming, rotating or repeating these same recurrent cycles cannot turn them into a strict FI-only example.

The result excludes a finite reset architecture and its arbitrary-fringe/power closure. It does not prove that all sparse-reset skeletons have E<=C_D, that all non-diagonal cycles are UD-covered, or that FI and UD have the same full closed-walk class. Those broader statements remain unproved. Universal Step 3/CD stays OPEN, with matching-terminal work frozen and Stage 11G unchanged.
