# Reproducing the B normalization audit

The [producer](audit_b_normalization.py) inherits eight local PE matching certificates, constructs the two fixed helper P graphs and one source maximum witness with reflections, and attaches hand matching/cover certificates. It compares both immutable source engines on all six controls and the twelve-step closed replay. The connector is the already certified helper word with its KEEP2 split into DELETE2,KEEP2; no new search is run.

The [independent verifier](independent_verify.py) imports neither producer nor tuple source nor a matching algorithm. It regenerates every interval, eligibility decision and endpoint edge, checks all matching/cover equalities, verifies the depth-five maximizing auxiliary witness and the destination's two extreme leaves, and recomputes the exact-source/lower-destination separation. It checks the scalar-normalization arithmetic and actual physical paired closure. The global all-auxiliary upper bound is a written structural argument in BN02, not finite exhaustion or a formal-kernel compilation.

Scripts write outputs exclusively with mode x and intentionally refuse to overwrite a completed run. To reproduce, copy them and BN00 into a fresh sibling versioned directory under DIRECT_U4_PARALLEL_RESEARCH, preserving relative directory depth and existing prior inputs. From the repository root run Python -X utf8 -B with the new audit_b_normalization.py path, then the new independent_verify.py path. Preserve all existing runs. No installation is needed.

For read-only delivery verification, recompute hashes in delivery_manifest.json and source hashes in entry_source_pins.json, and compare the certificate hash with independent_audit.json. The manifest excludes itself. final_integrity.json records the gate hash, Stage 11G inventory/bytes, inherited source pins, clean tracked state and scope. No exact helper-destination J, M or Phi value is claimed, and no potential labels are assigned on other replay states.
