first block after the inherited deep episode to be a donor.

**OPEN:** eventual repayment using original reachable paired

## One fixed source substitution

Use the old16-core source pair and word P from TR. In its
gap strictly between core keys1 and2, insert six ordered keys
y1<...<y6. In A the body is a right vine rooted at y1; in B
it is a left vine rooted at y6. Their complete key sets agree.
All other gaps may be empty. Neither tree accesses these six
keys during P, so the whole body shapes remain unchanged.

After P the body attachment depth is3 in EACH original source.
Now access y1. Its local A depth is0 and local B depth is5.
Thus its complete source depths are

    d_A=3+0=3,       d_B=3+5=8,
    a=2,            q=4,            delta=0.

This is the fixed gap/body/query prediction in DC00A, written
before execution. No alternative gap, size or target was tried.
The literal order encoding is core k->7k, and y_i->7+i. There
are16 old core nodes and6 explicit fringe nodes,22 nodes total.
This is one exact formal substitution, not a larger finite fit,
source-size sweep, new core candidate or graph search.

The complete six-block prefix costs are

    (1,3),(1,2),(1,2),(1,2),(1,2),(2,4).

It creates seven A StepEvs, fourteen actual A units and fifteen
B double demands. Only the first block is positive; all others
are exactly saturated. The original16-core deficit has not been
paid. In the integer order encoding the last physical events are

    A: LL(8,56), ZIG_R(7,8),
    B: LL(8,10), LL(8,12), LL(8,14), RL(7,35).

These are source event intervals, not an extra comparison path.
The source certificate includes complete entering/destination
trees and event IDs. Both original engines independently agree.
Reflection k->119-k verifies the other orientation. Physical

## What is and is not established

The prefix is source-valid on equal complete key sets. It
realizes the exact escape equation with alpha=beta=3,
u_A=0,u_B=5,z_B=0. Hence identical gap key SETS cannot
replace the paired depth/shape condition of DC01.

Its complete paired endpoint differs from its input. Diagonal
reachability and a closed extension with exactly one positive
and otherwise only saturated blocks are NOT ESTABLISHED.
No connector or closing-word search was performed. Fourteen
units versus fifteen demands on an open prefix is not a
Coarse-Double counterexample.

This result stops only the immediate-discharge extension to
arbitrary unequal interiors. It does not show that a later
physical donor can be avoided on an actual reachable closed
walk, and it does not upgrade the old template into one.
