# Reproducing the terminal antichain evaluation

The [producer](audit_antichain_terminal.py) evaluates one fixed formula on six frozen controls, their reflections and the existing CP closed word. For each completed pair of at most seven keys, it enumerates the maximal antichains of residual B intervals and issues an exact ordinary matching plus equal-size vertex cover for each. Maximizing those certified ranks evaluates alpha exactly. This is optimization inside a defined current-state function, not fitting state potential labels or solving source inequality feasibility.

The [independent verifier](independent_verify.py) imports neither producer nor tuple source nor a matching algorithm. It regenerates all terminal sets and endpoint edges, independently enumerates every maximal residual B antichain, checks completeness and every matching/cover equality, and verifies the global alpha objective. It also regenerates raw P certificates, pointer-source operations and all completion values, full B identities, costs, reflections, shared states and actual paired closure. The all-size proofs in AT01-AT02 are written arguments; no formal-kernel proof compilation is claimed.

Scripts write exclusively with mode x and intentionally refuse to overwrite a completed run. To reproduce, copy them and AT00 into a fresh sibling versioned directory under DIRECT_U4_PARALLEL_RESEARCH, preserving directory depth and existing prior inputs. Run Python -X utf8 -B with the new audit_antichain_terminal.py path, then the new independent_verify.py path. Preserve all completed runs. No installation is needed.

Read-only delivery verification recomputes the hashes in delivery_manifest.json and entry_source_pins.json and compares the certificate hash with independent_audit.json. The manifest excludes itself. final_integrity.json records gate/source preservation, Stage11G inventory and bytes, tracked state, scope and report links. PASS refers to exact audit correctness. The mathematical candidate's disposition is OPEN because its universal DELETE proof is absent; finite survival is not that proof.
