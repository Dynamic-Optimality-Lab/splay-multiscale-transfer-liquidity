# What an actual first loss of core agreement forces

Status: PROVED-DERIVATION / AUDIT-PENDING. This is a source restriction,
not a universal ownership-compatible donor theorem.

Call a genuine boundary core-synchronous when the actual rooted labeled
ancestor cores C_M(A) and C_M(B_F) are identical. Their proper off-core
private BSTs need not have identical shapes. All marked access paths
then have identical physical labels/depths in the two trees.

## Rotation-distance lemma

For any fixed actual target x, one BST rotation changes its depth by at
most one: the two operands and the outer attached subtrees move by one
level and the middle attached subtree stays at its level. Hence an A
StepEv, containing one or two ordinary rotations, reduces x's depth
by at most two. Over ANY original macro ending at x, every original
access is retained and the final depth of x is zero. Therefore

    H >= ceil(initial_depth_A(x)/2).             (O1)

The argument does not assume x is each intermediate access target.
Private ancestors, arbitrary helpers and all event orientations obey
the same depth-change bound.

At a core-synchronous source boundary in the actual closed maximal B
domain, initial_depth_A(x)=initial_depth_B(x)=2Q. Thus H>=Q.
As beta+z<=Q+1, the actual leaf-comparison tail has at least

    2H-min(2H,beta+z) >= H-1.                   (O2)

In particular no such macro creates a leaf-comparison hole. These
inequalities use actual physical H, never a clipped selector or qE.

## First divergence lemma

Start at an actual core-synchronous boundary and consider the first
later genuine boundary where core agreement fails. Its macro has H>=2.
Indeed, if H=1, the single positive A access is the final marked x
(possibly its earlier DELETE preview); all other accesses are zero-root
identities. The A endpoint is exactly splay_x(A_start). The B endpoint
is splay_x(B_start). Since the starting marked cores agree, both marked
paths and original frame formulas agree, and arbitrary off-core hangers
remain off those paths. The resulting marked cores still agree, a
contradiction. The same conclusion holds if the macro has only one
positive access of any event count and its target is x.

Consequently the first divergent macro contains a genuinely additional
positive A access, has H>=2 and, by O2, at least ONE actual bit outside
the leaf-comparison image. Its physical location is the appropriate
tail ordinal in that macro; this is not an invented debt credit.

This covers any actual source segment starting at core agreement,
with arbitrary private populations and both orientations. If a later
H1/Q2 zero hole is reached, either core disagreement already existed
at the chosen segment's start or such a first divergence has occurred.
Core agreement itself cannot support that H1/Q2 contrast, since O1
would give H>=2.

## Why this does not close the multicomponent gap

One forced tail bit does not prove enough DISTINCT eligible bits for
every later blocked component. Its effective owner may lie elsewhere
and the permitted continuation may reach another undefined comparison.
No source correspondence matching all later holes to divergence-tail
ordinals has been proved. A single first-divergence count cannot pay
arbitrarily many later holes by assertion.

Moreover the ORIGINAL paired-closed period need not have an assumed
core-synchronous boundary. Diagonal reachability concerns the original
reaching history; its last agreement or divergence can lie in the
transient prefix outside the certified physical interval. Importing
that earlier event would violate the period contract. No theorem here
forces a new agreement boundary inside every original closed period.

Thus the source attempt identifies two unresolved alternatives: charge
repeated holes against actual in-period divergence events with joint
ownership control, or prove escape from persistent core disagreement
without an in-period fresh origin. It does not manufacture a new
equivalent cover premise and count it as the missing universal proof.
