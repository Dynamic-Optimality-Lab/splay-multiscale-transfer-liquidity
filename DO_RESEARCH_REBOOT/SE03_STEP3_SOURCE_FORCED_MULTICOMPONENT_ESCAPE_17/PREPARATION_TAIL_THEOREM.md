## 1. Physical tail lemma

In any actual closed maximal-core source, let p be a genuine natural
macro with Q_p=1. The unique B ancestor is either unary or branching.
Therefore beta_p<=1 and z_p<=1. h_Lambda can use at most two own units
of p: the first reserved bit if z1, and at most one local branch bit,
which is the first available bit excluding the reserve. Nonlocal leaf
channels use ONLY a macro's reserved first bit. Consequently BOTH bits
of every actual A StepEv after p's FIRST StepEv are outside im(h_Lambda).
There are exactly2(H_p-1) such physical tail units.

This proof follows directly from the inherited source allocation rule;
it needs no assumption that a tail is free under a, no auxiliary qE
bound, and no extension of a six-key chart potential. Actual original
event ordinals may cross DELETE/root-repeat occurrences; the first
StepEv means the first event in the entire actual natural macro.

## 2. Explicit collective source rule

specified source rule assigns disjoint undefined branch-demand sets
R_i to them, with |R_i|<=2(H_pi-1). List each R_i in original source
ordinal order and pair it with that many first tail units of p_i,
again in actual source order. This is an explicit D->U function.
Every chosen bit is an original actual event, lies outside the old
comparison image by part1, and is distinct globally because source
macro inventories are disjoint. Thus it extends h_Lambda injectively
on the specified branch frontiers for ANY finite supplier/claim count.

The source rule/cover is a hypothesis at this general level, not inferred
from total capacity or the final matching. When ALL R_Lambda are covered,
the comparison is complete, independently of any fixed smaller map.
The inherited all-paid source exchange then yields free endpoints for
every missing root, preserving all old a/common values on the same

never declared an available effective donor merely by part1.

This is a physical source/block counting theorem. Source block eligibility
and required working realization are retained interfaces; no new arbitrary-
