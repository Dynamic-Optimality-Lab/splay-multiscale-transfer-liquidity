# Uniformity of the proved restricted source rules

The new physical tail lemma and first-core-divergence restriction have
symbolic proofs for arbitrary finite r, ambient keys and source length.
They use actual original depths/events and labeled cores, not a finite
population surrogate. The tail argument counts beta<=Q and a first
reserved bit; the divergence argument counts actual rotations. Neither
introduces extra solver/controller fields.

The preparation repair for Gamma_r C_r has at most4 holes and at least4
protected preparation bits. For Gamma_r C_run,r it has r-4 holes and at
least2r-6 protected bits. Both inequalities follow from source word
structure for EVERY r>=7. Original block formulas preserve arbitrary
independent ordered gap BSTs. Distinct repetitions have distinct original
occurrence IDs, so arbitrary positive finite block counts are covered.

All six A source frame formulas commute with order reflection and subtree
swap. Reflecting a complete source comparison preserves occurrence/event/
bit ordinals and injectivity. The fixed-owner composition works for ANY
supplied certified old map at its domain, so it need not assume a backend's
tie choices make f_E literally the reflected allocation. The old actual
reflected owner records are retained as their own certified inputs.

The only r7/r8 controls are already verified old histories. Fifteen new
producer maps on them test the new implementation/physical selection,
not arbitrary-support truth. At r8 the natural own partial map is used
when no certified smaller map is supplied; no unknown universal f7 is
fabricated. Uniform owner conclusions are parametric on the original
certified map and actual recurrence interval.

These source families do not cover arbitrary maximal-core order, all
other full cores, higher-H zero-hole cases or persistent A/B core
disagreement. The uniform active-operand representation with at most
2r+2H-3 known A nodes is an inherited necessary source syntax, not a
realization or sign theorem on arbitrary projected paths.

The new EDGE_CREATOR theorem does cover raw candidate origins for the
anonymous-parent H1 class even under persistent core disagreement. Its
parameterized proof is the at-most-two six-frame count plus cyclic
edge lifetimes, not finite testing. It does NOT prove those bits are
comparison-safe/usable, and marked-parent or higher-H classes remain
uncovered. This is an explicit mathematical boundary, not a hidden r cutoff.

The width>=r-4 lower bound remains confined to the unchanged deep/q1
packet debt/carry architecture. Static preparation maps supply actual
credits directly but do not prove an arbitrary-r native Bank25 schedule.
Support-dependent proof records/long noncausal channels are not renamed
constant carry. This stronger Gate U interface remains OPEN.
