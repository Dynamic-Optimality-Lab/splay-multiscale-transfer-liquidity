# Uniform scope of the new source argument

E21-COMP/J21 quantify over every original reachable paired-closed history
with maximal full core2r-1, r>=7, deep H1/Q=r-1 recoveries having EXACTLY
two selected T19 arrivals. They allow arbitrary finite source length and
any finite number of repeated/shared recoveries. The proof's constants
depend on the bounded three-ancestor extreme frame, not population size.

The inner remaining-chain key K exists and differs from x because that
chain has r-3>=4 marks. This explicit inequality is the only lower-support
size needed in X21/the backward unary recursion, apart from noncollision
with other deep accesses Q=r-1>=6. It is not a finite r7 enumeration.

Literal deep Q6,u6,beta0,z1 implies r7: six unary ancestors plus leaf x
exhaust the whole marked tree. Adding genuine keys changes that geometry;
the legitimate deep extension is Q=r-1. Nondeep fixed-Q6,beta1,z0 and the
zero-tail larger-support cases remain outside this source theorem.

Private BSTs are actual ordered operands of the six ordinary bottom-up
formulas. No off-path population is bounded, no mark is deleted and no
shared inventory is duplicated. X21 explicitly covers two-event macros
with anonymous helper y on either side of the marked interval. V2, W2
and the A_G/A_R inverse families retain anonymous top parents on both
outer sides. Longer inactive private ancestors remain inside unchanged
operands. Genuine boundaries have their actual marked root, so no
anonymous boundary root is silently assumed away.

Reflection reverses the global physical order and swaps every L/R child.
It commutes with zig, LL/RR and LR/RL and transports original occurrence/
event/bit IDs bijectively. Thus every proof and supplier rule applies to
the reflected extreme order. No one-orientation extrapolation is used.

Changing charts/root-repeat KEEPs remain in the original source; the new
rule does not use a fixed-chart predicate. No finite passing experiment
or abstract edge-realization assumption supports a universal quantifier.

What is NOT lifted: more than two arrivals, all H/other origin types,
smaller full cores, every prechosen immutable HIGH comparison extension,
general effective-owner endpoint closure, or arbitrary-r physical Bank25.
These remain source-level proof targets, not merely larger test cases.
