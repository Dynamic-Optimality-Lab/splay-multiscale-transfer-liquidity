# Symbolic coverage and the raw nonreal-kind refinement

The proof is over the original arbitrary-signature LOW domain, not a
finite population corpus. Reuse UNIFORM03/SOURCE_COVERAGE's complete
count-free protected-prefix grammar and POP3/4/5 source-lift inductions.
For every actual witness retain both endpoint alpha observations,
real operands/ancestry and the current children of literal source
owner0 after the unit-cost A word. There are only the six original
words L/R/LL/LR/RL/RR. No full prefix terms are enumerated.

Introduce a SYMBOLIC production type at every protected address:
Score0..8,F anonymous,PORT,EMPTY,G. Types are private proof variables,
not added shared coordinates. The root/terminal are forced to the
actual Scores r/x. Forced ancestry is real. A Score k splits its
remaining Score interval[l,h] into[l,k-1],[k+1,h]. Anonymous gap g
splits it into[l,g-1],[g,h], allowing equal-gap anonymous nodes on
BOTH sides. All g in[l,h+1] remain possible, with no Sigma bound.

PORT is a cut and can hide any compatible remaining material. EMPTY
has no hidden Score and is therefore possible only if l>h. G has
the same Score-empty restriction from the completed source grammar,
but is the original kind0 out-of-range reference, NOT an active node.
G lookup reads the literal old source owner and its CURRENT children.
PORT and EMPTY propagate their own original nonzero kind. They are
kept DISTINCT, so an old PORT guard is never silently extended to
EMPTY. Ignored unused flags/indices remain universally arbitrary.

The original normalized grammar merged nonreal cuts. Its refinement
is complete: map each actual protected cut to its actual kind; actual
EMPTY/G cannot hide a remaining Score by the original Score-cover
and port semantics, so their interval restriction is satisfied. All
other induction cases are the old cases. Extra anonymous population
restrictions are omitted, an OVERAPPROXIMATION that cannot invalidate
an UNSAT signed proof. No completion or gap is selected as public data.

formal address tree. Each observed path stops at PORT/EMPTY, resolving
