## 2. Why this is still the full scalar obligation

This point follows exactly from (2); it is not a conjectural comparison.

First, A(W)=0 cannot create a zero-denominator counterexample. With no A StepEv, A never rotates and every request is to its one fixed root x. If there is any KEEP, the first such B phase makes x the B root, after which all B phases are identities. Exact B closure forces B to have started with root x as well. If there is no KEEP, B never moves. In either case Q_B=R6=0. The empty physical population is vacuous.

For A>0, divide (2) by A and take suprema over all admissible W:

\[
M_6:=\sup_W R_6(W)/A(W),\qquad
M_Q:=\sup_W Q_B(W)/A(W).
\]

Then, in the extended nonnegative reals,

\[
M_6\le M_Q\le C_0+M_6.
\tag{4}
\]

Consequently a uniform finite-c R6 bound exists if and only if a uniform finite-coefficient relaxed Coarse-Double bound exists, under the inherited premises. A proof of (1) gives coefficient C0+c; a relaxed-CD coefficient C gives c=C.

Thus the remaining gap cannot be described as a small consequence of the nonbranching-chain theorem. The inherited Route 04 transfer gives the stated connection to the larger DO program at its recorded scopes; it supplies no missing bound here.

There is an elementary size-dependent bound for the ENTIRE source:

\[
R_6(W)\le Q_B(W)
 \le \left\lfloor\frac{|S|-1}{2}\right\rfloor K_B(W)
 \le \left\lfloor\frac{|S|-1}{2}\right\rfloor A(W)
\tag{5}
\]

when B has a nontrivial carrier. Each actual nontrivial B path uses distinct physical S vertices and therefore has depth at most |S|-1. No projection or discarded hanger is used in this argument. If B never rotates, both sides are zero.

Equation (5) is not the requested uniform theorem: its coefficient grows with |S|. It does show why arbitrary repetitions or exhaustive cycles on one fixed finite population cannot refute the existence of ALL finite coefficients. A genuine asymptotic refutation must have unbounded carrier size. This is a necessary test, not a construction of such a family.

## 3. Exact all-source filtered SET balance

This derivation uses only the original SET labels and literal event conventions from RG-01. It is a diagnostic expansion of the existing signed identity, not a new candidate capacity or potential campaign.

To avoid confusion with D6's fixed domain I(W), write L for an arbitrary carrier-rank interval, including S itself. Define

\[
\chi_L(J)=\mathbf1[\varnothing\ne J\subseteq L].
\]

At a fine-event boundary let

\[
m_L=\sum_{J\in J_S(B)\setminus J_S(A)}\chi_L(J).
\]

The sum is over the actual SET of missing labels. Duplicate A representatives do not create extra occurrences.

### 3.1 Every original real A bit

For the actual A rotation alpha, keep B fixed and set

\[
\mathcal L^-_\alpha=J_S(A^-)\setminus J_S(A^+),\qquad
\mathcal L^+_\alpha=J_S(A^+)\setminus J_S(A^-).
\]

The literal rotation preserves the whole-frame label, every internal component label and every ancestor label. Only the old promoted-child label can be SET-lost, and only the new demoted-pivot label can be SET-created. Each displayed set therefore has size at most one, with empty candidates and duplicate surviving representatives suppressed.

Exactly,

\[
a_L(\alpha):=\Delta_\alpha m_L
 =
 \sum_{J\in\mathcal L^-_\alpha\cap J_S(B)}\chi_L(J)
 -
 \sum_{J\in\mathcal L^+_\alpha\cap J_S(B)}\chi_L(J).
\tag{6}
\]

Thus a_L(alpha) is -1, 0 or +1 for every original real A rotation. Define p_L and n_L to count its +1 and -1 occurrences. Then

\[
\sum_{\alpha\in A}a_L(\alpha)=p_L-n_L,\qquad
p_L+n_L\le R_A.
\tag{7}
\]

These are interval-filtered event signs. They are not, for a proper L, the original P_A and N_A, and they are not counts of A rotations promoting a key in L. In particular, a globally zero SET change can move the two affected contributions between different interval filters. All real private-key A rotations are included in (6).

### 3.2 Every original real B bit

Fix the complete post-A tree at KEEP target x. For every actual B rotation beta:

* the old proper promoted-child label C_beta contains x and is A-absent;
* the new demoted-pivot label J_beta excludes x;
* the whole-frame label is transported unchanged;
* the actual B SET change is exactly removal of C_beta and insertion of J_beta.

The operands are genuine S vertices, so both replacement labels are nonempty and their B representatives are unique. Post-A root x makes a proper label containing x A-absent, even with private physical keys.

If beta is decreasing, J_beta is A-present and

\[
\Delta_\beta m_L=-\chi_L(C_\beta).
\tag{8}
\]

If beta is neutral, J_beta is A-absent and

\[
\Delta_\beta m_L=\chi_L(J_\beta)-\chi_L(C_\beta).
\tag{9}
\]

This gives the complete table:

| Original B bit | chi_L(C_beta) | chi_L(J_beta) | Delta m_L |
| --- | ---: | ---: | ---: |
| Decreasing | 1 | either value | -1 |
| Decreasing | 0 | either value | 0 |
| Neutral, entering the filter | 0 | 1 | +1 |
| Neutral, leaving the filter | 1 | 0 | -1 |
| Neutral, both labels inside | 1 | 1 | 0 |
| Neutral, both labels outside | 0 | 0 | 0 |

The decreasing rows ignore chi_L(J_beta) because that new label is A-present, hence missing with weight zero. The two neutral zero rows still contain an actual real B rotation.

Let d_L count decreasing B bits with C_beta contained in L; let iota_L count neutral entries (0,1), and omega_L count neutral exits (1,0). These counts are actual original event occurrences, not inferred edge agreements.

### 3.3 Whole-period telescoping

Complete paired closure returns both original SET collections, so m_L returns to its initial value. Sum (6), (8) and (9) over the original period:

\[
0=(p_L-n_L)-d_L+\iota_L-\omega_L.
\]

Equivalently,

\[
\boxed{d_L+\omega_L-\iota_L=p_L-n_L.}
\tag{10}
\]

The exact quantitative consequence is

\[
|d_L+\omega_L-\iota_L|
 \le R_A\le2A.
\tag{11}
\]

This proof covers both orientations, SS/opposite doubles, roots and empty middle subtrees. It uses actual SET differences, so private ancestry and duplicate A labels are handled. A terminal B zig is one real decreasing bit. DELETE contributes its actual A changes and an empty B sum. Zero-cost operations contribute nothing. At the cyclic seam there is no new event or extra copy of an A unit; paired closure is exactly the endpoint cancellation used in (10).

For L=S, every nonempty label passes the filter. Then iota_S=omega_S=0, p_S=P_A, n_S=N_A, d_S=D_B, and (10) is precisely the inherited identity D_B=P_A-N_A.

\[
D_W(L)=|\{\rho\in R_6(W):J_\rho\subseteq L\}|,\qquad
P_W(L)=|\{\alpha:\alpha\text{ real original A bit, promoted key}\in L\}|.
\tag{13}

\[
