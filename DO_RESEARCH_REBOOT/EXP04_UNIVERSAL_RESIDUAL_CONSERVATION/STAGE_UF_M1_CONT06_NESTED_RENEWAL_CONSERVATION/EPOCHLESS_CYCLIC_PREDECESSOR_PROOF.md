# NR-7: epochless PF cycles and same-ID copies

Fix a no-A-reset column with at least one ORIGINAL C_old parent. Its filtered predecessor graph is a cyclic list of the ORIGINAL IDs, lifted to the repeated physical period. This is not the M0 forest.

If every edge in that cycle were PF, the exact physical containments would compose at their actual timestamps:

    F_(i+1) subseteq J_i proper-subset F_i.

The chosen output is after the full B phase at i; the next frame is before the later B phase. Every following inclusion uses the same original g and physical key universe. At the final edge, paired closure identifies the next-lap F_0 with the ORIGINAL F_0. The composite strict finite-set inclusion F_0 proper-subset F_0 is impossible.

Thus each nonempty epochless filtered cycle contains at least one PM edge. With a single C_old ID, its self-copy edge must be PM. Equality F_(i+1)=J_i does not evade this: J_i is still strictly smaller than F_i because the marked producer target is removed.

Cutting at every PM edge turns all remaining PF edges into finite paths. In columns with A resets, epoch boundaries already cut the list and E_old pays its first C_old parent. Consequently the number of nonempty maximal PF runs is at most the number of nonempty A epochs plus the number of PM edges, hence at most R_A plus the unweighted P-entry count using C5's mediation injection. This bounds chain openings, not total length or initialized domain size.

The forced PM edge has an actual SS non-target promotion, but its P entry has no proved A price. No new donor is supplied by the seam. This closes the cyclic structural exception only; it does not prove G/H coverage or an absolute bound on the remaining PF runs.
