# EXP-04 evolving theorem ledger

All new symbolic proofs are same-agent, not formal or independent external
certification. Finite observations have FINITE-EXACT status, not PROVED.

## T1 — Actual carrier-SET zero cuts (PROVED—UNIVERSAL interface)

Let Psi=|J_S(B)\J_S(A)| using the original physical trees, fixed S and SET
semantics. At KEEP x, A is rooted at x before any B rotation. Each B bit
loses a proper S-subtree label containing x, hence absent from A, and creates
the completed demoted label excluding x. That output persists for the rest
of this splay, as in EXP-03's physical double-frame induction. If post-KEEP
Psi=0, all these output labels are A-present. Every B bit therefore has sign
-1. In particular no neutral residual-consuming parent ends at such a cut.

Use maximal intervals of positive post-operation Psi, including the first
following Psi=0 operation, and one whole designated lap when Psi never hits
zero. Rotate the traversal after the earliest zero if the initial cut is
positive. Assign the actual A StepEv of each interval. They are disjoint;
sum A(E)<=A. Full tree equality is not required, and source trees/labels are
never projected or changed. Persistent positive-Psi cycles are not excluded.

## T2 — Two separately budgeted directions (PROVED—RESTRICTED DOMAIN)

Inside T1 intervals, run the original eligible consecutive-rank shadow
selector separately in each orientation. Each system initializes from the
actual complete B tree. Its selected spans do not overlap within that
system. Every successive distinct retained target pair has a nonempty
original post-A-to-post-A interval; select its first bit0. These intervals
are disjoint in one system, across intervals and across the cyclic seam.
The two directions may reuse an A occurrence at most twice, not as two
physical rotations. Hence sum |J|<=4A. Original parents matching a shadow
old grandparent at the same operation inject into shadow doubles, by old-g
uniqueness. The original three-slot theorem then gives

    R_zero2 <= 3 C_seq sum |J| <=12 C_seq A.

R_zero2 is the union of matching ORIGINAL R_* gaps, ties assigned first to
increasing then decreasing. The exact complement is retained. Consequently

    Q_B <= (35+48 C_seq) A + (R_* \ R_zero2).

This does not claim that every old or new G/O/X consumer is covered. The
missing-rank constructions refute completeness. It is an independently
selected new quantitative class, with a true absolute global load bound.

## T3 — Physical edge-boundary primitive identity (PROVED, insufficient)

Define D_E(A,B)=|E(B)\E(A)| for complete labelled directed physical child
edges, including side. One rotation removes at most three and adds at most
three edges. Holding B fixed, |Delta_A D_E|<=3 per real A rotation, so the
total absolute A variation is <=3 R_A<=6A. The full paired cycle telescopes
the value exactly. This is a valid population-independent boundary bound,
unlike raw ordered ancestry-pair mass.

The missing B-decrease implication is FALSE. At the mandatory consumer
(132,2), D_E is46 before the first bit and47 after the second, with changes
0,+1. Moreover neutral B bits and even fully Pi-qualified neutral B doubles
can lower D_E. Thus neither B monotonicity nor a paid-only source for all
negative B boundary variation follows. No residual bound is inferred.

## T4 — Dynamic-finger monotone comparison interface (PROVED application,
external theorem dependency explicitly retained)

Use the classical dynamic-finger theorem with an absolute constant C_DF
large enough that the total bottom-up search/rotation cost on an arbitrary
initial N-key tree and m requests is bounded by

    C_DF [N+m+sum_{i=2}^m log2(1+|rank(x_i)-rank(x_(i-1))|)].

The source for the linear initialization term is Richard Cole, SIAM J.
Comput.30(1),44–85, DOI10.1137/S009753979732699X:
[primary publisher record](https://epubs.siam.org/doi/abs/10.1137/S009753979732699X),
[author institution's report record](https://cs.nyu.edu/dynamic/reports/?year=1995).
This established theorem is an added dependency, not a newly proved paper.
No explicit numerical value for C_DF, reproof, or formal audit is claimed.

Take any selected shadow with strictly monotone distinct retained targets
and their original repeats, initialized at actual complete B. Let J be the
initial physical path union to those targets. It is ancestor-closed; target
splays remain in J and preserve internal outside components. The physical
comparison is therefore exactly an ordinary J-tree execution with the same
double counts. Collapse zero-cost consecutive target repetitions in the
comparison, leaving ell<=|J|. The ranks are ranks IN J. Their positive gaps
telescope to at most |J|-1; log2(1+d)<=d for integer d>=1. Thus

    Q_shadow <=3 C_DF |J|.

This applies to skipped ranks and interior initial targets; it does not
assert a consecutive-rank sequential completion has identical geometry.

For one chronologically disjoint window system, accept only |J|<=2(ell-1).
The original retained-root intervals again inject into real A StepEv, so
sum |J|<=2A. Same-old-grandparent injection and the original three slots give

    R_system <=18 C_DF A.

For two orientations the coefficient is36 C_DF; for h separately defined
selection strategies in each direction it is36h C_DF. A scalar coefficient
accounts for every system's reuse; no free multi-orientation budget exists.
The selector depends on original targets/physical domains, not demand success.

## T5 — Whole-cycle rank-travel certificate (PROVED—RESTRICTED DOMAIN)

For a nontrivial closed source the original closed-core theorem gives
|S|<=2|M|-1, while distinct genuine KEEP keys are at most K_B<=A. Thus
|S|<=2A. Remove only consecutive root-repeat KEEP requests in the B
comparison, choosing its scalar cyclic traversal just before a genuine KEEP;
there are K_B<=A genuine target transitions in one such lap. This mathematical
cut does not renumber or edit archived original occurrences.
Use the actual B carrier skeleton, retaining all physical hangers, for the
dynamic-finger theorem. Let L be the sum of integer ceilings of log2(1+d)
on consecutive B-target ranks in S (cyclic last-to-first included).
The noncyclic theorem's travel sum is no larger than L. Therefore

    Q_B <= C_DF(3A+L).

For the independently testable source class L<=c A, Q_B<= (3+c)C_DF A,
and the three-slot interface gives R_*<=3(3+c)C_DF A. This is not a theorem
that every source has L<=c A: cheap alternating extreme targets refute that
universal traffic premise. Local versions must pay initialization and overlap
separately. Zero-A cycles have Q_B=R_*=0 by exact closure, without a ratio.

## T6 — Actual-window dynamic-finger density budget (PROVED—RESTRICTED DOMAIN)

Within T1's actual physical intervals, start from the next unowned original
operation and consider each chronological prefix. Retain EVERY actual KEEP
and DELETE; B freezes only at the genuine DELETEs. For a tested prefix,
fix J as the union of its targets' initial complete B paths. Collapse only
B-root repetitions. Let m be the remaining target-block count and L_J the
sum of integer ceilings of log2(1+rank distance IN J) between successive
blocks. Put D=|J|+m+L_J. Accept the longest prefix satisfying D<=4 A(prefix),
provided it contains a KEEP. Then advance past that whole span. If no such
prefix exists, reject that opening operation and advance one. No demand,
R6 predicate or B cost participates in selection.

Every actual B path during an accepted span lies in the fixed initial
ancestor-closed J, by the complete physical path-union induction. The
dynamic-finger theorem gives Q_B(span)<=C_DF D. All selected spans are
chronologically disjoint, including their genuine DELETE helpers, so their
actual A StepEv inventories are disjoint. Consequently

    R_density <=3 sum Q_B(span) <=3 C_DF sum D <=12 C_DF A.

The paid class is the literal subset of old R_* whose genuine consuming
operation belongs to an accepted actual span. This is not a shadow donation
and does not require any grandparent matching. It applies to arbitrary
within-span target order. Source-defined density eligibility is not a
theorem of coverage for every residual consumer.

Nonvacuity beyond T2/T4/T5: composed_p4_alternating_inside_m256 has A932,
Q_B732, one genuine old R_* gap. It escapes both monotone strategies and
has L/A=3995/932>2, yet is in an accepted T6 span. More such witnesses are
retained with full original traces. The original source itself is closed;
its cost-certified span need not be a standalone closed source.

## T7 — Own-access physical-grandparent class (PROVED—RESTRICTED DOMAIN)

If an old unpaid B parent's old g belongs to that access's PRE-A target
path, its original A splay rotates with pivot g exactly once. Bottom-up
splay demotes each original strict ancestor once; no two original B parents
in the same access have the same g. Thus these parents inject into real
original A rotations by (source,operation,pivot g). Three gaps per parent
and R_A<=2A give R_own<=6A. This strictly relaxes full synchronized A/B paths.
The composed_p6_bitreverse_inside_m256 parent(1032,1) supplies a finite
nonvacuous example. This optional class has its own6A coefficient if added;
it is not silently added free to the main four-class scalar reconstruction.

## Main quantitative reconstruction (PROVED partial interface)

Assign old R_* gaps successively to T2, the two T4 selection strategies in
both orientations, T5 with c=2, and T6, always by literal set difference.
Their respective budgets are12 C_seq A,72 C_DF A,15 C_DF A and12 C_DF A.
The precise unassigned original complement is R_next. Therefore

    Q_B <= (35+48 C_seq+99 C_DF) A + R_next.

Both constants are absolute inherited/external theorem constants. This is
not the universal conclusion R_next=0. A separate, often smaller interface
using T6 alone is Q_B<=(35+36 C_seq+12 C_DF)A+(R_*\R_density); its complement
can differ. Neither complement is erased because finite tests are covered.
