# Verification scope and results

The new witness archive contains six complete source records,
each with complete initial A, B and common diagonal, explicit
reaching prefix, every measured KEEP/DELETE and exact complete
closing trees. The exact source SHA256 values are recorded in
PHYSICAL_SCREENS and INDEPENDENT_RESULTS. Hashes identify
full source bytes or canonical structured records; exact
full-pointer state identity is checked by replay.

Every new source has a full pointer engine versus immutable
tuple transition check at each original operation boundary,
including unchanged physical fringe components. The reaching
prefix is replayed independently from the common diagonal
and not charged to A. The tests confirm 16,267 measured original
operations across all six sources. Actual genuine marked
support equals the physical key set in each case.

Five sources additionally have full original primitive SET,
Pi, U and cohort/R6 verification: 13,273 primitive rotations,
290 U events, 194 cohorts, and 96 adjacent pairs. The separate
immutable checker recomputes exact edges, signs, frames and
A membership intervals; the separate cohort checker rebuilds
the original first-hit adjacencies and consuming primitives.
The primary original R_* selectors were freshly run for these
five sources. Older higher comparison selectors remain pinned
primary implementations; they are not claimed to have a second
fully independent implementation. The 516-key screen did not
run full Pi; its count is unknown. Its principal physical
counterexample does not depend on that classification.

The exact positive raw periodic certificate is checked in a
separate rank-cost computation and against the frozen code
for each source. Consequently the original periodic source
case applies, every noncheap original R_* gap is covered by
H_all, and any remaining cheap packet fits Q(D). This proves
zero prescribed overflow for the stored sources without
claiming all other comparisons were reimplemented. There
was no candidate with a negative periodic certificate
requiring an all-cut/local failure proof. No negative
failure certificate is claimed.

CYCLIC_GAIN_LEDGER and LAST_PROMOTION_FORESTS use explicitly
named diagnostic pools, never a synthetic D. Each selected
real primitive event ID, slot and causal cyclic interval is
recorded. CHALLENGE_RESULTS separately replays G, DH, DW5,
DW6, the mixed-ownership EXP03 case and the exact 577-key
C03B witness, plus the small new sources. The tests check
root/donor uniqueness, strict frame containment, the two
outgoing roles and SET accounting. They do not prove a
uniform bound on forest size per A unit. For the 24-key
case, full critical states, primitive signs, original Pi/U
records and the exact silent selection are saved.

C04's 60-file seal, the prior checkpoint manifests and their
transitive input pins are verified before and after the
work. Important Pair Access and downstream source specs and
the pinned local Levy–Tarjan PDF are also hashed. No
historical result is modified, no historical run is overwritten,
and HEAD and tracked files remain unchanged.

Proofs are mathematical derivations with explicit inherited
interfaces. Four-node coercion is a proved all-size lift
of a completely checked fixed transition table. The larger
finite witness replays are exact program checks operated
by the same agent; no proof assistant or independent-human
certification is claimed.
