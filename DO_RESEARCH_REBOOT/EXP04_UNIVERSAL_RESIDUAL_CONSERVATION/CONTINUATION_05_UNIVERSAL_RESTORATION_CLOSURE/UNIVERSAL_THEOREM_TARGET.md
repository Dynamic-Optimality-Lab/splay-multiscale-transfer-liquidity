# Frozen universal target

The source is an arbitrary finite, complete labelled present-key Pair Access
period reached from an allowed common diagonal. KEEP splays its target in
both actors; DELETE splays A and freezes B. No physical key is removed.
Both entire labelled trees return to their respective starting trees.
Reaching work is not measured. All original chronology, marked support S,
SET labels, Pi windows, U, cohorts, first hits and occurrence IDs remain
unchanged.

Use \(a_t=\lceil d_A(x_t)/2\rceil\) and
\(q_t=\lfloor d_B(x_t)/2\rfloor\) on KEEP, zero q on DELETE.
Put \(A=\sum a_t\), \(Q_B=\sum q_t\). A bit means an actual rotation;
\(R_A\le2A\), with no virtual donor.

The fixed original pool is
\[
D=R_*\setminus(F_{\rm carrier}\cup F_{\rm skipped}\cup E_{\rm old}\cup H_{\rm all}).
\]
E_old uses its original after-frozen-and-original-index-prefix selection pool,
before hybrid payment. It is not recomputed or refilled. H_all is the whole
noncheap hybrid eligible class. Q(D) pays all literal gaps of the first
\(2a_h\) distinct D parents at each KEEP h, or all parents if fewer.
Here \(a_h=A(G_h)\), with the original cyclic preceding KEEP gap including
all intervening DELETE helpers. The fixed remainder is
\(R_{\rm overflow}=D\setminus Q(D)\).

Put \(e_h=(b_h(D)-2a_h)_+\). The number of distinct tail parents is
\(T=\sum_h e_h\), and each has 1–3 literal gaps. Thus
\[
T\le |R_{\rm overflow}|\le3T,\qquad
Q_B\le(47+48C_{\rm seq}+102C_{\rm DF})A+|R_{\rm overflow}|.
\]
The requested theorem is an absolute \(K\) with \(T\le KA\) for all sources.
It would yield the stated constant \(47+48C_{\rm seq}+102C_{\rm DF}+3K\).
A direct absolute \(Q_B\le CA\) is equally valid: in fact
\(|R_{\rm overflow}|\le3Q_B\) by the original three-slot theorem, so the
existence of these two absolute bounds is equivalent. The proofs need not
use the same accounting.

No KEEP or no genuine KEEP gives zero B work. If \(A=0\), every operation
targets the unchanged A root; exact B closure forces every KEEP to be
a B identity. No ratio is formed at zero. No finite tested source inventory
or new optional payment is substituted for this target.
