# Global original A-work accounting

## Frozen coefficient

Only the original occurrence partition is used for the main target.
The inherited base is \(35+36C_{\rm seq}\); frozen carrier adds
\(12C_{\rm seq}\); four skipped-rank strategies add \(72C_{\rm DF}\).
E_old adds 6 and the single source-case hybrid budget adds
\(30C_{\rm DF}\). Q(D) adds 6 **in place of** the original prefix
payment. Sum: \(47+48C_{\rm seq}+102C_{\rm DF}\). E_old uses its old
pool and the quota is applied once to D. All quantities multiply
original A, never reaching work. This is exactly C04's interface.

## Additional partial payment for the R1 selectors

Apply the following to a fixed parent pool, for the new residual
application only the **literal overflow parents**. Use last promotion
(or, for the smaller class, last actual gain). In this priority order
classify each parent once:

1. Actual A reset of its old g since its predecessor.
2. Selected B restorer in its own original index prefix \(j\le 2a_h\).
3. Selected B restorer at an H-protected KEEP in the frozen
   hybrid's eligible union of operations.
4. Selected B restorer has a decreasing bit.
5. Fully neutral restorer has an A-exposed whole frame.
6. Fully neutral restorer's **completed old-parent output** is
   A-acquired during its continuous B SET membership run.
7. Otherwise: silent restoration, or no-promotion retention.

No comparison is recomputed to make a donor eligible; no original
R_* or E_old membership is changed. Step 3 uses the unchanged
original H guard (noncheap and containing an internal fully neutral
double) at the operation, which need not guard that particular
restorer by its own frame. It uses the old periodic case first;
otherwise the old local eligible union. In either case a protected
operation is retained at its original complete B state. The donor
can be a physical double that was not itself an original R_* consumer.

### Exact budgets

Reset bits inject across columns and within each cyclic column,
so count at most \(R_A\). Selected B restorers are all distinct by
R1. At most \(2a_h\) prefix positions per original KEEP, summed over
disjoint real A gaps, price step 2 by \(2A\). For step 3 in the
periodic source case, the retained comparison's double count is
at most \(10C_{\rm DF} A\) by the periodic initialization
cancellation. In the local case each eligible comparison costs at
most \(5C_{\rm DF} A(I)\), and C1's irredundant cyclic subcover
has operation multiplicity at most two. Thus the SAME bound
\(10C_{\rm DF}A\) prices step 3 in either case. The two cases do
not add. This is a separate transfer budget; old H_all is unchanged.

A fully neutral same-side restoring double cannot be root-level.
At root level its completed old-parent output is the entire S side
of the new root x on that side. The post-A tree is also rooted at x,
so it has that exact nonempty label. This B bit decreases. For an
internal fully neutral restorer, its whole frame F is a proper
nonempty S label. Its old B membership run is consumed by the first
access inside it: a KEEP outside its subtree cannot alter that
completed component; a KEEP inside places its target at the root
and removes the proper label by the end. Strictly nested pre-B
frames give only one double with a given F in that access.

For step 5 use the original whole-frame window from the preceding
B loss before this run to the post-A snapshot of the restoring
access. Both ends are A-absent: the proper label contains the
current A root at each such endpoint. This is the Route04
whole-frame exposure selector, applied to the actual restoring
double. Choose an actual A SET creation of F within the window.
Each A primitive creates at most one SET label, including private
A duplicates (which can suppress creation). For a fixed label
these windows of different runs do not overlap. Thus at most \(R_A\)
actual A bits pay step 5. This does not assume that the restorer
has an original cohort or belongs to R_*.

For step 6 use the new nonempty label P of the old parent after bit
1 (the second primitive), not the grandparent output J used by U.
It is an actual B SET creation. B operands are in the fixed marked
core and each nonempty B label has a unique root there. The label
is absent in A at its birth by neutrality. If A acquires it before
its next B loss, select an actual A creation in that membership
run. Different labels cannot select the same A creation, and runs
of the same label are disjoint cyclically. At that A bit B already
contains P. Acquiring P subtracts one from \(\Psi\); the possible
one removed A label adds at most one. The bit is therefore negative
or neutral. B losses and A creations are separate original primitive
events, so inclusion of the loss endpoint does not add a donor.

Write P_A, N_A, T_A for the counts of real A signs +,−,0.
Closure gives total B decreases \(D_B=P_A-N_A\).
Step 4 uses distinct B doubles, each with a decreasing bit, so its
count is at most \(D_B\). Step 6 uses at most \(N_A+T_A\) real A
bits. Jointly steps 4 and 6 cost at most \(P_A+T_A\le R_A\).
Equivalently one may use the inventory of positive A bits for
decreasing restorers and nonpositive bits for output acquisitions.
This is aggregate sign accounting; it does not claim unused
historical ownership or a temporally local injection.

The total is
\[
 |T_{\rm paid}|\le 3R_A+2A+10C_{\rm DF}A
                  \le (8+10C_{\rm DF})A .
\]
Without the optional steps 2 and 3 it is at most \(6A\).
A actual bit can be reused across the three separately counted
roles, never within a role. Prefix and comparison costs are counted
again explicitly. Virtual A units supply no work.

## Literal auxiliary coefficient and complement

Delete only the original overflow gaps at these paid parents, without
refilling any selection. Let \(R_5\) be the remaining literal gaps.
Three original slots per parent give
\[
 |R_{\rm overflow}|\le(24+30C_{\rm DF})A+|R_5|,\qquad
 Q_B\le(71+48C_{\rm seq}+132C_{\rm DF})A+|R_5|.
\]
This auxiliary coefficient is **not** the frozen coefficient with
a different meaning of D. The C04 optional local-return mechanism
is not activated or added here. No absolute bound on \(R_5\)
is proved.
