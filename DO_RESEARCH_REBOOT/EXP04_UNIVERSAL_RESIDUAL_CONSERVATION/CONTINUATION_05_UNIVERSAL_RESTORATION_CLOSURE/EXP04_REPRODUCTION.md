# Reproduction and safe continuation

Use the existing Python with -B. Copy these scripts to a fresh
sibling under EXP04_UNIVERSAL_RESIDUAL_CONSERVATION; do not
rerun producers over either sealed checkpoint. Preserve C04,
C03B, C03, C02, C01 and the parent EXP campaigns. No dependency
installation or Git mutation is needed.

    python -B stage5.py
    python -B families.py
    python -B verify5.py
    python -B challenge.py
    python -B finalize5.py

Include the accompanying proof reports before finalization.
stage5 verifies the complete previous delivery and transitive
pins. The family generator builds actual measured reset
words using the independently checked 14-shape four-key
transition table and the explicit all-size lift. It builds
all six sources, then verifies complete physical closure,
reaching prefixes and positive raw periodic certificates.
No classified Pi outputs are inferred from physical screening.

verify5 replays the five small sources through original Pi,
checks primitives with the separate immutable implementation,
and rebuilds original cohort/R6 records separately. Original
primary R_* selectors write diagnostics only into the new
directory. The larger 516-key source is independently
checked physically and its exact critical geometry is
saved, without running full Pi. challenge replays the
specified historical controls and tests the last-promotion
classification with and without optional transfer payments.
It does not rerun historical producers.

SOURCE_WITNESSES holds complete source words, reaching
prefixes and physical initial/final states. Full primitive
histories can be regenerated by the pinned replay. The
24-key critical source interval, all actual primitive
signs and original Pi/U records are also materialized.
PHYSICAL_SCREENS and INDEPENDENT_RESULTS bind these words
by canonical SHA256. LAST_PROMOTION_FORESTS and
CYCLIC_GAIN_LEDGER retain original event IDs and precise
diagnostic pool scopes. Historical input bytes are
preserved, not recopied as new witnesses.

Integer exact costs decide every eligibility. The analytic
families are justified for unbounded parameter size in
the reports; the command runs only the saved sample sizes.
The 360 CPU-second and 2 GiB observed-peak allocations
are experiment limits, not theorem assumptions or claims
of host limits. All timed stage receipts, including
successive runs as the proof obligations changed, are
retained. Imports, tool overhead and report writing are
outside the measured stage sum.

finalize5 runs only after the producing processes have
ended. It checks the independent result bindings, every
required artifact, exact new and prior hashes, and the
resource ledger, then seals all files except the delivery
manifest itself. Verify the exact sealed file set and
SHA256 values afterwards without creating a new log
inside the delivered directory.
