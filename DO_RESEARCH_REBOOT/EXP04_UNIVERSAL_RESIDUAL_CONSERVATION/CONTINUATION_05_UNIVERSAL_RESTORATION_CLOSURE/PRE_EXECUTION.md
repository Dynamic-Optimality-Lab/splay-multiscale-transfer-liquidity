# Continuation05 scope and pre-execution gate

One primary target: absolute conservation of the fixed original packet tail,
or an absolute direct Q_B/A theorem. Preserve C04 and all historical bytes.
Stage allocation: 360 process CPU seconds, 2 GiB observed process peak,
at most 12 new complete sources and 1,025 keys per tested source. These are
search allocations, not theorem hypotheses. No broad support sweep.

Strictly smaller mechanism: consecutive appearances of one original tail
grandparent give disjoint cyclic intervals in that column. A selected
restoring promotion names exactly one column, unlike raw ancestry-pair
mass. Separate actual A resets, signed/exposed restoration, and continuous
retargeting. Identify the remaining mechanisms instead of assuming coverage.

Concrete start: rotation changes only two rooted descendant sets; a
non-target gain is the first bit of a same-side double. The signed SET
identity pays decreasing restorers. Exact completed output containment
distinguishes same-side disjointness from opposite-side wraps. An explicit
alternating path is an adversary to orientation-blind batch restoration.

Upward test: a genuine absolute bound on the unpaid restoration and
retargeting parts would finish the frozen sum e_h inequality. A new
orientation-blind counterexample only rejects that candidate, not CD.
Direct route independently tests whether O(n) complete closure of any
fragment provides a useful linear-overhead bridge; it supplies no
unproved constant for Q_B.
