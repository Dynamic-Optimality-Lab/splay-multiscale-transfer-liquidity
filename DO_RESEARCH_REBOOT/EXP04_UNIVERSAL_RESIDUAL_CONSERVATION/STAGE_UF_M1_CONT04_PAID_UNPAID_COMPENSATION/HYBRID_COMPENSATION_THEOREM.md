# Source-uniform guarded-return replication theorem

Principal scoped result. It proves that a precise physical deformation cannot turn an eligible G/H-paid source into an unpaid one. It does NOT classify every admissible source as such a deformation.

## Exact assumptions and deformation

Let W be any legally reached, exactly paired-closed ORIGINAL source. It contains a block of two consecutive KEEPs to a,b, where before the block BOTH full trees are rooted at b and a is a direct child of b in both. The complete middle components may differ, include arbitrary private keys and have unbounded size. Assume a!=b. The two actual accesses are inverse root zigs in each tree: each A access costs1, B has zero doubles, and the full labelled A/B state returns exactly.

Let W_T replace this EXISTING block by T copies, T>=1. Preserve the original initial states, source cut and excluded reaching prefix. The added copies have their own literal original operation/bit IDs; no old occurrence is relabelled as a new donor.

Assume the original G or H full-period certificate, with comparison cut immediately BEFORE this block, has cyclic cost C<=10A(W). This is an original permitted certificate, with all old initialization and retention rules; it is not an assumed universal property.

## Primitive/full-source invariance

Every copy is a two-zig full-state identity. Outside the replicated block the complete A/B states, depths and original rotations are unchanged under the literal ID shift. KEEP support M is unchanged: the same two already-present nonidentity targets are repeated. B's initial path union S is unchanged: each copy begins at the same actual B state and traverses the same two paths. No DELETE is added, and all original DELETE accesses occur in the same full A states, so the original I data are unchanged.

A(W_T)=A(W)+2(T-1), Q_B(W_T)=Q_B(W). Every copy has q=0, hence neither a neutral-internal-double guard G nor a noncheap neutral guard H. Outside the block, the incoming KEEP A gaps are unchanged: the last copied KEEP still has target b and leaves the same full A/B state before the original suffix. The first copy has the same incoming gap as the original; later copies are unguarded regardless of their gap. This explicitly handles H's A-dependent test.

## Exact normalizer law at the specified cut

At the comparison cut the guarded-return stack is empty and its state table contains just the actual pre-block B state B0. The first zig produces a different root/state B1 and is appended. The second returns to B0 and erases both entries. The stack and state table are again exactly their initial values. Every further copy does the same. No guard intervenes.

The unchanged original suffix is therefore normalized with precisely the same stack, initial B state, G/H guards and original physical state sequence as in W. The retained suffix word and its physical path-union domain J are identical under the original ID shift. Thus, for each applicable variant,

    C_G(W_T;cut)=C_G(W;cut),
    C_H(W_T;cut)=C_H(W;cut).

The chosen positive certificate remains positive since C<=10A(W)<=10A(W_T). The frozen H_all source case pays every prescribed noncheap original R_* gap. Any cheap KEEP has at most2a_h original B parents and all of its D parents are quota-selected. Consequently

    S_UU(W_T)=empty for every T>=1.

No claim that the long source's native R_* set is empty is needed. The theorem applies whatever that new original set is. The original source/cyclic cut used to DEFINE S/U/R6/R_* is unchanged; only the comparison's permitted cyclic traversal starts at this block.

## Budget and exact complement

This invokes the EXISTING single H_all budget30 C_DF A(W_T); do not add another30. Other assigned classes keep their old order. There is no new K_UU or transfer X for arbitrary sources, and no general M2 conclusion.

The precisely proved source class consists of these W_T with an eligible original G/H certificate at the stated cut. The complement is every source for which such a base/block/cut certificate is absent. The theorem gives no reduction of that complement to this class.

Destroying this compensation requires more than replicating the stated identity: one must change the retained physical B trajectory/domain, the original support, the applicable G/H guards, or the certificate assumptions. It is OPEN whether every actual late silent residual forces such a change with globally bounded A load. Calling every failed certificate a physical defect would be circular.

It is FALSE without qualification that inserting a return anywhere leaves an existing stack untouched: its intermediate B state can coincide with an earlier stacked state. The cut at the block is essential here. It is also unsafe to infer H-guard invariance for first-time insertion that splits a previously large incoming A gap. Replicating an EXISTING block leaves the relevant outside gaps unchanged; the proof does not silently extend to that stronger insertion rule.

Proof box D: primitive inverse zigs and exact state-stack cancellation establish universality over arbitrary admissible bases satisfying the stated assumptions. No population cap, corpus percentage, or finite successful probe is a premise. Full M1 remains OPEN outside this subclass.
