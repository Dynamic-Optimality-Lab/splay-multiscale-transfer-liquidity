## Independently defined physical class

For every original B double v=(h,j), use g(v) and the original cyclic incoming KEEP cost a_h, with all DELETE work retained. Call v index-noncheap when j>2a_h. This is a property of the original all-double column; it does not inspect R6, R_*, F, D or S_UU.

For each actual A rotation alpha with pivot g, take its cyclic epoch through the next actual A rotation with that pivot. If the epoch contains any index-noncheap original B double with old grandparent g, select the FIRST such double. Let E_phys be the set selected over all physical A bits. If g has no actual A demotion, its column has no epoch and contributes nothing. Keep the actual modulo-period IDs, not a new donor at a seam.

This is not E_old's selection pool. E_phys is defined on ALL B doubles before gaps or F. E_old is still selected once on the original C_old. No selector is refilled.
