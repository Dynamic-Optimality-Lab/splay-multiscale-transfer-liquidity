\[
V=V_R\mathbin{\dot\cup}V_C\mathbin{\dot\cup}V_P

and a finite binary rooted forest on V. Each C or P vertex has exactly one predecessor. On every edge r to v, the original S frame satisfies

\[
F(v)\subsetneq F(r).
\]

The same strict inclusion holds on complete physical key sets. There is an explicit injection from V_R to real original A-demotion bits, so

\[
|V_R|\le |\mathcal B_A^{\rm real}|=2A-Z_A\le2A,

Let \(\mathcal R_{\rm overflow}\) be the **fixed original** C04 residual set, and let its scalar cardinality be \(R_{\rm overflow}\). Every member has one original consuming B double \(\mu(\rho)\in V\). Set

\[
w(v)=|\mu^{-1}(v)|,\qquad
R_i=\sum_{v\in V_i}w(v)\quad(i=R,C,P).
\]

Then

\[
0\le w(v)\le3,\qquad
R_{\rm overflow}=\sum_{v\in V}w(v)=R_R+R_C+R_P,
\]

and therefore the required module interface is

\[
\boxed{R_{\rm overflow}\le6A+R_C+R_P.}

\[
\boxed{R_R=0,\qquad R_{\rm overflow}=R_C+R_P.}
\]

This sharpening follows from the existing E_old selector and the unchanged quota, not a new payment or an assumption of universal residual emptiness.
