# Physical root-to-A-bit injection

Define iota(v), for each canonical global R vertex, as the last actual A primitive with pivot g(v) in its lifted interval I(v). Existence is exactly the R predicate. Return that primitive's original ID modulo the measured period; do not manufacture a new donor when the interval crosses the seam.

## C1 and C2: existence and legitimacy

I(v) uses the measured period's complete original event word. A donor is an actual rotation demoting its pivot g, either in a KEEP or DELETE A phase. It can be either real bit of an A double or the real bit of a terminal A zig. Preparation-prefix events, comparisons, B rotations and virtual accounting companions never enter this list. A root-repeat access has no bit and cannot donate.

## C3: injectivity

Suppose two roots receive the same original A primitive. Its pivot is a single physical key, so both roots have the same old-grandparent key g. The global consecutive-use intervals I(v) for that g have disjoint primitive inventories on the cyclic word. The same original bit therefore cannot lie in both. This proves injection, not merely bounded observed load. Bits of the same A StepEv are different donors; we do not assert injection into cost-one StepEv.

## C4: cyclic validity

Each interval runs between consecutive global uses of its key and traverses no more than one lap. Selecting an event on a negative or positive lift and then returning its original ID does not duplicate it. Exact complete A/B closure makes this cyclic lift an actual repeated history. If a column has only one use, its full wrap interval still contains each eligible original bit at most once. Moving a computational scan seam leaves the cyclic intervals and original donor identities unchanged.

## C5: budget in the original cost convention

For an A access with depth d=2k there are k doubles, cost k and 2k real bits. For d=2k+1 there are k doubles and one terminal zig, cost k+1 and 2k+1 real bits. For d=0 both are zero. Summing over all original KEEP and DELETE accesses gives

\[
|\mathcal B_A^{\rm real}|=2A-Z_A\le2A,
\qquad |V_R|\le|\mathcal B_A^{\rm real}|.
\]

An equivalent budget says at most two roots per actual cost-one A StepEv. A virtual companion of an odd-depth access contributes no donor. If A=0 the finite forest has no roots, and therefore no vertices; equivalently all original A targets are its fixed root and exact B closure forces B identities. There is no division by A at zero.

## Why the EXP-01 Hall counterexamples do not refute this map

This maps only canonical **global forest roots**, not all R6 gaps, all upper parents, every restored B ancestry relation or every later use of one grandparent in an A epoch. Those later uses can be C or P descendants and receive no new A donor here. We do not assign one common root-entry resource to every consumer, or claim unit or load-two capacity for the historical EXP-01 incidence graph. The W-family Hall obstructions to those different assignments remain preserved. The injection here follows disjoint all-double same-key intervals and a single physical pivot, neither of which was an established property of the refuted maps.
