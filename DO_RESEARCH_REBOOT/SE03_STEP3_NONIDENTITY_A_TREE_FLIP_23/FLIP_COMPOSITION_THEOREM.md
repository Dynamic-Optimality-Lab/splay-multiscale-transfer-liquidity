Let d_i=H_A(D_i) (4 or5). On every retained occurrence outside catchers,
actual and shadow A-event counts agree. At each catcher original-shadow
is -1; on each deleted interval it is d_i. Therefore

    A_actual-A_shadow = sum_i(d_i-1).

This is an exact occurrence-by-occurrence identity. The source correction
data is the list of original deletion intervals, catcher occurrences and
repair maps, not an unproved scalar state potential. It composes without
assuming that endpoint equality makes intermediate costs vanish.
