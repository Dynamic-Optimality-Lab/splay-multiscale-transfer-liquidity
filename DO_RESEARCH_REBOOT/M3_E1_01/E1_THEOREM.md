## Public definition and exact scope

let r be its core root and define

 V(s)={x in0..8: x!=r, mu marks x, and for SOME i in1..6,
                      alpha_i.kind=0, alpha_i.isS=true, alpha_i.index=x}.

Use a SET of labels, not positions; duplicates are irrelevant. Opaque/empty
positions never contribute, regardless of their unused isS/index fields.
The predicate is

 E1(s) iff EVERY x in V(s) has depth_coreB(x)<=3.

V empty makes E1 true. Invalid B projections can receive any fixed totalization
outside genuine H1 source states; no original edge is deleted or identified.
Neither V nor E1 reads a private gap colour, inventory, port bill, pointer
identity or history. Sigma need not be bounded to a particular population
for this argument; the frozen source domain/caps remain unchanged.

## Augmentation and proof

Let D be ANY public ordinary-state function with0<=D<=2. Define

    D+(s)=max(D(s), I[E1(s)]).

For EVERY original H1 edge s->t whose D residual is nonnegative, its D+
residual is also nonnegative. Thus the theorem preserves already valid
inequalities INDIVIDUALLY, without assuming D was globally feasible.

If the source is not raised, D+(s)=D(s), while D+(t)>=D(t). Hence

    w+D+(t)-D+(s) >= w+D(t)-D(s) >=0.

If the source is raised, it belongs to E1, D+(s)=1 and w>=1. The range gives

    w+D+(t)-D+(s) = (w-1)+D+(t) >=0.

Both arguments hold with source/destination raised simultaneously. They
include equality boundaries D(s)=1,w=1,D+(t)=0 and empty V (no genuine H1
edge can leave that state). D+ stays in[0,2]; if D>=psi, so does D+.
The proof applies to real or integer debts and all masks/signatures.
