# An unguarded retained packet branch with an exact global owner

This is a proved subcase, not universal Step2 or all unguarded packets.
The displayed auxiliary debts are the old D on one FIXED actual erased
nine-Score history. No debt on a recent-key chart is identified with D.

## Source scope

Take an original reachable fully paired-closed six-key core11 history,
its actual recurrent erased five-key/core9 comparison, the fixed Step1
fE, and its legal maximum-D actual period I. Consider disjoint original
q5,q1 packets with total actual A cost2, both terminal targets retained.
Require that their two actual auxiliary genuine macros ALSO have H=1,1
and qE=4,1. No preparation tail, large preceding macro, or return of full
and erased B to equality is assumed.

The original first four doubles are common; its fifth is P. Its return
double is common. Thus this packet has exactly one unmatched demand p
and no local N. Actual A events may occur at DELETEs before the terminal
KEEP; identify the sole actual event of each macro by its real source ID.

The sealed M3 local source law forces

    -2+d_mid-d_before>=0 => d_before=0,d_mid=2.
    +1+d_after-d_mid>=0 => d_after>=1.

Its integer range implies d_after is1 or2. This theorem closes the branch

    d_after=2.                                           (1)

This is an actual fixed-chart predicate, not a newly fitted six-key debt.

## The source donor, determined without a cardinality premise

The period maximum is2 because d_mid=2. Fixed Step1's bank2-D is
2 before the first macro,0 after it, and0 after the return by (1).
The first macro pays qE4 using two old bank units and its two new bits.
At the return, no old bank is present. Its sole actual A event e supplies
bits(e,0),(e,1) in that order; qE1 consumes bit0 FIFO. The required final
bank is0, so bit1 is irrevocably released into SURPLUS reserve. Define

    h(p)=(e,1).                                         (2)

The allocation follows the actual source FIFO queue, not |P|<=|V|.
It keeps every common assignment. The donor is outside the image of the
ENTIRE fE, hence outside fE(N) as well. In particular no negative chart
residual has been treated as a released unit.

This closes every packet in this branch even when its preparation gap
has no ordinal>=4 A event. The return event has auxiliary macro ordinal1.
Its original fifth demand may precede it; this is payment by packet/cyclic
block end, not native matching-terminal causal eligibility.

## Global ownership with the existing source modules

Apply (2) only to still-unfunded packet demands. Original q5/q1 packets
are disjoint by the inherited successor theorem, so their actual return
events and bit1 units are distinct, including under repeated periods.

All accepted Gamma, Omega+, Xi and guarded-preparation cold receipts use
fixed fE TAIL bits, whose auxiliary event ordinals are>=4. The unit (2)
has ordinal1. Thus none of those receipts owns it. Preserve all of them,
and skip any p they already fund. Units already assigned from fE(N) are
also disjoint from (2), since (2) is unused by fE. This supplies an explicit
ownership class test, not an assumption of an unclaimed donor.

The independent safe full-packet allocations for Hsum>=3 use different
source packets. Their units cannot be this Hsum2 packet's return event.
Their conditional exchange theorem is not invoked as an additional
already-completed allocation on an unresolved history.

The completed WHOLE-HISTORY B-return-pulse theorem cannot conflict on a
history containing a q5 access. Its erased support has at most five keys,
core<=9. Outside a pulse full and erased B are identical, so every retained
target has actual depth<=8 and q<=4. Inside a pulse the full demands are
q1 at its first z and return y, or0 at root repeats. Hence that complete
class contains no q5. Its alternative refined allocator and its exchange
are not superimposed on a nonreturning q5 history. Partial future pulse
modules would require their own disjoint-owner proof; none is silently
introduced here.

All newly funded units are registered as RETURN_SURPLUS owners indexed
by the actual packet. A future module must exclude these owners. This
proves global nonduplication of THIS module against the stated existing
allocations. It does not fund other currently unmatched cold demands.

## Legal seam

Use Step1's actual maximum-D period, not an arbitrary empty-bank seam.
A seam may split the cyclic packet after its first macro, since that
debt is2. Map each donor and demand role to its one actual occurrence
inside I by the already proved period bijection. If the return is early
in I and its corresponding first macro is late, both are actual events
of I and the release calculation still starts with bank0 at the legal
cut. If the whole packet lies inside I, payment is by its end. No period
copy, prefix supply or erased warmup excess is borrowed.

## The branch that this theorem does not solve

At d_after=1 the exact same FIFO computation KEEPS bit1 as bank1. It is
not released. Xi proves it can later pay a common K5 demand. Neither (2)
nor an ownership priority may take it away while preserving fixed fE.
Also open are packets whose actual auxiliary demands/macros are not
H1/q4 then H1/q1. These restrictions cannot be dropped to claim all
unguarded core11 packets or universal Step2.
