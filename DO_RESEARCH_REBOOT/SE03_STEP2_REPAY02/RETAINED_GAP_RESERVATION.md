# Source reservation after refining at every retained KEEP

Status: universal auxiliary funding/reservation theorem, not a complete
nonreturning Step2 theorem. Reuse the sealed pointwise M3 certificate and
the exact11F source map, at their unchanged five-key/nine-core scope.

Let pi be an actual reachable fully paired-closed auxiliary source history
with five genuine KEEP keys and fixed nine-node marked B core. Partition
it after EVERY KEEP, not just the genuine ones. Consecutive retained KEEP
targets are y,x. Each gap includes all intervening DELETEs and its terminal
KEEP. A and B start rooted at y; A ends rooted at x. All operations before
the terminal KEEP freeze B. Let H be its actual A-event total and q its
terminal auxiliary double count. These are original physical events/costs.

## Genuine change gaps reuse existing source proofs

If x!=y, H>=1, and the gap is itself a source-valid11F macro: every
intermediate nonterminal operation is DELETE, and the terminal KEEP is
genuine. The existing local source proof supplies the same full ordinary
endpoints and LOW/HIGH price2min(H,3)-q, with the same actual midpoint for
HIGH. Cutting a longer macro at preceding root repeats does not modify
or normalize its remaining source events. It merely starts this shorter
macro at its actual root-synchronized state.

The ordinary projection is defined at every retained KEEP boundary,
including root repeats: A and B share the marked root, the actual B core
and present-key gap populations are the same, and the existing raw fields
come from those actual trees. This uses no new graph coordinate or witness.
All such states obey the sealed range0<=D<=2. A repeat boundary need not
be the endpoint of a genuine graph edge to have a defined D value.

## Repeat gaps use range, not a fabricated original graph edge

If x=y, auxiliary B stays exactly unchanged and q=0. H=1 is impossible:
the sole positive A event would end at a different root, and subsequent
zero events could not return to y. Thus H=0 or H>=2. At H=0 both full
actual trees are unchanged, so the ordinary projections and D agree.
At H>=2, the RANGE alone gives

    2 + D(after)-D(before)>=0.                         (1)

No nongenuine LOW edge is added to M3. Equation(1) is an independent
inequality between actual boundary values of its existing function.

Set c=min(H,3) on change gaps, c=0 on H0 repeats, and c=1 on positive
repeat gaps. Then, for every gap,

    2c-q+D(after)-D(before)>=0.                        (2)

The raw chi8 issue is unchanged: a repeat gap fixes all B raw fields;
actual change macros have the sealed nondecreasing chi classification.
Full B closure fixes its final raw value, so chi is constant on this
refined comparison period. Hence (2) uses the actual D without dropping
an entry cost. Corrected h0 and every frozen graph edge remain intact.

## Actual physical source allocation

working bank is Dmax-D and starts/ends at0. On each gap mint the two
capacity bits of its first c actual A StepEvs. All other events' bits
are immediately reserved. At the gap end pay its q auxiliary doubles
FIFO and keep Dmax-D(after) working units. Equation(2) proves payment
sufficiency; release the remaining selected units. This is the same
ownership induction as completed Step1, with the explicitly new c rule.
Boundary bank<=2, selected units per gap<=6, within-gap queue<=8.

The reserve birth still equals2H-q+D(after)-D(before). In a positive
REPEAT gap, BOTH bits of EVERY event after the FIRST are guaranteed to
be outside this new auxiliary allocation. In particular the second
actual event provides two identified free units. Different gaps have
disjoint absolute source event IDs. No preperiod unit or double credit
is used. Summation gives the exact reserve size2A-QE, as in Step1;
the improvement is a stronger location guarantee, not more total credit.

Call this new auxiliary allocation gE. It is not asserted that the same

injective exchange into U disjoint_union fE(N). Claiming direct availability
under fE without that exchange would be unjustified.
