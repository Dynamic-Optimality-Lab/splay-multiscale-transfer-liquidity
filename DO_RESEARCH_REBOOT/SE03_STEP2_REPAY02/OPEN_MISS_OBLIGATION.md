# Exact surviving Step2 obligation

The recent-key cover does not complete Step2. It allows the already
proved nine-Score signed theorem to handle every HIT within one fixed
chart, including H1/q3,q4 and every zero/+1 helper transfer. The complete
global certificate still needs to pay changes between charts at MISSES.
Changing the debt to do that also requires preserving those hit laws.

For core10/11, retain the original q5-with-forced-q1 paired partition.
Its non-range-paid miss obligations are the same signed classes, now
restricted to segments that change the chart:

* singleton H1/q1: release at most1;
* singleton H1/q2: no debt release;
* singleton H1/q3,q4: debt increase at least1,2;
* singleton H2/q3,q4: release at most1,0;
* paired q5/1 with Hsum2: increase at least2;
* paired q5/1 with Hsum3: no release.

Miss segments of weight>=2 are range-safe for a width-two function.
The paired successor may itself be a miss, so both chart replacements
must be retained. No intermediate debt seam can be discarded.

Directly using the accepted D in successive recent-key charts is false.
The Hamiltonian ceiling fixes one prior obstruction but the stronger ray
ceiling still fails on Omega_plus, with source debt1, paired weight-2,
and target debt<=2. This is an original source counterschema to that
formula, not an original negative cycle or a refutation of arbitrary
width-two functions. Omega_plus has explicit physical repayment.

For a core11 miss, the exact common-core decomposition gives either
two disjoint cold twigs or one cold same-side four-node chain. The former
has an unpaid comparison between debts in two already valid charts.
The latter has the precise residual d_virtual-d_old-1, with the -1 an
actual B double. M3's pointwise inequalities alone give neither sign.
The deficiency-one core10 comparisons also remain. Their source case
partition is not replaced by an assumption of favorable erased-key choice.

A complete solution must construct a new compatible source debt with
all these signed preservation rules, or a nonduplicating source-credit
allocation that carries capacity through the replacements. Defining the
missing marginal inequality to be true, summing -2 per hit run without
funding it, or reusing the refuted normalized chart formula would be
circular or false. No such complete mechanism has been established here.
