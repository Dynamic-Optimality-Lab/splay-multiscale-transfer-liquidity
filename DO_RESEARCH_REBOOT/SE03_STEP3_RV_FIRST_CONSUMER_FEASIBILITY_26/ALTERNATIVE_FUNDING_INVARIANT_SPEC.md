# Diagnostic alternative interface — not a new established invariant

The current frozen extension property has NOT been refuted. No frozen
owner is replaced and no alternate induction branch is promoted.

A precise sufficient interface, should a different proof be required,
would supply for each actual source an independent total source-derived
H, before consulting the frozen effective a, together with:

* original natural/common and E-only retirement correspondence;
* same actual-period occurrence bijection and legal source cuts;
* a proved eligibility-closure license for alternating owner paths;
* a physical working schedule respecting Bank25;
* all signed full/erased chart corrections.

The uniform counting extension lemma would then preserve a without
moving any successful value. For a nonuniform static eligibility relation
the exact sufficient closure E(q) subset E(d), whenever H(d)=a(q) on
a relevant path, is proved in SOURCE_FORCED_FROZEN_EXPANSION. It is a
testable candidate source implication, not a fact about these sources.
No assertion is made that it is necessary or that it implies a working
schedule. Original block eligibility must first be reconstructed in the
particular proposed license; no invented terminal-key restriction.

An invariant J_new claiming the above would need a new scope-correct
base, its original owner/period/working specification, and a noncircular
source transfer. None is derived here. Accepted CD6 is not automatically
a base for every such strengthened invariant. The existing I(6) and
conditional I(r-1)+E_r=>I(r) remain exactly at their inherited scopes.

This diagnostic is useful because it locates the unresolved input in
source supply and license transport. It is not a renamed assumed Hall
condition, a proof that M(W) holds, or a repair of all G deficits.
