# Two levels of the frozen-extension proposition

Use actual I, F full original demands, U actual source units and an
injective prescribed a:A0->U. Let P_req be the actual required unpaid
roots, a subset of F\A0. For a complete original allocation the required
set is all F\A0. All mandatory policy successes must be included in a
before declaring a unit free. Earlier f5/f6 common/scope data stay fixed.

F_count: an injective extension of a covers F using original U on I.
M_count: some full injection H:F->U exists at that counting level.
These use E_count(p)=U. They are diagnostic weakenings, NOT replacements
of the user's frozen theorem.

F_lic (the actual F(W)): a new source-eligible injection on P_req into
U\im(a), preserving every specified comparison, owner, actual cut,
period and Bank25 condition. M_lic (actual M(W)): a complete physical
allocation with the stated original eligibility/period/working contract,
without imposing this particular frozen partial prefix. It does not
authorize changing a inside the current construction.

F_count and M_count are pointwise equivalent by the non-displacing
complete-map construction in SOURCE_FORCED_FROZEN_EXPANSION. This is
not a proof that either holds for every source. It shows that freezing
an injective prefix, BY ITSELF, is not an extra static obstruction under
unrestricted same-period counting eligibility.

For nonuniform source eligibility or global Bank25 schedules, M_lic
does NOT imply F_lic by that static argument alone. An old owner path's
terminal can fail a target restriction or a full working/cut contract.
Whether the ACTUAL campaign sources prevent such a failure remains the
primary B26 question. No fully source-valid failure witness is supplied.

In particular: a partial comparison ending at a hole does not disprove
F_count, F_lic or M_lic. A saturated local endpoint pool does not exhaust
U\im(a). A hypothetical restricted-neighborhood graph is not an original
source witness. A complete source-derived H plus the appropriate path-
eligibility/working license would prove F_lic without moving a; that
source supply/schedule bridge is not currently known universally here.
