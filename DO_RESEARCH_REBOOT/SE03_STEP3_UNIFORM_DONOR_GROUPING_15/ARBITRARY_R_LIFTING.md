# Uniform source lifting and exact scope

The leaf theorem's proof uses just the two original SS frame formulas,
nearest-marked ancestry and cyclic Boolean status for EACH marked key.
No bound on r, word length, number of births/deaths/deep groups or private
BST population is used. All mark-bearing branches remain in the actual
marked tree. Off-core BSTs are rigid under every full B splay. Arbitrary
A ancestors/helpers are retained in original H and actual event-bit lists;
no six-key zero-correction rule is generalized.

The full-source population reduction inherited from U14 is also uniform:
an r-mark synchronized A boundary has<=r-2 anonymous branchers, one per
adjacent-mark gap, after contracting unmarked unary core chains. An H-event
natural macro has<=2r+2H-3 active known nodes, with all other private terms
arbitrary. This is a source comparison/lifting theorem, not a sign or donor
availability proof, and it does not make fixed-support saturation uniform.

For the explicit family, r dependence enters only n=2r-1 and the new lower
neighbor prefix/suffix. Those are proved via original RR/LL vine induction.
The old H6 identity is used with an arbitrary lower marked subtree in an
old private gap; it is only a SOURCE identity on old operands, not an
application of a six-key FUNDING theorem to a seven-key history. The final
descending reset has its own uniform induction. Actual full maximal-core
membership follows from closure and support; no dynamically unrealizable
abstract state is assumed. Repetition is concatenation of complete original
closed blocks BEFORE any erasure multiplier division. The source donor
and reset inventories remain disjoint for ALL finite block counts.

Reflect the ENTIRE key order and swap child sides in every source formula.
LL/RR, LR/RL and zig directions interchange, every original cost/bit ordinal
is unchanged and all group/channel correspondences transport. This proves
both orientations; the numerical reflected witnesses are audits, not the
reason reflection is valid. Mixed orientations require actual source
bridges and are not silently included in this restricted family theorem.

The full principal theorem over ALL histories remains OPEN because the
required general branch-frontier supply and strong storage interface are
unproved, not because a finite-fringe cutoff has been substituted for them.
