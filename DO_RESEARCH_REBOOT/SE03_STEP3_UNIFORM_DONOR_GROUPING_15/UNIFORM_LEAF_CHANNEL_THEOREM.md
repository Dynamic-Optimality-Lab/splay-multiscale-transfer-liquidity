# Uniform marked-leaf channels and branch-frontier reduction

This is a NEW universal source theorem on the closed MAXIMAL full core,
not the complete U-DEEP-GROUP theorem after frozen ownership.

Fix any r>=7 and an original source period with fixed S=C_M(B), |S|=2r-1.
Use the inherited density/all-SS theorem: every genuine B access has even
depth, each double has marked G and unmarked P, and each unmarked subtree
has mass0. Natural macros retain all actual DELETEs/root repeats and have
H>=1. Let T(B) be the rooted tree on M whose parent is the nearest strict
marked ancestor in the ACTUAL B tree. It is not the binary induced subtree.

## 1. Source path-to-star and the exact leaf ledger

In LL, G(P(x(A,B),C),D) becomes x(A,P(B,G(C,D))). All mark components
inside A,B remain children/descendants of x; all mark components of C,D
remain under G. The marked parent edge G->x is reversed, and all other
marked parent edges are unchanged. P is unmarked and cannot supply an
additional marked parent. The RR formula gives the same edge reversal
with sides interchanged. This is an exact original frame identity with
arbitrary independent mark-free BST terms, not a graph approximation.

Induction over the original bottom-up SS frames proves: if the old marked
ancestors of x are g_1,...,g_q (from nearest to root), the new root is x,
every g_i becomes a child of x, and all off-path parent edges stay fixed.
In particular q equals the ACTUAL B-double count.

Let U_e be old marked ancestors with exactly ONE marked child (the path
child), B_e those with at least TWO marked children, and z_e indicate
whether x was a marked leaf. Write u=|U_e|, beta=|B_e|. The old ancestors
which become leaves are EXACTLY U_e; x loses leaf status exactly when z=1.
No other marked vertex changes leaf status. Hence, with L(B) the marked
leaf count,

    q=u+beta,
    Delta L=u-z,
    2H-q+Delta L = 2H-beta-z.                    (LC1)

All terms are original source quantities. Anonymous A helpers affect the
actual H/inventory but do not invalidate this B identity. This is uniform
in r, private populations, macro length and both orientations.

## 2. Concrete donor channels by marked key

If z=1, reserve the FIRST actual A-bit unit of that natural macro. Such
a bit exists since H>=1. Its exact (occurrence,event,bit) label is retained;
it is a candidate donor, not declared free under fixed owners.

A marked key v becomes a leaf only as an old unary ancestor in a B double;
that original double is its LEAF-BIRTH DEMAND. It ceases to be a leaf only
when a genuine access targets v, giving its LEAF-DEATH MACRO. Because
the actual full period closes by label, these Boolean status changes
alternate cyclically for EACH v. Keys with no changes need no channel.
Pair each leaf-birth demand to the reserved bit of the immediately preceding
leaf-death of the SAME marked key, cyclically within the selected period.

This is a specified source rule, not a matching oracle or a cardinality
assumption. Distinct births of one key use distinct alternating deaths.
Deaths of different keys occur in different genuine macros (only the
accessed key can die there). Thus ALL selected donor units are distinct
for every finite number of groups/keys. A wrapping channel uses the ONE
actual death occurrence in I, never the corresponding occurrence of an
adjacent copy. It may be later in I than its demand under the inherited
cyclic/block contract; no new native causal rule is claimed.

Every remaining B double corresponds to a branching marked ancestor.
Assign those branch-demand IDs in original event order to the first own
actual bits EXCLUDING the one reserved death bit, as far as they suffice.
Call the resulting partial source injection h_Lambda. Its only undefined
demands are a specified final subset of branch demands R_Lambda,e, with

    |R_Lambda,e|=(beta_e+z_e-2H_e)_+.             (LC2)

The leaf-channel units are excluded from all local branch spending.
Different macros have disjoint inventories. Therefore h_Lambda is injective,
uses actual U(I), and has domain D(I) minus R_Lambda, uniformly. Unused
physical bits stay unused; no debt value is counted as a physical donor.

## 3. All raw deep packets are covered; spacing and groups

A maximum-depth B access q=r-1 has a Hamiltonian full core, hence marked
parent tree a chain. Its target is the unique leaf, every old ancestor
is unary, beta=0,z=1, and ALL its r-1 doubles are leaf-birth demands.
They therefore receive distinct channel donors. The actual forced extreme
q1 successor has beta=1,z=1, and H>=1; its sole branch double fits the
other own bit. Consequently EVERY full double of EVERY actual deep/q1
packet belongs to dom(h_Lambda), with simultaneous raw nonduplication.

After a deep access L=r-1; after its successor L=r-2. Before the next
deep access L=1. Equation DeltaL=u-z>=-1 shows that at least r-2 genuine
accesses intervene between consecutive deep access occurrences, including
the q1 successor; after that successor at least r-3 more are required.
This excludes an assumed adjacent alternating deep/q1 run for large r.

Define a canonical cyclic group to run from AFTER one actual deep/q1
pair end through the NEXT pair end. When there is at least one deep
packet these groups partition all actual macros/operations without overlap;
each represents exactly one deep packet. Both endpoints have L=r-2, so

    2A(G)-Q(G)=sum_{e in G}(2H_e-beta_e-z_e).      (LC3)

Channel arcs can cross these groups. Their accounting owner is the UNIQUE
birth demand/key, and their donor owner the UNIQUE paired death macro,
so crossing evidence does not duplicate a physical bit. LC3 is an identity,
not a proved nonnegative group capacity or frozen-owner availability.

## 4. Frozen owners: exact partial augmentation and remaining frontier

Let a be the already licensed original partial full allocation on the SAME
I, keeping all required smaller-support common owners. From each missing
root p follow h_Lambda(d); if its unit has an a owner, continue there.
If the unit is outside im(a), append p to that free unit. If d lacks an
h_Lambda value, stop BLOCKED at that actual d in R_Lambda, never call it free.

Both maps are injective. Unique incoming predecessors prohibit a rooted
cycle or merger of two missing-root paths; a missing root is outside
dom(a), whereas every reached owner is in dom(a). Finiteness therefore
forces a free terminal or an undefined frontier. Free terminals are distinct,
old a values stay fixed, and BLOCKED roots inject into R_Lambda by the
same backward uniqueness proof. Successful exchanges have the inherited
actual-ID block receipt; a blocked path is explicitly NOT a payment.

Thus the new source theorem reduces every remaining locked-owner obligation
to a distinct LOCAL branch-excess frontier. A deep-anchored missing root
can reach an ordinary already-paid branch owner; covering its raw deep
demand in h_Lambda does NOT prove a free frozen-owner endpoint. The exact
seven-key witness shows this occurs. No Hall/global capacity is assumed.

If a source-defined rule completes the branch frontier to a full independent
injection, the all-paid complete augmenting-path proof fixes every old a
and common value at arbitrary r. The missing source SUPPLY cannot be
replaced by that conditional algebraic fact.

## 5. Status and storage

partial blocked-frontier theorem are PROVED uniformly on the stated maximal
core. They neither assume nor prove local beta+z<=2H; that candidate is
source-refuted. Full U-DEEP-GROUP after frozen ownership remains OPEN.

A single-scan implementation of the leaf channels may retain a pending

support-dependent reserve. Bank25 is unchanged. Further storage/eligibility
