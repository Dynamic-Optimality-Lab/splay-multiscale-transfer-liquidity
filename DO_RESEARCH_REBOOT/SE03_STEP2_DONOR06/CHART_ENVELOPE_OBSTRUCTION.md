# A chart envelope alone cannot repair the paired miss

This closes the proposed chart-envelope branch by a source-exact
counterargument. It is not a negative original CD cycle and does not
exclude a newly proved A-dependent chart correction.

Consider ANY formula that takes a pointwise minimum or maximum over
all valid physical nine-Score charts marking five of the six genuine
marks, using the accepted fixed-chart debt D or either of its completed
Hamiltonian/ray normalizations. Suppose its output is in[0,2].

before its critical K11,K1 packet, the full B tree is R11 and the A tree is

    1(F0,3(2(F1,F2),11(4(F3,E6),F11))).

critical actual A paths are RR,LL, each costing1. The original full B

The inherited proof establishes exact reachability, BOTH full-tree
closures, all original occurrences and positive full slack54 for Omega.
Those completed source rows are reused, not replayed.

At this R11 boundary, the ONLY ancestor-closed set of nine actual nodes
that contains five of the six genuine marks is precisely the first nine
R11 spine labels1,...,9. To contain mark11 it would need every one of the
eleven ancestors on its full path, already exceeding nine. Thus mark11
is omitted. The five required remaining marked nodes have a nine-node
ancestor core, leaving no free Score slot for any gap key. This argument
also covers arbitrarily populated Fi; it does not assume an empty fringe.

There is consequently ONE eligible physical chart, not several charts
whose values an extremum can compare. At that chart the inherited Omega
proof gives D>=1, and both completed normalized values equal1. Therefore

    -2 + D_target - D_source <= -1.

The universal paired inequality fails. Merely changing recent-chart
selection to min/max over all charts cannot fix it. A formula allowed to
LOWER the unique chart using new full A information is outside this
rejection, but its incoming zero/+1 rows require their OWN proof.

The counterargument uses an actual original reachable fully closed
source family. It does not promote the old chart debt to a full-source
floor, concatenate different A states, discard a signed term, or change
any existing allocator. No finite tree/population experiment is used.
