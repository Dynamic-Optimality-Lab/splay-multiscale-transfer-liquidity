# Exact remaining three-predecessor saturation

STATUS: this is the exact THREE-predecessor classification. Subsequent
F20/M20 source proofs close two of the direction-change orders, in part
using a fourth/fifth supplier. See REMAINING_EXTREME_FRAME for the current
unresolved source class. No three-window automatic coverage is assumed.

Use actual full marked B trees, not a fixed nine-Score chart. For an H1
deep two-arrival recovery e, G20 forces p and v's forms. If its p/v donor
rules do not apply, then p is H1/Q1,u0,beta1,z1 and v is
H1/Q2,u1,beta1,z1. Let G,R,C be the first three pre-deep marked ancestors.

If the B root before v is G (unary child C), its third predecessor t is
Q1,u0,beta1,z1. If H_t>=2 it supplies a fresh last bit. The only remaining
form here is H_t=1.

If the root before v is C (branching, with unary arm G->R and a longer
chain), after t the root C has TWO nonleaf children. The original root-
degree identity gives either

    Q_t=1,z_t=0;
    Q_t=2,z_t=1,u_t=0,beta_t=2.

The first case has a fresh last unit for every H_t>=1 by the strict-
surplus lemma. The second has one if H_t>=2. Only H_t=1 remains, which
is an actual H1/Q2,beta2 zero-hole macro. Its target C remains nonleaf
until the deep recovery, so its next leaf birth is that recovery's C
demand. If all relevant zero holes are selected, this is one of the two
arrivals, not another virtual debt.

Thus a direct three-predecessor source rule closes all cases except

    (a) t:H1,Q1,u0,beta1,z1; v:plateau; p:leaf Q1,
    (b) t:H1,Q2,u0,beta2,z1; v:plateau; p:leaf Q1,

with v,p as above. In either form the marked-leaf counts are3 before t,
2 after t and v,1 after p, and r-1 after the deep access. None of t,v,p
has an unassigned comparison tail at this source stage. A source rule
must reach farther or reassign through actual owners.

O20 excludes BOTH forms under G<R<C<x or its reflection, using the actual
A order barrier. The remaining saturation therefore has a direction
change among the first marked extreme choices. It is not excluded by
current proofs. No claim of global realizability for every formal order
or of a main negative funding cycle is made.

Candidate route investigated: root-degree recursion alone cannot produce
