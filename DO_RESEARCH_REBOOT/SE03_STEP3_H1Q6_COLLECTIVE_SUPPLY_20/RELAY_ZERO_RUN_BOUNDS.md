# Exact inherited bounds and new incoming-history restriction

Inherited C19 R19: a one-A-event creator has one qualified birth whose
child is the old marked root and at most one other qualifying birth.
Immediately targeting that old root has actual B Q1; it cannot be an
H1/Q2 direct-target zero frontier. A marked-parent DOUBLE watches an
outer edge whose child is not its target, so it is an explicit exception.
Delayed targets have intervening B operations and are not excluded.

Inherited C19 recovery barrier: a chronological consecutive H1/Q2,
beta2,z1 zero run has length<=r-3. More generally natural-zero runs ending
H=c have length<=r-1-2c. Proof uses exact Delta L=-1 and the last target's
at least2c new marked ancestor children. These bounds do not bound
nonchronological ownership paths, nor prove an unused A donor.

New G20 restriction: before a deep recovery, the preceding genuine macro
is Q1,u0,beta1,z1. The second predecessor is either Q1 with nonleaf target,
or Q2,u1,beta1,z1. The latter is a leaf-status PLATEAU, Delta L=0, and has
no original C15 branch hole at H1. It is different from the H1/Q2,beta2
zero-hole source that produced the transported debts.

G20 derives an actual source donor in every two-predecessor case except
H_p=H_v=1 with that Q2 plateau at v. There the marked-leaf counts are
2 before/after v,1 after p, and r-1 after the deep access. All three
macros have H1; v,p have zero own tail after source allocation and the
deep own bit is already used. Counting the B recovery still gives no
second physical credit. No source impossibility of this residual pattern
is claimed. A farther source event or licensed collective exchange remains
to be proved, including repeated/shared plateau histories.

Zero-DELETE padding proves chronological operation distance can be made
arbitrarily large without changing any of these costs/states. Thus the
two-predecessor guarded rule is a genuine-MACRO rule, not an unproved
fixed-operation-window mechanism.
