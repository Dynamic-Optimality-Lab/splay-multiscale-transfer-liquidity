## 1. Actual A order barrier

Suppose A has root C and x>C. During accesses to keys below C, the old
C.right subtree containing x is off the search path and remains attached
to C; thus C remains an ancestor of x. If a later such access targets R<C,
the new root is R and its right subtree contains C and x. A subsequent
access to G<R keeps that R.right subtree rigid. Its new root G therefore
has a path to x containing the distinct ancestors R,C. Its edge-depth to
x is at least3, so accessing x requires at least2 A StepEvs.

The same argument holds with ANY earlier accesses below C: they cannot
remove C from x's ancestor path. Whole reflection proves the reverse order.
This is an original-tree argument with arbitrary populations; it does not
depend on a quotient graph or depth-only chart predicate.

## 2. Exhaust the source predecessors

Let p,v,t be the first, second and third preceding genuine macros. G20
already supplies the donor unless H_p=1 and v has

    H_v=1,Q_v=2,u_v=1,beta_v=1,z_v=1.             (S)

Before v, its two marked ancestors are G (unary) and C (branching).
There are exactly two possible marked-tree orders:

* root C has a unary child G whose child is the leaf target R, together
  with the other marked chain; or
* root G is unary with child C, and C has the leaf R and the other chain.

In the FIRST case the previous genuine A/B root before v is C. Since
H_v=H_p=1, their only changing A accesses are R then G, including the
possible earlier DELETE of the same final target. Condition(O) and the
A order barrier force the following access to x to have H>=2, contradicting
the declared recovery H1. This case is source-impossible under(O).

In the SECOND case the previous genuine root before v is G. The preceding
macro t created that marked root with ONE child C, which has two children.
By the original root-degree identity it must have Q_t=1,z_t=1,u_t=0,
beta_t=1. Its old root before t is C, whose off-path marked children are
the leaf R and the other chain. If H_t=1, the successive changing A
accesses are G,R,G, all below C in the first order in(O). The A order
barrier again forces H_x>=2, contradiction. Thus H_t>=2 is FORCED.

The actual last bit of t is consequently unused by h_B: its own source
image has just the first2 units and it has no unary-birth arrivals.
No arbitrary donor-existence hypothesis was introduced.
