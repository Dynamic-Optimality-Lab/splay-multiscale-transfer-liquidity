certificates while preserving the distinction from the universal target.

equality, source-grammar completeness and substitution induction.

## Free-term closures: why these exclude arbitrary path length

forward_closure.json contains exact A/B term/cost cells and every marked
target's actual A/B paths. For the known T families its closure sizes
are6 (Omega),2 (Gamma),4 (Sigma), with6,1,3 affordable edges. For the
new local family's zero prefix there are5 cells/4 edges, and after the
two losses2 cells/1 edge. Reflections are separately checked.

These tables become proofs only with the following explicit source bridge:

1. A complete original full-state path maps to its ACTUAL A/B trees and
   accumulated cost c. No potential or full state is assumed to factor
   through this projection. It is used only for exclusion.
2. At every listed cell the complete cost grammar is inspected. If any
   q4 singleton, q5 pair or affordable H2/Q3 branch existed, the checker
   would record an unresolved arbitrary-helper branch and NOT certify
   completeness. All five tables have ZERO such unresolved branches.
3. Thus every affordable next packet is an H1/Q1 or H1/Q2 singleton.
   Its only positive A access targets its terminal marked key. Original
   zero DELETEs and retained-root repeats do not change A/B endpoints;
   possible changes in BE do not create a new A/B transition. Every
   marked target is inspected, with no missing anonymous positive access.
4. Each exact resulting term/cost pair is one of the table cells, with
   the displayed signed price. Every cell lacks A-one-event q4/q5 source
   geometry, so no cell can lie in F11, regardless of the recent chart.
5. Induction on arbitrary finite path length proves all actual affordable
   paths stay inside the table. Structural substitution proves the same
   for arbitrary Fi and thus arbitrary passive private populations.

This is a finite list of SOURCE TERM IDENTITIES plus an exhaustive action
grammar and inductive invariant, not a finite BST population sample or
bounded path-length search promoted to a theorem. It proves only the
declared parameterized starting families, not arbitrary T11. Complete
BE/recent states remain necessary for positive witness composition;
discarding them for this exclusion only admits additional possibilities.

The closure tables also test +1 positions before/after zero operations
in the known families, a neutral continuation between losses in the
new family (which reaches a zero sink), and loss/restoration repetition
(also a sink). They do not provide a general alternating-cycle theorem.
