# RG35 — claim-bound reservations and exact chart compatibility

## Frozen normal form and exact target

Fix original actual F,E,U,I and a legitimate current frozen a0. Let Gamma_F
be any additional already-certified literal full-claim bindings d->u,
d in F, whose union a+=a0 union Gamma_F is a consistent injection. These
may reserve a currently unpaid full claim; they need not be called a paid
claim in the historical a0 file. Let Gamma_N be auxiliary-only reservations
whose ACTUAL claims lie in N=E minus F, with the original alternative-ledger
retirement permission. Keep the supplied fE, common values and all later
successful full pairs literally. Natural h0 is the original independent
comparison reservation, not an incompatible second physical value.

Assume a complete independently SOURCE-licensed h:F->U containing h0 has
already been supplied on the SAME I, with its original Bank25 trace.
No source donor existence is assumed as a conclusion of this theorem.

Conclusion: all claim-bound reservations and actual chart corrections
compose with that source comparison, without another donor-supply theorem.

## Constructive proof

Use a+ as the immutable partial owner map in the ORIGINAL complete
h/inverse-owner exchange. Start only at F minus dom(a+). Every h step is
defined; unique incoming edges exclude entered cycles and merged roots,
so each root reaches a distinct unit outside im(a+). Append ONLY those
root-to-terminal pairs. This covers all F, including demands reserved by
Gamma_F, and keeps every old a0 and Gamma_F pair exact. Promoting a known
binding to a+ is proof bookkeeping; it does not edit the actual a0 input
or assume an unprovided full assignment for other demands.

If a terminal is h0(q), complete h containing h0 forces q to be the last
demand on that root path. It is either that root, or an already owned
interior demand. Thus no different unpaid natural claim loses its reserved
unit. This is the inherited natural-reservation safety proof, now applied
also to additional claim-bound reservations.

Common fE values lie in a0 and never move. Gamma_N units are freed only
in the alternative FULL ledger under their literal N retirement receipts;
the archived auxiliary allocation is unchanged. Simultaneously paying
F and every E-only claim as two disjoint bills is NOT required by the
original contract. A refined gE protection is not a fixed-fE exclusion.

At each actual occurrence define c=min(qF,qE), p=(qF-qE)_+,
n=(qE-qF)_+. Then qF-qE=p-n, and the first c ordinals are exactly common.
The full h/exchange funds ALL literal full ordinals, including erased-key,
cold-change, repeated and persistent-disagreement cases. No changing-chart
potential is used or telescoped. Hence chart changes create no new unpaid
ordinal outside F and no unsigned correction that has been dropped.

Use the original simultaneous occurrence bijection on BOTH endpoints.
The supplied fE/Step1 cut stays fixed; an internal full-comparison cut is
only a coordinate construction. All physical units are in ONE actual I.
The original unassigned bank trace of independent h is unchanged: owner
bindings and path records are assigned proof data, not extra idle buffers.
Thus Bank25 remains valid at the inherited interface. QED.

## Precise unresolved reservation scope

This theorem DOES NOT release an independently live Gamma restriction
which is neither a full-claim binding nor a licensed auxiliary-only
retirement. Such a restriction needs its actual source rule, identity,
release event and period permission. Saying a unit is outside im(a0)
does not supply that license. No arbitrary untyped set of permanently
forbidden bits is added to the original theorem either.

The original C14 ledger has the exact partition

    U = im(fE|C) disjoint_union (U minus im(fE)) disjoint_union fE(N).

Its normalized f6/common owners and later fixed full assignments are
claim-bound. The original Gamma26 two-bit repair is an actual pair of
full-demand bindings with its certified same-period cut proof. These
contracts are covered. Later C33/C34 manuscripts explicitly retain possible
additional unretired Gamma restrictions; no exhaustive general schema for
such a ledger was found in the inspected authorities. Their scope is kept
as an explicit normalization/permission obligation, not silently declared
empty and not represented by fabricated reservations in a new raw source.

Thus CHART35 and CLAIM_BOUND_GAMMA35 close conditionally on full source h.
The stronger statement 'every legitimate additional Gamma is in this
normal form or has a proved discharge' is NOT established by this proof.
