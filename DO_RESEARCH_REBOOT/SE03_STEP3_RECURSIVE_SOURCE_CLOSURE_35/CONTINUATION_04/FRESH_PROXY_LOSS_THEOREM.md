# FP35 — source-exact recent proxies for every original B double

Status: uniform mathematical derivation, without a collective mixed-
target allocation or a full Bank25 license. JR35 remains OPEN.

## Frozen IAGS Box

Target: independently derive nonempty original physical donor
candidates for every actual B double at arbitrary support and core,
with exact within-macro and repeated-target noncollision.
Conditions: original reachable exactly paired-closed source; genuine
full natural macros; all original A operations and event bits.
Inheritance: C14 source/period transport, original bottom-up rotations,
the set-growth lemma in CLOSED_CORE_SUBTREE_DENSITY.md.
Ambiguity: same A loss may remove several DIFFERENT targets. Such
collisions require simultaneous repayment and ownership licensing.
Bridge: tag first entry into a target-relative growing marked core;
pair the two original ancestors of each B double; orient a degree-two
tag graph; identify the actual loss of that proxy's A ancestry.

## 1. Fresh core tags, without assuming a closed intermediate subtree

Fix an actual genuine KEEP x. Work along the original cyclic interval
after the preceding genuine KEEP of the SAME x and before this one.
Both copies of the boundary denote actual occurrence identities on
the fixed period; if x occurs once, the interval is the rest of that
one period. The previous access leaves B root x. Start V={x}, whose
ancestor core consists only of x.

Add each newly seen genuine B target y to V at its first visit in
this interval. A DELETE leaves B unchanged. A root-repeat KEEP
does not change B or introduce a new root key. If a target is
already in V, the V-core cannot grow. At a first y visit the
inherited set-growth lemma allows at most TWO new physical
labels in the new core, among {y,p}. Here p is the first node
below the old core on the original target path, when needed.
The adjunction of y itself adds nothing further: y is now root
and already in the nonempty core of the old V.

For each non-x physical vertex, tag its FIRST ENTRY into this
growing-target core by that actual first-visit occurrence y.
The underlying core may shrink and later regain a label. Do
not count a second birth for that same label. Each tag is a
different marked key and accounts for at most two vertices.
This uses the SET-GROWTH lemma on the actual whole B execution,
not closed-subtree density transplanted into a moving subtree.

Immediately before KEEP x, every vertex on its original B path
belongs to the current core, since x is still in V. Every proper
ancestor on that path has a tag, because initially only x was
in the core. All tags are actual genuine KEEPs strictly between
the two x occurrences.

## 2. Distinct proxies within one natural macro

In an original bottom-up B splay, each double consumes a pair
of original proper path ancestors. The pairs are disjoint, for
all LL/LR/RL/RR, and a possible terminal zig is not a demand.
No artificial B packet is introduced. Form a multigraph on the
tags of these ancestors, with one edge for each original double
joining its two operand tags. Count a loop twice in the degree.
Since a tag occurs on at most two actual path vertices, this
graph has maximum degree two. Every component is a path, a cycle
(including a two-edge parallel cycle), or a loop.

Orient each path from either endpoint, each cycle cyclically,
and a loop at its vertex. Assign a double to its head tag.
This is injective: each head has indegree at most one. The
choice can be fixed by source occurrence/ordinal order and is
independent of any desired physical matching. This is more
than a bound on the total number of recent keys; it gives a
different original marked proxy y for each double.

Use the last actual genuine KEEP y after the previous x and
before the current x; it exists by the tag. At its end A root
is y, so y is an ancestor of x. At the end of the A part of
KEEP x, A root is x. The relation y->x has therefore been lost
at some actual A single rotation in this interval. A rotation
can shrink only its demoted pivot's descendant set. Its pivot
must be y. The theorem includes a zero-event final KEEP when
earlier actual helper events already reached root x.

Select one such loss by a fixed first/last source rule. Its
rotation bit is a real original (t,j,b). The distinct chosen
proxies have distinct pivots, so the selected bits within the
macro are distinct. This constructs an individual-macro
injection even if every local bit of that macro is already owned.
It does not show that any particular selected bit is free.

## 3. Repeated target and private population lifting

For a FIXED target x, the cyclic intervals between successive
genuine x KEEPs partition the original occurrence period.
The selected loss events for each such macro lie strictly after
its preceding x. Across different macros with that same target,
these donor intervals are disjoint. Combined with the preceding
within-macro argument, all original B doubles aimed at a fixed
key x admit one simultaneous injective map to original A bits.
There is no assumption that different target maps are disjoint.

If two different-target demands choose the same rotation bit,
they use the same actual marked pivot y, the same y tenure
(most recent actual genuine KEEP y), and distinct x values in
that rotation's one-sided lost descendant interval. All these
statements refer to one actual period's bit IDs. A wrap denotes
a cyclic interval of those IDs, never a second inventory.
No assumption of monotone order for arbitrary off-path proxy
collisions is made. MD35's stronger monotonicity needs an
actual marked B grandparent in the maximal-core source class.

Only exact original rotation effects and the whole-source
set-growth lemma are used. Anonymous A ancestors, positive
DELETE helpers, arbitrary rigid private BSTs, all B cores,
changing charts, both orientations and arbitrary finite support
are retained. The proof never computes a splay cost in a
contracted shadow. A private ancestor can be the promoted
operand in a loss rotation, and its actual event stays present.

## 4. The remaining collective theorem

Allow for each double either operand's source tag (or the
deterministic degree-two choice above), every actual loss
rotation allowed by that tag's tenure, and the existing legal
own-macro units. Candidate bits retain their physical identities.
This relation is derived without assuming matching feasibility.
The root proof still needs a simultaneous injection or licensed
exchange, not just an individual-macro or individual-target map.

An exact remaining Box is MIXED-TARGET LOSS ESCAPE:
given an arbitrary set of different-target claims whose eligible
loss bits overlap, use the actual splay source to exhibit distinct
unowned endpoints or a licensed nonlocal exchange. Establish
noncollision across repeated use of a proxy and across the whole
original period. If the specific fresh-proxy relation fails on
an original paired-closed source, preserve its exact cut and
seek a larger independently source-derived rule. Such a cut
does not by itself refute JR35 or Coarse-Double.

The inherited all-loss relation in maximal cores (MD35) is a
complementary candidate, not an assumed universal solution.
Proof of source eligibility/ownership and Bank25 must be supplied
separately from a successful matching. Old h0/fE and allocations
are unchanged; reservation compatibility remains DEFERRED.
