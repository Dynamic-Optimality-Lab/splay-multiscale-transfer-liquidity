# JC35 — source-uniform joint cluster geometry

Target: a new sufficient signed source law which retains joint A/B
geometry rather than only values of inherited smaller-source debts.
Original JR35 and all physical owner requirements remain unchanged.

Definitions: for each actual marked-descendant interval I, let l_A(I)
be the depth of the LCA of its marks in A's branch quotient, and l_B(I)
the same in the actual fixed B core. Keep marked and anonymous-brancher
A clusters separately, and marked/unmarked B clusters with multiplicity.
An interval is represented by its actual ordered marked-label set.
Private populations do not enter these functions. They do enter the
actual H, which is never replaced by quotient rotation cost.

Candidate architecture: a real linear combination of the joint LCA
depth sums, the four marked/unmarked cluster intersection counts, total
cluster intersection, marked depth sums, anonymous brancher count, and
marked leaf counts. The exact feature list is machine-pinned before
construction. No fitted coefficient is declared a theorem by finite
agreement. A passing candidate must be proved on the uniform original
source grammar, including HIGH, arbitrary r, helpers and period license.

Inheritance: complete maximal seven-key LOW frames and literal realized
q6/q1 pairs. Every chosen inequality has an independently source-realizable
edge, not a freely composable quotient path. The cluster work lemma
already bounds lost/new SET clusters by actual single rotations, while
this candidate also retains where intervals lie in the other tree.

Ambiguity: aggregate work alone does not assign distinct eligible donors.
No owner/Bank25 conclusion follows from feature values or a fit.

Bridge for refutation: if nonnegative RATIONAL multipliers of actual
source inequalities cancel every feature difference but have negative
total price, no real coefficient vector in this entire architecture can
work. This is an exact algebraic countercertificate to a sufficient proof
route; it is NOT a negative source cycle or a refutation of JR35.

Bridge for success: derive the fitted formula symbolically on every
original frame at arbitrary support, then construct the actual licensed
physical assignment, preserve h0, original periods and Bank25. Without
that bridge the root remains open.
