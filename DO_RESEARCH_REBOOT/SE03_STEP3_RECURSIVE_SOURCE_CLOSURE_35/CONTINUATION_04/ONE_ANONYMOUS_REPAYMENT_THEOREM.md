# AR35-1 — complete maximal-core seven-key funding with one active anonymous A node

## Exact statement

Let W be an original reachable exactly paired-closed period with seven
genuine KEEP keys, maximal full-B marked ancestor core of size thirteen,
and at most one distinct unmarked A rotation operand or positive-cost
target during the period. Then there is an original physical full-B
comparison containing the natural h0 allocation, with no duplicated actual
A-event bit, and with working bound fourteen under the inherited source
Type-B bank convention. The word length, number of repeated/shared
recoveries and untouched private BST populations are unrestricted.

This is a restricted source theorem. It is NOT universal JR35, CD(7), or
the all-core seven-key theorem. Reservation compatibility is deferred.

## Independently checked signed law

At synchronized genuine boundaries let D(A,B) be the completed potential
in the corresponding pinned active_a8_g*_02.pkl certificate. All four
gaps have 0<=D<=4. For every genuine B edge of cost q and every possible
source A helper word from synchronized A state s to t,

    2H-q+D(t,B')-D(s,B) >= 0.

The independent checks are independent_active_a8_g0.json through g3.json.
They do not replay the producer's Dijkstra heap. They enumerate all
eight-anchor shapes independently and verify every bounded Bellman path
of up to four positive operations, using the accepted exact A and B
action receipts. A macro with H<5 contains at most four positive source
operations, so it is included. All zero-cost repeats remain harmless
identities. A macro with H>=5 instead satisfies

    2*5-q+D(t)-D(s) >= 10-6-4 = 0.

Therefore the actual natural macro law is uniformly

    2c-q+Delta D >= 0,    c=min(H,5).

Nongenuine KEEP operations inside the macro retain their actual A cost
and have q=0 in full B. The shortest-helper comparison is only a lower
bound on the ACTUAL H; no source operation is removed from W. Original
identities and full/erased provenance are not conflated.

## Constructive physical allocation and Bank25

For each natural macro take the first c ACTUAL A StepEv events, hence
2c named physical units (t,j,b), in their source order. The natural h0
owner units are included: if H<=5 every event is selected, and if H>5
there are ten selected units while q<=6. Assign the first min(q,2H)
demands to their prescribed own-macro h0 units before using old bank bits.

Rotate the full comparison's internal cycle cut to a boundary maximizing
D, with maximum K<=4. Start with an empty bank. At boundary s maintain
exactly K-D(s) distinct unspent selected physical bits. This holds at the
starting boundary. In the next macro there are at least

    K-D(s)+2c-q >= K-D(t)

bits after paying all q demands. First preserve h0. Pay any remaining
demands using distinct earlier bank bits, then retain exactly K-D(t)
unused bits, discarding excess capacity. This is possible by the displayed
inequality. No discarded bit is reclaimed later. Immediately before
payment the working inventory has at most K+2c<=4+10=14 physical units.
At the end D returns to K and the bank is empty. Thus there is no initial
credit, cyclic-copy borrowing or implicit debt unit.

Transport BOTH endpoints of every assigned pair back to the inherited
one-period source indexing. The original Step1 cut is not changed by the
internal construction. All units and demands are absolute original
occurrences, and the return transport is a bijection, so no owner can be
duplicated by describing the same event at a different cut. The inherited
full-comparison-then-exchange theorem, at its exact stated interface,
preserves prior frozen auxiliary owners; it is not a proof that arbitrary
additional live Gamma reservations are compatible.

This completes the restricted physical comparison theorem. Independent
checking here means a distinct implementation operated by the same

## What remains

No bound of one active anonymous A node was proved for an arbitrary
source. Neither smaller B cores nor larger genuine supports are reduced
to this class. Consequently this theorem cannot reconstruct universal
Joint Repayment or UCF35. The next computational falsification class has
two active anonymous A nodes; the missing universal bridge must still
handle unbounded operand sets and supports by source reasoning.
