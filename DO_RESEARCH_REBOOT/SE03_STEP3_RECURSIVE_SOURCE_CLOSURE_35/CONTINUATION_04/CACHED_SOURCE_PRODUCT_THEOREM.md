# CP35 — source-exact composition of certified action caches

## Conditions

Let K be a fixed ordered native A anchor set. A previously certified action
table gives, for EVERY retained tree/index and accessed anchor, the exact
ordinary bottom-up destination and actual H=ceil(depth/2). No fresh source
action is evaluated in this construction. Let G_B contain only exact
full-B transitions from previously independently checked original source
rows, with literal before/after full trees, KEEP target and actual q.
Reflected edges are permitted only by the inherited exact reflection
theorem. Every full B tree has the same original physical key set P.

Choose an order embedding of K into P containing every genuine B target.
The extra physical keys P minus K are unaccessed in A and are put in
the corresponding external gaps as rigid leaf/tree terms. Different
retained anchors outside the accessed A subset are likewise rigid leaves.
Every initial native tree and all retained A transitions must satisfy
that rigid-leaf condition. No active anonymous node is contracted.

## Exact rigid-gap lifting

A search for an anchor never enters an external gap subtree. All ordinary
rotations therefore have the same native operands; every gap term is
reattached whole at its ordered port. Induction gives the EXACT full A
operation and H for every native table lookup. No omitted key is physically
deleted. If the native tree returns, the reconstructed full tree with the
SAME gap assignments returns too. The statement holds for arbitrary finite
rigid gap BSTs, not just empty gaps or one chosen population.

## Product system

Vertices are pairs (native A state, original full B cache tree). A DELETE
of an allowed A anchor uses its certified native destination, leaves B
fixed, and has weight2H. A KEEP of a genuine key uses a cached B edge and
that same anchor's certified A destination, with weight2H-q. No freely
chosen B successor or projected B state is introduced.

Every product path lifts operation-by-operation to the ORIGINAL Pair
Access model on P. Incoming B endpoints must match literally. All event
costs are taken from accepted cache entries, and full A costs are equal
by the rigid-gap proof. Identities, helper accesses and all bits remain.
A closed product walk gives EXACT full A/B closure, using each occurrence
once. This is a source-realization bridge, not abstract reachability.

Reachability: from the common diagonal equal to the initial B tree, the
accepted ordinary-splay transformation theorem on |P|>=4 supplies a finite
A-only word to the reconstructed A tree. Its cost is outside the chosen
closed period and is NOT used as a donor there. Thus the pair is genuinely
reachable. Erased-B and recent charts can be aligned by their actual
eventual recurrence; a negative whole-word weight stays negative on every
positive multiplier. No prefix or neighboring-copy credit is borrowed.

## What a negative cycle establishes

An actual negative product cycle has sum(2H-q)=2A-Q<0. Its one-period U
contains2A physical units and F has Q demands, so NO physical injection
exists, under ANY proposed source allocation. This would refute JR35.
For the requested support>=7 the final source must genuinely visit those
keys. If necessary a supplied closed B-cache walk visiting all seven can
be appended, followed by a native A-only return word from the complete
certified cache. Repeating the negative core enough times outweighs this
finite bridge cost. Every such operation and endpoint must be certified
before any counterexample verdict. An incomplete negative path is not it.

## What nonnegative closure does not establish

No negative cycle in a chosen finite cache product certifies only that
exact product class and its proved rigid-gap lifting. It is NOT a proof
for arbitrary active anonymous nodes, unseen B transitions, every support,
or JR35. The source-query limit is not bypassed: cache lookups, product
edge examinations and fresh original source-engine calls are recorded
separately. Fresh source-engine calls here are0, not hidden in a renamed
