# CF35 — uniform local-frame lifting from already certified actions

## Box and exact role

**Target.** Reuse a verified H1 ordinary splay as a symbolic local-frame
identity on arbitrary hanging BSTs, including hangers containing other
global marked keys. Then generate the COMPLETE seven-mark H1 relation
on the unmarked-unary-contracted A branch quotient.

**Conditions.** The accessed key is marked. The actual starting A root is
the preceding marked genuine key. The original natural macro has H=1.
All actual operations, including every zero-event operation, are retained.
The endpoint quotient prunes only mark-free subtrees and contracts only
unmarked unary vertices, retaining all unmarked branchers.

**Inheritance.** C14 FULL_PROOF sections2–3 (support-free branching and
off-operand unary-frame lemmas), C35 OR35 one-event normal form, the
independently accepted native-ten source actions and their exact free-gap
semantics. No credit sign is inherited for seven marks.

**Ambiguities.** Forgetting unary contexts can create abstract paths not
realizable by one closed original source. A negative quotient cycle only
refutes this sufficient potential route until a full source lift is proved.
No H2 or larger macro is characterized by this H1 lemma.

**Bridge.** Every actual H1 macro is one of the six exact root-local
identities below with arbitrary ordered hanging terms. Therefore its
branch-projected endpoints occur in the generated relation, independent
of private populations or the number of inactive unary ancestors.

## 1. Rigid filler generalization of a certified source action

A depth-one access has two active path nodes and three hanging ports.
A depth-two access has three active path nodes and four hanging ports.
Their order is determined by the two/three active keys. A hanger may
contain any number of OTHER global marked keys; it is not entered during
this access. The ordinary rotation identity never reads its interior.

Choose native keys1..k for the k active operands, k=2 or3. Put the remaining
native keys k+1..10 into one rigid right-vine subtree at the rightmost
external port. The accepted native-ten table contains this exact tree and
the accessed active key. Its verified H is1. The filler subtree is entered
by neither search nor rotation and remains an identical rigid term in the
certified destination. Replace that ENTIRE filler subtree, in both trees,
by a formal ordered port variable. Replace the other external native free
ports by the other formal variables. This is valid by induction through
the one actual event: every changed pointer belongs to the active nodes,
and every port term is reattached whole.

Consequently the resulting symbolic identity is valid for arbitrary
ordered port substitutions, including empty trees and mark-containing
trees. It is not a claim that physically deleting an active ancestor
commutes with splaying. No active path operand is removed. Treating an
unaccessed filler as one variable is exactly the proved rigid-hanger rule.

There are two zig orientations and four double orientations. Their cache
indices, target ranks, H and symbolic outputs are recorded before use.
Every subsequent generated edge is a TERM SUBSTITUTION in one of these
already certified identities, not a call evaluating a new original splay
state. Fresh source-engine calls/queries are zero; symbolic substitutions
and relation rows are counted separately and consume symbolic CPU. A
verifier must check the source-cache pins and the six identities, rather
than silently running uncharged new source traces.

## 2. Complete branch boundary grammar (all supports)

For r genuine marks, prune mark-free hangers and contract all unmarked
unary core vertices. All surviving unmarked vertices branch to two
nonempty marked intervals. They occupy distinct adjacent-mark gaps.
There are at most r-2, since the whole root is marked. This is the same
binary branching proof as C14, with6 replaced by r; no numerical source
check is used to generalize that proof.

Let T_0=1 count an arbitrary reduced interval, allowing an unmarked root.
For n>=1,

 T_n = sum(i=0..n-1) T_i T_(n-1-i)
       + sum(i=1..n-1) T_i T_(n-i).

The first sum chooses a marked root and its two mark intervals; the second
chooses an unmarked cut with both intervals nonempty. With a marked whole
root R_n is the first sum. Unique inorder labels and the two recursive
subtrees give a unique parse. In particular R_6=974 (accepted old grammar)
and R_7=5947. This does NOT bound the original unary chains or populations.

## 3. Complete H1 source lift

OR35 proves the only positive access is the final marked target x, at
actual depth1 or2. All inactive source unary vertices lie outside that
full path and inside rigid hangers at this event. C14's support-free
off-operand lemma permits contracting exactly those vertices, leaving
the same branch-projected endpoints and exact event count.

If the reduced x depth is2, its two ancestors are already retained and
the H1 identity applies directly. If the reduced depth is1, either there
is no active unary or exactly one old unmarked unary is inserted on this
edge, with its sole marked-carrying child on either side. Its key lies
below the entire child interval or above it, subject to the parent bounds.
These are all order sectors; all other hanging terms are arbitrary.
If the reduced depth is greater than2 the original depth cannot be1/2.

After the exact template substitution, reduce at the DESTINATION, not
before the event: a previous brancher may become unary and an inserted
unary may become a brancher. The result belongs to the same branch grammar.
Thus every actual H1 macro occurs in this necessary relation, for arbitrary
anonymous A populations, both orientations and original root repeats.

This is a uniform source COVERAGE theorem. It does not make paths of
quotient edges source-realizable when contracted contexts change.
