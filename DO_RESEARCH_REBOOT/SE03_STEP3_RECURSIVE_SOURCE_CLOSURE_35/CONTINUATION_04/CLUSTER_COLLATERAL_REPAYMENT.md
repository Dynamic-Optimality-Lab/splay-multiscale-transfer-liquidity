# CCR35 — physical collateral from marked-cluster changes

Status: new universal source derivation; independent interface audit pending.
It is a sufficient block repayment theorem, NOT universal Joint Repayment.

## Box

**Target.** Fund a disjoint source block consisting of a recovery natural
macro R followed by natural macros e1,...,em. Let d_i=max(Q_i-2H_i,0)
be their missing natural h0 demands, L=sum d_i. Suppose

 delta_R=max(|J(start R) minus J(end R)|,
             |J(end R) minus J(start R)|) >= Q_R+L.

Then construct L DISTINCT actual source bits in R, unused by natural h0,
and fund every later missing demand. The construction is uniform in
support, populations, helper work, repeats and source charts. For L<=23
the direct carry working bound is L+2<=25. Arbitrarily many DISJOINT
such blocks compose; no bound is placed on their number.

**Inheritance.** MC35 source cluster theorem; original rotation/StepEv bit
ordering; natural h0; original complete-comparison-then-exchange and
absolute-period transport at their actual accepted interfaces.

**Ambiguity.** No theorem yet partitions EVERY source into such blocks or
proves this cluster inequality for arbitrary recoveries. Shared or
overlapping recovery intervals cannot be counted twice. This child does
not discharge the parent just by restating a cardinality condition.

**Bridge.** The STRUCTURAL endpoint condition forces named source-event
donors via the one-cluster-per-rotation identity, independently of any
desired B injection. The allocation below then uses those physical units.

## Actual donor rule and proof

Fix the axis with at least delta_R endpoint changes: losses if loss count
is at least gain count, otherwise gains. For each selected endpoint
cluster C, define tau_C to be the FIRST actual single rotation in R that
removes C from J (loss axis), or first introduces C into J (gain axis).
The defining event exists by the actual endpoint values. A rotation can
remove at most one member of J and introduce at most one, by MC35.
Because one axis is fixed for this entire R, distinct C have DISTINCT
tau_C. Do not count both a birth and a death of one rotation as two bits.

If tau_C is the first/second rotation of an actual double StepEv (t,j),
use bit (t,j,0)/(t,j,1), respectively. A zig uses bit0. These are distinct
ACTUAL A-event units. The unused second bit of a zig is never fabricated
as an extra rotation witness. No abstract positive packet price is a bit.

There are at least delta_R such distinct units. Since R's actual
2H_R>=delta_R>=Q_R+L, its natural h0 pays all Q_R demands using exactly
Q_R actual units. Filter those h0 units out of the witness list. At most
Q_R witnesses are removed, leaving at least L original units. Choose the
first L remaining witness units in actual source order, breaking any
irrelevant ties by cluster interval order. This is an independently
defined source-event rule, not an assumption that a matching exists.

Order all subsequent missing demands by actual source occurrence and
double index. Assign the kth missing demand the kth chosen witness bit.
Keep every h0 value literal. All missing demands are paid; no donor is
reused. The rule never imports an auxiliary protected unit as already
free: this is the independent full h construction, followed only later
by the previously proved owner exchange on its exact interface. Extra
unclassified live Gamma reservations are still the deferred problem.

## Source bank and period

Inside R retain only the selected L witness bits. Every actual StepEv
admits two named units; own h0 assignments remain fixed and all other
unused capacity is released. Current event plus carry uses at most L+2
units. Each subsequent macro funds its own h0 demands from its actual
events and consumes exactly d_i chosen bits. The bank is empty at the
block exit. For L<=23 this is a direct Bank25 trace, independently of the
number of source events or of blocks. Larger L needs the inherited static
source-block emission license; no new such license is asserted here.

For a disjoint cyclic block partition choose an actual block boundary,
process every original occurrence once, then transport BOTH endpoints to
the fixed Step1 period. Distinct blocks have disjoint actual occurrence
intervals, hence disjoint witnesses even when cluster names repeat.
Overlapping descriptions are NOT extra periods or extra donors. Both
orientations follow by the literal order-reversal bijection on all keys,
pointers and access targets; H, event ordinals and interval cardinalities
are preserved. Original root-repeat and zero-A KEEP operations stay in
their source macros; a positive DELETE may supply a bit later owned by
a zero-A terminal KEEP, exactly as the original semantics requires.
