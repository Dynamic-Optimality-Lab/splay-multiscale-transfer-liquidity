## 2. Counts, slots and the already reserved zig

For EACH original occurrence t let B_{i,t} count its original B doubles
with total Psi decrease i, i=0,1,2. Let Z_t count its decreasing terminal
B zig (0 or 1). On DELETE/root-repeat these B counts are zero. Define

    q_t = B_{0,t}+B_{1,t}+B_{2,t},
    ell_t = 1 if (t,q_t) is a neutral last double, otherwise 0.

ND35 reserves the FIRST decrease of every B1/B2 double as its payment
slot. Denote these slots P_t. Denote by E_t the SECOND decrease of
every B2 double and every decreasing terminal B zig. Then

    |P_t|=B_{1,t}+B_{2,t},   |E_t|=B_{2,t}+Z_t.

All these actual slots are distinct, across and within accesses.
ND35 already assigns each nonneutral demand to lambda(its payment slot).
For ell_t=1, ZRC35 reserves the actual terminal-zig slot z_t in E_t
and assigns (t,q_t) to lambda(z_t). In particular

    ell_t <= B_{0,t},   ell_t <= Z_t <= B_{2,t}+Z_t.

This is the only terminal reservation made by ZRC35.

## 5. Exact per-access residual and maximality in this inventory

Write b=B_{0,t}, r=B_{2,t}+Z_t, ell=ell_t. Since ell<=min(b,r),

    ell+m_t = ell+min(b-ell,r-ell) = min(b,r).

Hence the number of still-unfunded original neutral demands is

    d_t = (b-ell)-m_t = b-min(b,r)
        = max(0,B_{0,t}-B_{2,t}-Z_t).

All remaining demands are strictly internal. The unused release count is

    s_t = r-min(b,r) = max(0,B_{2,t}+Z_t-B_{0,t}).

If d_t>0, all allowed release slots of that access are used. If s_t>0,
all its neutral demands are paid. Thus no construction preserving g_Z
and restricted to these same-access release bits can fund more here.
This is maximality ONLY for this frozen inventory, not a global theorem.
