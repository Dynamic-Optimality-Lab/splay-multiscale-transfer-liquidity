## Uniform owner algebra (inherited; proof recalled)

Fix finite actual demand and unit sets F,U. Suppose a0:D0->U is the
legitimate frozen injection, and an independently source-licensed complete
h:F->U has been supplied, with the original source/reservation/path and
period compatibility. For p in F minus D0, follow

    p --h--> unit --inverse(a0), if defined--> owner --h--> ... .

Each visited demand has a defined h value. An entered directed cycle is
impossible: injectivity gives each demand at most one incoming edge, so
an outside root cannot enter a cycle; the unpaid root itself has no
incoming inverse(a0) edge. Finiteness therefore forces a unit outside
im(a0). Distinct unpaid roots cannot meet, again by unique incoming
edges. Append only each root's final free unit, retaining EVERY a0 value
literally. This is a complete injection. No displaced comparison edge
is called an actual owner's reassignment. QED.

Natural h0 belongs to the independent comparison normalization. The
physical owner map after the original common exchange need not equal h0
on a demand whose supplied common owner differs. Preserve the ORIGINAL
normalization/exchange contract, not an invented requirement to make two
conflicting values simultaneously literal.

This proves: given a compatible complete comparison, there is no separate
finite owner-path endpoint-existence obstruction. A blocked path in a
PARTIAL h only identifies a demand where h is missing. It is not evidence
that the complete original route is infeasible.

## Reservation qualification

The argument does not retire extra Gamma reservations by algebra. Its h
and terminal paths must obey the ORIGINAL licenses: common ordinal IDs,
E-only retirement in the alternative ledger, all still-protected extra
reservations, actual source block and signed chart conditions, and both
endpoints on I. A path unit outside im(a0) can still be reserved. There is
no new universal claim that every source-generated h is compatible with
every apparently injective raw owner map.

    E_r1 holds and there exists c in C(W,I) with chi(c,fE,a0,Gamma).
