# B-only cycle compensation investigation

**B — PARTIAL.** A source-uniform compensation theorem is proved for
the guarded aligned bundles defined below. Its free bits and their
distinctness follow from actual source events, without a complete h.
It explains seven of CCR's nine cycle-associated residuals through
entry-event geometry. CCR's remaining two have fully occupied entry
events and retain their existing nonlocal ownership-relay certificates.
Compensation for arbitrary collections of B-only cycles remains OPEN.

## Frozen source and R1–R4

The target is the original residual set F(W), with the unchanged raw
Step 1 map g1, on ONE original reachable finite A/full-B paired-closed
period. A credit is an actual (t,j,b). Missing-label cycles, interval
names, repeated tree shapes and repeated copies are not extra credits.
All historical source operations, helpers, owners and certificates stay
literal. No new potential, source query, replay, experiment or source
search is performed.

The principal smaller target is a GUARDED ALIGNED BUNDLE: actual
single-winding B-only cycles with a common sequence of transfer-access
occurrences, at most one distinct associated residual demand at each
such access, and a first-entry A event having a literal source-geometry
certificate for a zero rotation or an actual terminal zig. These are
declared restrictions, not properties assumed of every closed source.

R1: only this common-cadence source class is claimed; arbitrary cycle
sharing and saturated entry events remain outside the child theorem.
R2: first root entry is forced by consecutive B-transfer labels; a
literal zero-rotation/zig certificate identifies a free original bit.
Distinct event identities follow from consecutive actual source gaps.
R3: one existing root-entry/event-bit mechanism, cached CCR evidence,
and a symbolic construction. No new donor system or full comparison
is assumed.
R4: success funds the class without an independently complete h or
unknown augmentation endpoints. It does not prove that an arbitrary
cycle collection has this cadence or satisfies the local geometry guard.
Those missing implications will not be renamed as an achieved theorem.

## 4. Restricted source-uniform compensation theorem

This is a new derivation using ONLY the existing root-entry/event-bit
mechanism. No complete comparison, global capacity bound or free
augmentation endpoint is an input.

### Exact source class: guarded aligned bundles

Fix an actual collection C of one or more directed B-only components
of an original period W. Require:

1. Each component winds ONCE around the original time seam. Its transfer
   order is the actual cyclic order, with no duplicate period.
2. There is a common cyclic sequence of DISTINCT original B access
   occurrences tau_1,...,tau_m, m>=2. EVERY component in the bundle has
   one transfer at each tau_i and no other transfer. This is a restriction
   on actual occurrence histories, not a presumed source decomposition.
3. At each tau_i, all bundle ports that belong to F(W), if any, belong
   to ONE distinct residual double d_i. Already paid B1 or release-paid
   demands create no new obligation. A double touched by several cycle
   ports is counted once.
4. For that residual choose the first of its bundle ports in original
   rotation order. Let I_i be its removed label. Let beta_i be the FIRST
   actual A global-root entry into I_i after the bundle's previous B
   access tau_(i-1), and let E_i be its original A StepEv. This witness
   must satisfy the literal geometry guard below.

The guard is a source-state predicate, not assumed donor availability:

* Either E_i is an actual terminal A zig; or
* at least one actual rotation of E_i has its old promoted-child
  S-label K and new demoted-pivot S-label J BOTH absent from J_S(B)
  at that original event.

Empty labels count as absent from the nonempty B-label family. The
physical A trees, SET duplicates and B state are the actual ones.
No private population or support bound is imposed. A first-entry event
with two positive rotations need not pass this guard.

### Theorem and explicit rule

Every guarded aligned bundle admits a simultaneous RAW extension of g1
covering ALL residual demands associated with its cycles. For each
distinct residual d_i:

* If some actual rotation of E_i satisfies the two-absent-label guard,
  take its smallest original bit index b and use (t_i,j_i,b).
* Otherwise E_i is a terminal zig; use its virtual second unit
  (t_i,j_i,1).

All original g1 values remain literal. Each new donor is an actual
within-period unit and is used at most once. There is no assumption
that different cycles have independent preparations.

### Symbolic proof

Existence of beta_i: after the PREVIOUS transfer of the selected cycle,
its new label I_i is missing and excludes that access's target. A's
root is that target and hence outside I_i. The label persists on this
cycle until its next transfer at tau_i. Immediately before that transfer,
A has processed tau_i and its root lies in I_i. Only A rotations change
the A root. Therefore a first root entry exists in the original gap.
Other helpers, KEEPs and zero-event operations in the gap remain literal.

Freedom of the selected bit: an A rotation can change J_S(A) only by
losing K and gaining J, with SET duplicates possibly suppressing either
change. If neither K nor J is a B label, the whole missing-label set
M is unchanged, so the selected actual rotation has DeltaPsi=0. The
Step 1 image consists only of positive A-rotation bits. The selected
zero bit is therefore outside image(g1). If the rule instead selects
a virtual zig unit, it is not a rotation bit and is likewise outside
image(g1). This DERIVES endpoint freedom from the literal source guard;
it does not assume a free terminal or desired total capacity.

Distinctness: the intervals from the end of B phase tau_(i-1) to the
start of B phase tau_i are disjoint consecutive ACTUAL cyclic source
gaps. Because every component has the same transfer cadence, beta_i
and the WHOLE StepEv E_i lie in the ith gap. One A StepEv cannot
straddle two gaps separated by a B phase. Hence different residual
access occurrences use different original E_i and therefore different
bits. At one access condition3 gives only one new demand, even when
several cycle ports share E_i. This counts shared work once rather
than assuming separate work for each cycle.

The rule thus has distinct demands and distinct values disjoint from
image(g1). It is an injection and preserves g1. No sign inequality,
complete comparison, source-block budget, endpoint count or bounded
lookback was assumed. The disjoint gaps used in the proof are a
CONSEQUENCE of the common actual cadence; they are not independently
funded preparation blocks. QED.

The proof commutes with literal key reflection and child reversal.
Private A ancestors and hanging BSTs are allowed without deleting them:
the guard is evaluated on their full actual S-labels. Negative rotation
credits may exist elsewhere, but the proved rule uses only certified
zero-rotation bits or virtual units and does not claim other credits.

### Exact limits of the theorem

Common cadence, one associated residual per transfer access, and the
literal event guard are declared source-class hypotheses. We have not
proved them for arbitrary collections of B-only cycles. A single cycle
is a permitted bundle. Parallel C17/C18 and C19/C20 are also permitted;
their shared entries do not create extra claims or extra credits.

The theorem gives a separate RAW comparison, like Step 1. It does not
retire any independently live fE/Gamma owner, rewrite h0, change a
historical assignment or establish a new Bank25 trace. Such owner and
storage contracts keep their existing hypotheses. No old certificate is
replaced by the construction in this report.

## 7. What remains for arbitrary cycle collections?

The theorem does not cover the following source configurations:

1. An entry event whose two original bits are already positive g1
   payments, as in C16. An independently justified ownership relay or
   other existing source supply must reach outside that event.
2. Two distinct residual demands associated with one entry event in
   differently paced cycles. Their source gaps can overlap, and one
   zero or virtual bit cannot be counted for both.
3. Multiwinding components, in which the occurrence cycle crosses the
   period seam more than once. The proof's one-gap-per-transfer argument
   cannot be applied as if those were separate copies of the period.
4. Cycles with different access cadences, or several associated residual
   doubles at one common B access. The present one-demand-per-gap proof
   supplies no multiplicity bound or collective endpoint expansion.
5. Any additional live reservation or Bank25 eligibility contract beyond
   the raw g1 interface.

Step 2 guarantees real root entries and nested labels at shared root
promotions. It does not limit the number of different residual demands
that can name that event. Zero-Psi A work preserves M and can therefore
be invisible to component histories; virtual units never change a tree.
Knowing that such work exists or that individual relays succeed is
not a proof of distinct terminals for a general collection.

Original paired closure supplies the actual cyclic strand runs and
actual level-pairing credits. WHETHER it forces sufficient noncolliding
external work for EVERY B-only-cycle residual collection remains OPEN.
This report proves no negative answer to that question. No matching,
free endpoint, block partition, Hall inequality or desired capacity
sign is assumed to fill it.
