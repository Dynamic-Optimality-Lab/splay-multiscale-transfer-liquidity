## 2. T2 — zero erosion and zero first-doubling selections are disjoint

The original L3 proves nonpositivity of canonical-witness erosion.
The following strengthens its OVERLAP information without introducing
a potential or changing a single source operation.

THEOREM (canonical-erosion polarization). With the actual B fixed
during one A rotation, if that rotation removes a canonical blocker
of ANY current proper B label, it adds NO canonical blocker to ANY
current proper B label. In particular a ZERO erasure's own bit is
not one of L6's zero first-doubling selections.

PROOF. It suffices to erase the left blocker x=pred_S(l) of an
actual current B label I=[l,a]. The literal rotation must be

    p(v(L,C),R) -> v(L,p(C,R)),
    x <= v < l <= p <= a,                            (T2a)

by L3's reflected ancestor-removal argument. Private physical v
and p in these ranges are allowed; neither is contracted.

A right rotation can add only a RIGHT canonical witness. If it
added one on a current B label J, its newly relevant ancestor is
v. Writing b=ceil_S(p), the ancestor test requires

    min J <= v <= max J < p <= b,
    max J = pred_S(b).                              (T2b)

Indeed b is the first S key beyond max J; before the rotation p
prevented v from being an ancestor of b, and afterwards v is one.
No left witness can be added by this right rotation: its newly
acquired descendants are all to the right of v.

If p=l, (T2b) makes max J=x. For v>x it is impossible already;
for v=x, J contains x but excludes l while I contains l but
excludes x. Since x,l are adjacent in S and B paths to S are in
S, their B LCA is x or l. One is an ancestor of the other, so
two B subtrees cannot separate them in this way.

If p>l, then b is in I and b>l. Equations (T2a,b) make J contain
x and l but exclude b, whereas I contains l and b but excludes
x. These are crossing B labels, again impossible.

Thus no J exists. Reflection proves the left-rotation case,
including private keys in both adjacent-S gaps. QED.

CONSEQUENCES. Every zero erasure own bit is a genuine R1 unit
disjoint from g1, N9, L5 and L7 by sign/type, and disjoint from
L6 because a first-doubling selection ADDS a blocker. An erasure
of many labels is still ONE such own bit, never their count.
The heads of A-negative slots are the original distinct lambda
heads; no second own bit is manufactured. These conclusions
refine the existing 2N+T_A inventory, rather than adding to it.

This also resolves a possible hidden collision in using returns:
when a return is a zero erasure, another sponsor group CANNOT
already have spent its own bit through L6.

## 3. T3 — first A returns are globally distinct across sponsor runs

For each positive first-doubling group theta, let K_theta be the
actual common B label it loses from A. Define r(theta) to be the
FIRST later A rotation at which K_theta returns to J_S(A).
Original A closure supplies it within one cyclic traversal.

Then

    theta -> r(theta) is injective,                  (T3)

even when B removes/recreates the sponsors, different groups share
input histories, or the return lies across the chosen source cut.

PROOF. A rotation introduces at most one new proper S-label into
the A SET, so two groups with different K cannot have that same
first return. For the same K, a second positive loss of K cannot
occur between a loss and its first return, because K is absent
throughout that interval. Those absence intervals are disjoint
on the actual closed A history. QED.

The proof uses SET disappearance and reappearance, not a guessed
return of the same root or physical subtree shape. Private unary
duplicates therefore cannot create extra returns. The cyclic
definition identifies the original return occurrence once.

If r(theta) is a terminal A zig, its virtual bit1 is also distinct
for different theta, because a terminal event has only ONE real
rotation. None of g_pre's component maps uses virtual units.
Thus every such terminal first return supplies its one unused
virtual unit, REGARDLESS of its real rotation's sign. A double
return does not obtain a fictitious virtual unit.

## 4. T4 — intact-input and quiet cross-run returns expose fresh bits

Call a first return QUIET if it adds no canonical blocker to any
current proper B label. This is an original rotation predicate,
not a debt, a potential or an assumed matching endpoint.

Suppose an original input I_d is still in its SAME live B run
immediately before r(theta), and still carries the new blocker
x which theta added. The returning A label K_theta contains I_d
and excludes x, so immediately afterwards x is not below its
LCA. The return therefore erases this current canonical blocker.
By T2 it is nonpositive and quiet.

If K_theta is NOT a current B label at this return, it cannot be
negative: its sole introduced A label is K_theta, so no missing
B label is acquired. Its sign is consequently ZERO. Its own
physical bit is unspent after g_pre, by T2. If terminal, its
distinct virtual bit is unspent as well.                    (T4a)

For such a return a positive sign would lose some current common
B label, adding a canonical blocker to it; quietness excludes
that. A negative sign would acquire a current B label, excluded
because the one introduced label K is not in B. Hence it is
zero, and cannot be an L6 selection.                        (T4b)

Distinct quiet returns supply distinct own bits by T3. Their
