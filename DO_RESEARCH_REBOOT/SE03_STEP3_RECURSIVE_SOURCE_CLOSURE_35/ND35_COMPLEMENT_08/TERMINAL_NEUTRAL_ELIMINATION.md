# TNE35 — a uniform source reduction to strictly internal neutral doubles

Status: new mathematical derivation, independent challenge pending. It
is a RAW physical partial-matching theorem for ALL original supports,
not Universal CD, not a frozen-owner permission theorem.

## 1. The old-root side-cluster seed

Consider any genuine natural macro, from common A/B root g to genuine
target x!=g. Full B is fixed throughout the intervening original A-only
or nongenuine operations. Put

    I={s in S:s<g} if x<g, otherwise {s in S:s>g}.

This nonempty proper S interval is the FULL B side subtree at g toward
x. It is also an A-subtree label at the synchronized starting root g.
At the end of the actual A phase the root x belongs to I, so I cannot
be a proper A-subtree label. Thus its last SET disappearance occurs at
a real A single rotation of the same original macro. Fix that bit p_e.

The disappearance has DeltaPsi=+1, not just a lost label offset by a
different newly matched B label. To prove this, write L for the label
of the whole rotated A subtree. L persists at the promoted root. Hence
L is a strict superset of I, or I would still occur at that root.
Both L and I are S intervals; I is the full prefix/suffix beyond g.
Every strict interval superset L therefore contains g. Since the old
child subtree I excludes g, the old pivot's NEW subtree still contains
g. Any new proper label containing g is absent from J_S(B), whose
actual root is g; the full S label, if produced, already occurs in A
and is not a new SET addition. Consequently no gained A label can
cancel I's disappearance in Psi. This rotation creates exactly one
missing B label I, so p_e is a genuine ND35 positive bit.

This proof handles arbitrary anonymous unary duplicates: the chosen
step is disappearance from the SET, and the persistent L argument
rules out pretending that removing one duplicate loses I. It also
handles every helper sequence, multiple earlier returns to g, private
root changes and a zero-event final KEEP. Last disappearance is taken
in the exact cyclic macro order; no operation or bit is invented.
Distinct genuine macros have disjoint A inventories, so all p_e are
distinct original bits. There is no population or depth bound.

## 2. Every final B rotation is a genuine decrease

In the last single rotation of B's genuine splay to x, the promoted
node is the actual x. The old proper child label contains x and is
absent from A, already rooted at x. The old pivot's NEW subtree is
the ENTIRE left or right S-side at the final root x. That label also
occurs in A's corresponding root-side subtree. It is nonempty because
the old pivot is a distinct S key. Therefore the final B rotation has
DeltaPsi=-1 exactly. Call its decrease slot z_e.

For even B depth, z_e is in the last original double, which is hence
nonneutral. For odd depth it is the final terminal zig, not a double
demand. Every genuine macro has such a z_e, including Q=0/depth1.

## 3. Reroute the PROVISIONAL ND35 crossing bijection

The original ND35 level pairing is a bijection from all decrease slots
to all positive A bits. In each macro require z_e to use p_e. These
required pairs have distinct slot and bit endpoints. Impose them one
at a time by transpositions in the provisional bijection: if z_e uses
p and p_e currently belongs to slot z, swap the two images. An earlier
required pair cannot be disturbed because all required endpoints are
distinct. Every intermediate object remains a bijection of actual
slots and actual positive bits on the SAME original period.

No protected old owner map is changed. This rearranges only the new
analytical ND35 crossing assignments. It is an explicit finite source
construction, not a capacity assumption, and uses no CD inequality.
Raw within-period source matching is the claim; a stronger temporal
endpoint or reservation policy is not inferred from this transposition.

## 4. Pay all nonneutral and all terminal doubles simultaneously

If macro e has Q>=1, assign its LAST double the original bit p_e.
For even B depth, its final rotation slot z_e is its designated payment.
For odd depth, redirect p_e from the terminal-zig release to that double.
If it was neutral, this funds a genuinely additional original demand.
If it was nonneutral, its own old decrease slots can be release slots.
Q=0 macros assign no double and leave p_e as a release credit.

For every NONTERMINAL nonneutral double, choose its first actual decrease
slot and use the bit of the rerouted crossing bijection. None of these
slots is z_e. Thus their donor bits are distinct and avoid ALL p_e.
This constructs one injective partial matching g_T with domain

    Dplus union {last original B double of every Q>=1 macro}.

It covers every nonneutral double and every terminal double, at every
support, all core sizes, every helper population and either orientation.
It also proves P>=number_of_genuine_macros, by distinct actual seeds.

All still-uncovered demands are STRICTLY INTERNAL neutral doubles.
If L0 is the number of neutral terminal doubles, the raw analytical
complement has |R_T|=|R|-L0 and residual demand count B0-L0. Hence the
new exact identity remains

    |R_T|-(B0-L0)=2A-Q_B.

The last equation is bookkeeping, not a nonnegativity proof.

## 5. Natural h0 liability reduction, with old values unchanged

Apply the established two-injection alternating argument to g_T and
the original h0. From each h0-unpaid root, follow g_T, then reverse h0
if its bit is owned. Unique incoming edges prevent entered cycles or
merged roots. A finite path ends at a distinct h0-unowned actual bit,
or at a distinct demand outside dom(g_T). Such a demand is necessarily
a STRICTLY INTERNAL NEUTRAL double. Append only free-bit termini to
a separate partial comparison; no h0 value is changed.

This is a complete source-uniform reduction. It does not assume that
the remaining neutral labels are unpaid themselves, nor identify their
bits twice. It does not establish fE or other reservation availability.

## 6. Exact upward bridge and remaining child
