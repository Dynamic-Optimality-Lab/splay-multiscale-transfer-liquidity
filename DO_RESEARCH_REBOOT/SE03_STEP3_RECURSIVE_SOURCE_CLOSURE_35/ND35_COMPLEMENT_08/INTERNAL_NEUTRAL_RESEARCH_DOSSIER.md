## 1. Exactly what the remaining object is

It is a CLASS of strictly internal neutral B doubles, not one final
unhandled event or one fixed finite signature.

An original source occurrence t accesses x_t. A performs every access.
B performs KEEP; nongenuine root-repeat KEEP is an identity in B.
DELETE is A-only and NEVER physically removes a BST key.

    a_t = ceil(depth_A(x_t)/2)
    q_t = floor(depth_B(x_t)/2) on KEEP, otherwise0.

Depth counts edges. A StepEv has two physical units, even for a terminal
zig whose second unit is not an actual second rotation:

    C_A = {(t,j,b):1<=j<=a_t, b=0 or1},   |C_A|=2A.
    D_B = {(t,k):1<=k<=q_t},             |D_B|=Q_B.

A natural genuine macro includes EVERY original operation after the
previous genuine B change through the current genuine KEEP. Its H is
the sum of all original A events, including positive DELETE helpers and
any zero-event final KEEP. Its Q is the terminal full B-double count.
The previous and final A/B roots synchronize at genuine boundaries.

Let M be the actual genuine KEEP support. For nonempty exactly closed
histories the cyclic root argument gives all KEEP targets in M. The
actual labelled B ancestor core S=C_M(B) is fixed on the closed period,
with r<=|S|<=2r-1. Keys in S are accounting anchors; using them does NOT
make them genuine KEEP targets. A's private ancestors are unrestricted.

Let J_S(T) be the SET of nonempty S-descendant labels of actual subtrees.
Anonymous unary duplicates count once. Define

    Psi(A,B) = |J_S(B) minus J_S(A)|.

Each actual A single rotation changes Psi by -1,0 or+1. After A has
splayed a KEEP target x, every B single rotation changes Psi by -1 or0.
A B double is ND35-neutral when BOTH its rotations have change0.
It is nonneutral if its total decrease is1 or2.

The residual class is precisely

    D0_internal = {(t,k): double(t,k) is neutral and 1<=k<q_t}.

Thus q_t>=2, so such an access has actual B depth at least4. Both even
and odd depths are possible. There is no constant bound on q or on
the number of these demands as support grows.

Three distinctions are essential:

* Neutrality is a statement about THIS potential, not the physical
  cost sign2H-Q.
* Internal neutrality does not mean that the demand is unpaid by h0.
* A demand already paid by h0 may still become an alternating-path
  liability label; that does not release its old bit.

## 2. The complete ND35 inventory and conservation law

For a B double let m be its total Psi decrease. The exhaustive partition
is B0(m0),B1(m1),B2(m2). Let P count A +1 rotations, N count A -1 rotations,
and Z1 count decreasing terminal B zigs. Actual A/full-B closure gives

    P = N+B1+2B2+Z1,
    2A-Q_B = (2A-P)+N+B2+Z1-B0.

At each integer potential level, pair every downward crossing with its
cyclic preceding upward crossing. This bijection uses actual occurrences
on ONE period. An upward crossing is a real A rotation bit.

Choose the first decrease of every nonneutral B double as its payment
slot. Its paired up bit defines the simultaneous injection g+ on ALL
nonneutral doubles. This theorem is uniform in original support, word
length, private population, helper choice and orientation.

The complement R=C_A minus im(g+) has FOUR disjoint physical sources:

| Source | Exact inventory count | Qualification |
|---|---:|---|
| A units not associated with a +1 rotation | 2A-P | Includes nonpositive rotations and virtual zig units |
| Positive bits paired to A-negative slots | N | Actual release donors, not newly minted bits |
| Positive bits paired to a second B2 decrease | B2 | One extra release per B2 double |
| Positive bits paired to decreasing B zigs | Z1 | One actual released donor per such zig |

Hence |R|=2A-P+N+B2+Z1. This is an exact inventory, NOT a proof that
|R|>=B0. Its units need not be free under a separately frozen owner map.

The new final-rotation theorem shows that EVERY genuine terminal B zig
decreases Psi by1. Thus Z1 equals the actual number of terminal B zigs.
No zig is counted as a B-double demand.

## 3. What terminal-neutral elimination actually proved

Every final B single rotation creates the entire S-side of the new root
x as a proper subtree. A already has root x and the same side label.
The lost old label contains x and is absent in A. This rotation therefore
decreases Psi by1.

Consequences:

1. At even B depth the LAST double is nonneutral.
2. A neutral LAST double must be followed by a terminal B zig.
3. That zig's ND35 release slot has a distinct real A bit already in R.
4. Assigning it to the last neutral double leaves EVERY g+ value unchanged.

Call the extension g_Z. It pays Dplus union D0_terminal. If L0 is the
number of neutral last doubles, then

    R_Z = C_A minus im(g_Z),
    |R_Z| = 2A-P+N+B2+Z1-L0,
    |D0_internal| = B0-L0,
    |R_Z|-|D0_internal| = 2A-Q_B.

That last identity is bookkeeping, not the missing nonnegative bound.

The no-internal-neutral source class has a complete matching at arbitrary
support. The original static whole-block construction can then normalize
h0 with working bank2, given its original permission interface.
This does not assert new scalar coverage beyond all previously proved
classes, nor settle arbitrary internal-neutral sources.

One must NOT repeat the terminal argument on successive internal doubles:
their frame roots are not synchronized actual global A/B roots.

## 4. A stronger older tool: access-level release reassignment

PC35 already permits more than terminal-neutral elimination. This is
important and must not be lost when choosing the next proof target.

Fix an accounting projection M subset C subset S for the WHOLE period.
PC35 counts subtree-label multiplicities: B counts labels of S vertices,
A counts labels of ALL actual physical vertices, including empty labels.
Its potential is

    Phi_C = sum_L max(m_B(L)-m_A(L),0).

It has the same A +/-1 and B nonincrease properties. With C=S it agrees
with the ND35 set potential, because B's S labels are distinct.

Let delta_t be the total B-phase decrease during access t. All delta_t
decrease slots have distinct real A upcrossing donors. PC35 can assign
min(q_t,delta_t) of them to double demands of THAT access, regardless
of which double generated each slot. Therefore:

* A second decrease of one B2 double can pay another neutral double.
* A terminal zig can pay an INTERNAL neutral double too.
* The remaining access-level demand count is max(q_t-delta_t,0).
* Choosing C=M makes the saved AF source no-neutral, although C=S has
  four neutral doubles on the same source.

For a macro e, let P_e,N_e be its actual A positive/negative counts.
PC35's exact local signed expression is

    2H_e-Q_e-Delta Phi_C
      = (2H_e-P_e)+N_e+delta_e-Q_e.

When this is nonnegative on every macro of a source class, the accepted
grouping/static reconstruction supplies a complete comparison there.
In particular delta_e>=Q_e is sufficient. The expression is NOT known
nonnegative universally.

Choosing a DIFFERENT projection at each edge requires an additional

## 5. Geometry of each neutral double

Each single B rotation loses one proper nonempty S interval containing
the actual accessed root x, and creates one proper interval excluding x.
Neutrality means the new interval is absent from A as well.

The two removed intervals of one double are distinct and nested:
LL/RR remove the old-parent then old-target intervals; LR/RL remove the
old-target then its enlarged promoted interval. This gives TWO incidence
ports, not two free donors.

Once a missing-label strand is transferred during a B access to x, its
new label excludes x. Every later removed label in that same access
contains x. That live strand cannot transfer again during that access.
The two ports are therefore different LIVE strands at that time.
They need not belong to different GLOBAL history components after the
cyclic seam is glued.

All S labels are intervals of sorted S. At any one tree state they form
a laminar family. Intervals at different times need not form a globally
laminar family. Global noncrossing or a forest must not be assumed.

## 6. Full cluster histories: what they preserve and what they do not

The missing set Z=J_S(B) minus J_S(A) changes as follows:

* A can add one label, delete one, transfer one to one, or do nothing.
* B deletes one label and either adds one different label or adds none.
* B creates no birth without a deletion.

Join persistent actual labels across fine source boundaries, join deleted
to added labels at transfers, and glue the real final/initial boundary.
The exact occurrence graph has indegree/outdegree at most1, hence is a
union of birth-to-death paths AND directed cycles.

Each path has one genuine A-birth bit at its origin. This supplies an
alternative nonneutral matching g_life. It need not equal the original
scalar-level g+. Cycles have no nonexistent birth credit.

A component can wind through the cyclic seam several times in this
annotation. Each vertex still represents a different actual boundary/
label occurrence on the ONE period. This is not multiple donor copies.

The accepted CCR source has SEVEN directed B-only neutral cycles, with
no A-transfer edge on those cycles. Thus a proposed proof that every
neutral component must have an A-birth or A-transfer donor on itself is
false. A work outside that component can nevertheless fund it.

The history graph is a complete FORWARD annotation of actual sources.
No reverse-realization theorem or smaller all-support finite quotient
has been proved. Arbitrary abstract graph paths are not source witnesses.

## 7. Actual root-entry witnesses

For a removed missing interval I at a neutral port, find its latest
addition in cyclic source order. Such an addition exists: I is being
removed, so it was not present constantly throughout the period.

* If it was added at an A rotation, that event provides two real units.
* If it was added during B's access to y, it excludes y. Before the

## 9. A second uniform tool: one positive root-side seed per macro

At a genuine boundary with old root g and next target x, take the whole
S-side of g toward x. It is present in A initially and absent once A
has root x. Its LAST disappearance from the SET J_S(A) is an actual
positive ND35 rotation, even with private unary duplicates.

Why positive: the whole rotated label persists and strictly contains
that side interval, hence contains g. The new pivot label contains g,
so cannot create a new proper B-matching label; full S was already present.
The side loss is therefore an uncancelled +1.

These seeds lie in disjoint actual macros. Thus

    P >= number of genuine macros.

A provisional crossing-bijection transposition can pair each seed with
that macro's compulsory final B decrease. This alternative g_T pays all
nonneutral and all last doubles, including terminal neutral ones.
It is a useful locality normalization; g_Z's direct released-zig proof is
simpler and preserves the original g+ without these transpositions.

### B. Interval-top potential, TI35

For each actual B S-subtree interval I, take the unique shallowest
physical A key top_A(I), including private keys. Let

    T = |S| - number of distinct top_A(I).

An A rotation changes T by at most1; B rotations decrease it or leave

### C. Full physical rank tokens, RT35

For a right rotation p(x(L,C),R)->x(L,p(C,R)):

* depth decreases by1 on L union{x};
* depth increases by1 on {p} union R;
* all other depths are unchanged.

These are disjoint contiguous physical-key intervals. Record them as ONE
balanced token on the original bit(t,j,b), not as two credits. Reflection
gives the left-rotation rule. Over a closed A period the signed rank-vector
sum vanishes at EVERY physical key, including anonymous ancestors.

Immediately after A accesses x, every B ancestor interval containing x
has A-minimum depth0 at x. This gives an actual joint heavy-choice interface.

inventory is known; the missing issue is sufficient JOINT source supply
for all remaining claims. Proving an equivalent global count by assertion
would not be advancement. A new source-geometric bound or explicit
noncolliding allocation is required.

The missing-history cycles demonstrate why a model retaining only their
own A births/transfers is incomplete for donor purposes. Attach actual
zero-Psi A rotation bits and virtual zig units through full rank/root-
entry information. Prove a global collision bound or augmentation
invariant; mere witness existence is insufficient.

### Lead3: exploit both ports without assuming different components

Within an access the ports are different strands and their intervals
are nested. That is real geometry. A candidate source proof might use
this nesting, chronology and root-entry barriers jointly. It must survive
global seam permutations, self-incidence at a component and shared events.
A per-state laminar argument does not automatically extend across time.

### Lead4: combine complementary measures by a proved coverage rule

Different fixed C and the A-top measurement see different decreases.
An independently proved source partition or balanced block cover could
choose the appropriate complete mechanism. Simply summing donor counts
from different measures double-counts actual bits. Simply switching
potentials drops boundary corrections. The simultaneous counterfamilies
rule out the smallest scalar portfolios.

### Lead5: repair interval reduction WITH event pairing

A valid arbitrary-support quotient may need to retain whether a surviving
rotation is the first/second part of an original double, boundary ranks,
aliases and current private-ancestor exposure. Prove all original
operations forward-map with exact costs, then a certificate and source
lift. The four-key projection witness is a mandatory control.

### Lead6: a parameterized analogue of the CD6 branch representation

The six-key proof kept all marked nodes and unmarked branchers, then
proved that only actual cheap-access operands needed additional unary
decorations. A parameterized grammar is conceivable. Its size grows
with support; there is no universal974-state bound or fixed c4 argument.
One would still need a uniform signed certificate, not just a compiler.

### Lead7: structurally certified recovery blocks

Use actual cluster endpoint change to locate collateral or watched-edge
creator tails, then prove the required source blocks are disjoint or
their overlaps have a correct joint exchange. CCR35 supplies a precise
conditional theorem. The missing exhaustive block partition cannot be
assumed. Exact-return and shared-reset counterfamilies must remain tests.

### Lead8: complete-state induction on a genuinely smaller source

SC35 already handles repeated FULL A/B states. A new support/key removal
or source-simple cut surgery would need to preserve actual reachability,
paired closure, signed deficit and physical reconstruction with a
strictly decreasing measure. Removing a private key or an internal
rotation without this bridge is invalid.

### Lead9: source-forced augmentation of the JOINT candidate relation

The root-entry/own/ND graph has explicit physical provenance and its
control matchings require provisional rearrangement. A real theorem
would derive endpoint existence for every unfinished connected component
from source geometry. An arbitrary Hall inequality or a self-referential
“all components augment” premise is not such a theorem.

These leads are not nine new mandatory campaigns. They are alternatives
for attacking the one remaining implication. The four-rule gate requires
a strictly smaller obligation, a concrete current mechanism, bounded
scope and an actual upward case removed before executing any pivot.
