# Step 3.1B — finite-return slot construction

**B — PARTIAL.** A finite address system, sound physical-event payment
rules and a source-guarded fixed-pair reuse theorem are proved below.
The reuse theorem holds for arbitrarily many repetitions of its declared
claim stream. The saved CCR source supplies a nonvacuous instance.

Coverage of ALL original residual demands is not proved. In particular,
several arrivals can compete for one occupied address or for the two bits
of one return event. Neither source-state finiteness nor Step 3.1's
rotation count resolves that competition. No Step 3.2 execution follows.

Status at freeze: arbitrary-source coverage is OPEN. Finite addresses
will not be identified with a bound on ALL unpaid demands unless every
arrival is admitted without losing another claim.

## Frozen scope and R1–R4

Use the original finite physical key set X, actual original operations,
Step 1 g1/F/R1, and Step 3.1's actual ancestry return witnesses. Preserve
every physical unit ID, owner and cyclic alignment. No query, replay,
experiment, source search, new potential or unrelated funding system
is introduced. Only this report is written.

Principal smaller theorem: a fixed pair(u,x), one selected residual
arrival per genuine KEEP-u gap, and a source-certified return event
with an intrinsic g1-unused bit. Prove that the old claim is ACTUALLY
paid before the next admission, so the same finite address can be reused
across arbitrarily many original periods.

R1: this guarded, visit-separated claim stream is smaller than all F.
The general address system retains explicit unsupported/blocked arrivals;
it does not assume an injection of all unpaid demands into its slots.
R2: actual visits force A ancestry gains/losses by Step 3.1. The event's
literal zero/negative rotation or virtual zig unit is outside image(g1).
Current-event-only payment proves physical freshness on every repetition.
R3: one return-event mechanism, symbolic rules and the existing CCR
certificate. No new independent matching architecture or verification
program is used.
R4: success proves sound reuse for this declared class, rather than
discarding a claim when ancestry or full source geometry returns. It
does not show that arbitrary arrivals are separated, that returns have
usable units, or that different return pairs receive different service.

## 2. The exact return information available for slots

For a critical natural macro e ending at genuine KEEP x, use the actual
START trees A^-,B^- from Step 3.1 and define

    D_e=Anc_{B^-}(x) minus Anc_{A^-}(x).

Let M be the original genuine KEEP set and

    eta_{u,x}=1 if u is a proper ancestor of x in the actual A tree,
              0 otherwise.

At both the start and end of e, eta_{u,x}=0 for u in D_e. At the end
this follows from A's root x. If u in D_e is actually accessed outside
e, its resulting root-u snapshot has eta_{u,x}=1. Actual paired return
therefore forces a gain and a loss outside e. For a fixed x the selected
changes for different u use different actual rotations, giving

    R_A(outside e)>=2*kappa_e.

In particular every u in D_e intersect M has a genuine outside visit.
But several critical macros in the SAME KEEP-u gap share one return
pair. Across different x even the witnessed rotation can be shared.

The literal identity underlying this is

    p(v(L,C),R) -> v(L,p(C,R)).

For fixed x in L or x=v it loses only ancestor p; for x in R or x=p
it gains only ancestor v; for x in C or outside the subtree it changes
no ancestor membership. Reflect the identity for a left rotation.
Thus one rotation witnesses at most one membership change for fixed x,
but can witness changes for many DIFFERENT targets. It remains one bit.

Nothing here proves that a return bit is in R1. The retained distinction
between an actual rotation and an unused physical unit is essential.

## 3. Finite source-defined addresses and admission

Define

    L_X={(u,x): u,x in X, u!=x},
    |L_X|=n(n-1).

This size depends on the physical key set, not on the length of W or its
repetition count. An address is EMPTY or holds ONE record

    (actual residual demand ID, its original macro e,
     its fixed admissible-address set, current ancestry phase).

The phase is observed from the original A tree; the payload is an actual
unpaid demand, never an abstract amount or a physical credit in storage.
The payload IDs are not a finite set across repetitions. Only the
addresses are finite. That alone proves no bound on all unpaid demands.

For a residual d belonging to a CRITICAL macro e of target x, define
its current candidate addresses solely from the original source:

    C(d)={(u,x): u in D_e intersect M}.

This uses genuinely visited ancestors, not arbitrary anonymous B keys.
When d arrives during its original B double, the A splay has finished,
so eta_{u,x}=0 for every candidate. The entire macro and all helpers
remain attached to the record. No graph edge is used as a substitute
for an original operation or reachable source history.

**Admission rule.** Place d in an empty address of C(d), using a fixed
key order to break ties. Never overwrite an occupied record.

If e is not critical or C(d) is empty, label d UNSUPPORTED by this
system. If all its candidates are occupied and no sound readdressing
below is performed, label d BLOCKED. In either case d remains unpaid;
it does not disappear from the full residual inventory. These are
explicit failures of coverage, not exclusions from the original domain.

For n<=1 there are no B doubles and the empty ledger is sufficient.
No nonempty-support conclusion is inferred from that boundary case.

## 4. Actual-event payment and readdressing rules

These rules establish soundness even where they do not establish
coverage. They do not invoke finite carry, sufficient capacity or Hall
expansion as a premise.

### 4.1 The actual event's unused pool

For the CURRENT actual A event E=(i,t,j), let

    C_E={(i,t,j,0),(i,t,j,1)},
    J_E=C_E intersect R1(W^copies).

No bit of E has previously been produced in this execution. Its
membership in J_E is read from the frozen copy-lifted g1. In particular:

| Original unit type | Status relative to g1 |
|---|---|
| Real A rotation with DeltaPsi=-1 or 0 | Unused by g1. |
| Virtual second A-zig unit | Unused by g1. |
| Positive bit whose crossing slot is an A-negative release | Unused by g1. |
| Positive bit whose crossing slot is an unselected B release | Unused by g1. |
| Positive bit used for a nonneutral or Step 1 release payment | Protected by g1; unavailable here. |

The A-negative slot's released head is a DIFFERENT positive unit; it is
not a second copy of the negative rotation's own unit. A B release is
not itself an A bit. If its positive head occurred earlier, observing
the B release now does not produce that head again. The present rule
services claims from current-event units only; it does not keep a bank
of earlier unused credits.

One sufficient, purely local subpool is

    I_E={real bits of E with DeltaPsi<=0}
        union {the virtual bit if E is an A zig}.

Then I_E subset J_E, with at most two physical units in either pool.

There is a direct geometric zero-bit guard. At a right rotation
p(v(L,C),R), only the old S-descendant label at v and the new label at p
can change the nonconstant part of J_S(A). If neither nonempty label
belongs to the actual frozen J_S(B), its intersection with J_S(A)
does not change; consequently DeltaPsi=0. Empty labels and duplicate
private labels are interpreted with the inherited SET semantics.
The left case is its exact reflection. This guard is a local tree
predicate, not an assumption of the desired matching or capacity bound.

Call a return event INTRINSICALLY GUARDED if I_E is nonempty. This is
not asserted for every return event.

### 4.2 Return service

An occupied address (u,x) is eligible at E if some actual rotation of E,
after that claim's admission, gains or loses u's A ancestry of x.
List each eligible occupied address ONCE, even if E has several relevant
descriptions. Pair the first

    min(number of eligible occupied addresses, |J_E|)

distinct records with distinct bits of J_E in fixed order. Record each
payment Pi(d)=that actual bit and empty exactly those paid addresses.
The paying bit may be the OTHER bit of the witnessing event. It need
not itself be the ancestry-change rotation. Its physical existence and
availability come from J_E, not from the ancestry witness's name.

Unserved records retain their demand IDs and update their observed
ancestry phase. In particular 0->1->0 does NOT clear an unpaid record.
The event produces at most two payments globally, however many chains,
targets or histories mention it. No event is serviced a second time.

This is a two-unit current-event operation, not a Bank25 storage or
Gate U certificate. It uses no additional physical-credit storage.

### 4.3 Readdressing

An admitted unpaid record d can move from its current address to an
EMPTY member of its original C(d). Retain its original ID and original
source data; set the destination phase to the actual present eta.
The old address then becomes empty. No g1 or Pi value changes.

This operation pays no demand and creates no new return occurrence.
After such a move, the next payment still requires an actual subsequent
eligible event and an available actual bit. Readdressing into an
occupied slot, merging two records or treating an address cycle as
repayment is forbidden. Existence of a useful empty destination is
NOT proved for an arbitrary blocked arrival.

### 4.4 Other source transitions

B operations produce no A credits. They can create residual arrivals,
but do not pay them. An actual KEEP-u visit changes the observed phase;
it does not pay a claim unless an actual A event meets rule 4.2.
Zero-cost root repeats produce no event units. An exact A return,
complete A/B state return, chart repeat or end of W does not reset the
claim ledger. Claim records persist until actual payment or a legal
move. All original chart corrections and source boundaries remain.

## 5. Soundness and exact limits of the invariant

Let H be the ADMITTED unpaid demands, and P the newly paid residuals.
Starting empty, every finite sequence of the above permitted updates
maintains:

    H injects into L_X,
    Pi: P -> actual produced R1 units is injective,
    H and P are disjoint subsets of the actual residual demands,
    g1 union Pi is an injection on its declared domain.

PROOF. Admission uses an empty address and a fresh original residual
ID. A move transports one record into an empty address and leaves all
physical assignments unchanged. Payment takes distinct occupied IDs
and different units of J_E, all outside image(g1). No earlier payment
used a unit of this newly occurring E; different events/copies have
different physical IDs. Thus both demand and donor injectivity persist.
Removing only paid records preserves the unpaid-address injection.
Other operations change no payment. Induction proves the assertions.
QED.

The full unpaid residual set also contains BLOCKED and UNSUPPORTED
demands, if any. It is not identified with H. In particular the bound
|H|<=n(n-1) is NOT the bounded-carry hypothesis for all F. This explicit
distinction prevents finite geometry from concealing an unbounded
unregistered queue.

## 6. A source-certified fixed-pair slot-reuse theorem

This is the proved smaller theorem. Its guard is an explicit local
source predicate, rather than an assertion that a matching exists.

### Declared source class

Fix distinct genuine keys u,x. Select any finite or repeated stream of
actual residual demands d_1,d_2,... satisfying:

1. Each d_i belongs to a critical macro e_i of target x, with
   u in D_{e_i} intersect M.
2. Between consecutive selected macros there is an actual KEEP u:
   after the end of e_i and before the start of e_{i+1}. In particular,
   selecting at most one demand in each original cyclic KEEP-u gap
   suffices. Different demands in one macro are NOT automatically
   different such gaps.
3. Between the arrival of d_i and the next selected arrival, at least
   one of the forced ancestry-change events for (u,x) is intrinsically
   guarded as in section 4.1. For example, its other real rotation can
   satisfy the displayed absent-label guard. This is a condition on
   the actual original event, independent of the slot or payment map.
4. The restricted ledger services this ONE pair and these selected
   claims. Simultaneous service of other pairs is not a hypothesis-free
   extension of this theorem.

For a finite stream, condition 3 is needed only between consecutive
selected arrivals. No future event is assumed after its last arrival.
When the stream is the literal repetition of a selected list in W,
the separating-visit and guarded-event conditions include its actual
last-to-next-copy-first interface.

### Theorem and construction

Use only the source-certified address (u,x) for this stream. Admit its
first selected claim into the initially empty slot. Apply current-event
return service. Then every next selected arrival finds that slot empty.
Every removed claim has been paid with a distinct actual R1 bit, and
at every executed prefix

    |U_selected|<=1.

The bound is independent of the number of repetitions. No demand is
merged, and no old owner is displaced. No readdressing is needed.

### Proof

At d_i's arrival A has root x, so eta_{u,x}=0. At the separating KEEP-u
snapshot A has root u, so eta_{u,x}=1. At the actual start of e_{i+1}
the definition u in D_{e_{i+1}} again gives eta_{u,x}=0. Therefore actual
source rotations between these selected arrivals include a gain and
a loss. A zero-cost KEEP-u snapshot is allowed: its gain necessarily
occurred at an earlier actual A event after the preceding eta=0.

By condition 3 one such event E has a unit in I_E subset J_E. If the
old claim was not paid at an earlier eligible event, its occupied slot
is eligible at E. There is no other selected claim in this one-pair
ledger competing for J_E. Rule 4.2 therefore assigns an actual unit of
E to the old claim and empties the address before the next arrival.
If it was already paid, the address was already empty. Induction proves
admission and the bound of one at every prefix.

Each chosen unit is outside image(g1). It is produced at its actual
event, after the claim's admission, and used at most once. Consecutive
reuse intervals are separated by selected arrivals, so no return event
can be used to pay the later claim as well as its predecessor. More
generally section 5 already proves donor distinctness by event IDs.
These statements remain true across the actual source seam using the
copy IDs. If execution stops with one pending claim, it stays pending;
the proof does not count an unexecuted future unit. QED.

A stronger directly usable guard is: the FIRST forced gain after each
selected arrival has an intrinsic free unit. In that subclass the old
claim is paid by the next KEEP-u visit. On literal repetitions of W
this is a delay of at most one original period. The general theorem
needs only a guarded change before the next selected arrival and does
not assert that stronger delay without its hypothesis.

### What the theorem deletes and what it does not

It proves actual slot reuse, not only a finite discrepancy list: the
old demand ID disappears from the slot ONLY because a named, distinct,
g1-unused original bit paid it. Both signs of the ancestry excursion,
the actual event and the mate-bit possibility are retained.

It is uniform over arbitrary original support and private A geometry
WITH THESE CONDITIONS. Literal rotations and visits give the return;
the guard gives actual availability; one-pair admission gives distinct
service intervals. Reflections use the exact reflected rotation and
the same SET test. No bounded private population is assumed.

It does not prove conditions 2–4 for arbitrary F. In particular, many
residuals in one KEEP-u gap still have only the shared return witnesses
of Step 3.1. Applying this theorem separately to several pairs and
adding their payment maps would be invalid without noncollision.

## 9. Complete-state returns, lifting and absolute-period validity

The source-simple reduction repeats COMPLETE labelled (A,B_full) states
at genuine macro boundaries. It allows proof-child decomposition only
at those actual equalities. Equality of eta, D_e, a root, a shallow
frame or a chart representative is not a complete-state equality.
No interval is removed, trimmed or declared independently funded here.

Even a complete A/B state return does not imply that the extended
claim ledger has returned. Its stored demand IDs can differ, and
admitted or blocked unpaid claims can remain. Source-state finiteness
is therefore not a proof of an unpaid-demand injection into L_X. The
SC35 leaf-funding premise is not silently supplied by this observation.

All definitions above use the full physical trees. Anonymous A
ancestors, arbitrary permitted helpers, hanging subtrees and repeated
private S labels remain in those trees; none is erased to obtain a
more convenient return. The right-rotation identity applies to arbitrary
ordered subtrees, and its left reflection proves the reflected rules.
The restricted reuse proof only uses actual roots, actual rotations
and the stated source guard. Thus it has no hidden finite-population
or fixed-orientation assumption.

For periodic execution use the one original aligned cut and literal
copy IDs. Carry an unpaid demand across the cut if necessary; do not
reset it. A bit in copy i+1 may only be assigned after that event in
copy i+1 actually occurs. Such a payment is a receipt on the EXECUTED
multi-period prefix, never a claim that copy i contained an extra bit.
No static one-period donor map is obtained by forgetting the copy ID.
No bit from a previous symbolic copy is duplicated at the seam.

The legal Step 1 cut and its cyclic lambda remain fixed. All current
g1 owners are copied literally, and no recent-key chart is reset merely
because A returns. No chart normalization, signed-correction cancellation
or full/erased exchange is invoked. The theorem is at the same raw
full-source scope as Steps 1 and 2; it does not manufacture an auxiliary
or frozen-owner compatibility theorem.

## 10. Exact interface to Bounded-Carry Closure

This section checks the requested implication, not its unproved global
premise. Let

    f=|F(W)|,   r1=|R1(W)|.

Step 1 already proves

    r1-f=2A(W)-Q_B(W),
    |domain(g1)|=Q_B(W)-f.

After actually executing k complete copies, the copy-lifted Step 1
comparison uses k(Q_B-f) distinct bits. Its complement contains kr1
actual units. It is harmless that the original whole-period g1 can be
noncausal within a copy: at this completed-copy endpoint all of that
copy's units have actually occurred. This does not license using a
future copy's units earlier in the new ledger.

Suppose a valid ledger for ALL residual arrivals has paid all but U_k
of those kf demands, using distinct units of this actual complement.
Then necessarily

    kf-|U_k|<=kr1,
    kQ_B(W)-|U_k|<=2kA(W).                         (1)

If such a valid ledger has |U_k|<=K_X for every k, with finite K_X
independent of k, divide (1) by k and let k grow to obtain

    Q_B(W)<=2A(W).

Equivalently, if the integer Q_B-2A were positive, choosing k>K_X
would contradict k(Q_B-2A)<=K_X. This proves the exact conditional
counting statement with no source reduction or capacity assumption.

If EVERY residual could always be admitted into the sound slots and
retained there until payment, section 5 would give K_X=n(n-1).
That ALL-ARRIVALS premise is precisely NOT established here. It must
not be smuggled in under the phrase "finite return system."

For the restricted theorem, K_selected=1 bounds only the selected
stream's pending demands. This supplies an actual reuse interface for
that class; it does not meet the all-F premise of (1). For example,
selecting only CCR's (59,2) in each copy leaves the other eight residuals
per copy outside this restricted ledger. If they are not processed,
the full unpaid count is 8k despite the selected slot being empty at
completed-copy boundaries. The old complete CCR certificate proves
that control solvent separately; it is not an implicit input paying
those eight demands in this slot proof.

Consequently Bounded-Carry Closure is verified as an interface but is
NOT APPLIED to deduce Universal Scalar Coarse-Double here. Step 3.2 is
not begun.

## 11. Exact remaining proof obligations

The first general reuse implication not justified by Step 3.1 is:

    actual forced ancestry gain/loss for a pending claim
      => a serviceable, distinct g1-unused bit before required reuse.

The left side is the quantitative return theorem. The right side does
not follow from it: the designated CCR witness bits are occupied.
The guard-and-mate argument proves the implication only on the stated
restricted class. It does not prove every return has that guard.

A complete system would additionally need all of the following, none
of which is asserted by the present definitions:

1. Source-derived admission for residuals outside critical macros and
   for discrepancies with no genuinely visited candidate.
2. A rule for several demands arriving in the same genuine return gap,
   where Step 3.1 supplies one shared return pair rather than one per
   demand. An occupied-slot arrival cannot simply overwrite the old ID.
3. A source theorem controlling competition among different target
   pairs and nested chains for one event's at most two available units.
4. A justified treatment of returns whose relevant physical units are
   all protected by g1, without assuming an unowned alternative or
   moving a frozen owner.
5. If readdressing is used, a source-derived reason that an empty
   admissible destination and subsequent service exist. Finite address
   moves alone pay no claim and cannot be called augmentation.

These are explicit missing source implications, not an equivalent
capacity assumption renamed as a theorem. No all-source Hall claim,
bounded carry or universal injection is proposed without proof.
