## 2. New universal own-credit theorem for one original A access

### 2.1 Persistence of a newly demoted subtree

In one ordinary bottom-up splay of a physical target y, the new subtree
rooted at the demoted pivot of EVERY single rotation excludes y. It
remains an unchanged hanging subtree during the rest of that access.

For LL/RR, the first demotion hangs on the opposite side of the
promoted parent from y; after the second rotation it remains off the
remaining search path. In LR/RL, each demoted pivot hangs off y's
opposite-side child. A terminal zig has no subsequent rotation.
All later rotations involve y and its remaining ancestors, never an
interior node of one of these new subtrees. Ordered private hangers
are retained unchanged.

Consequently any nonempty S-label newly appearing in J_S(A) DURING
this splay has a permanent actual subtree representative until the
end of the splay. A whole-frame label carried to its promoted root
was already present and is not a newly appearing label.

### 2.2 Positive losses inject into INITIAL common B labels

Let J_B be the actual fixed B label set during access t. Every positive
A rotation removes one label K of J_B from J_S(A). This K must have
been common at the START of that A access, and different positive
rotations remove different such initial common labels.

PROOF. If K were first acquired during this access, section 2.1 would
give it a permanent representative, so it could not subsequently
disappear. If it had already disappeared once, its reappearance would
likewise become permanent. Thus each actual positive loss has a
different K present initially. The whole label S never disappears.
This argument handles every private target and every unary duplicate;
it uses actual label disappearance rather than deleting a multiset
copy that still has another representative. QED.

Write Psi_t^- for the value before the access. Since B has c distinct
nonempty labels, including the whole common S, this proves

    P_t <= c-1-Psi_t^-.                             (C1)

Define U_t to be the actual own units of t that are not positive real
rotation bits: all negative/zero real bits and its virtual zig unit,
if present. Then

    U_t subset R1(W),
    |U_t|=2a_t-P_t
         >= max(0,2a_t-(c-1-Psi_t^-)).               (C2)

Unlike the inherited B-fixed block identity, this bound locates its
entire certified pool INSIDE THE ACCESS ITSELF. It does not count
an A-negative slot's possibly nonlocal positive head. That head
remains an additional, separate unit of the inherited inventory.

This is uniform over arbitrary original support, source length,
private A ancestors, private helper targets and physical populations.
For c=0 the original B demand inventory is empty; the nontrivial

## 3. Root-order certificates: an actual unused bit without a deep future target

### 3.1 Rootward rotation lemma

During an A splay let g be the fixed actual B root. Suppose a single
rotation changes the GLOBAL A root from u to v and

    (g-u)(v-u)>0.                                  (C6)

Then that rotation is nonpositive. Its own actual real bit lies in R1.
The target, u and v may be private. Overshooting g is permitted.

PROOF. For a left rotation, v>u and C6 says g>u. The old child-v
subtree contains all S keys greater than u, because u was the global
A root. Its label K therefore contains g. If K is proper, it cannot
be a B-subtree label: every B subtree containing B's root has label S.
If K=S, its label has the continuing whole-A-root representative
and cannot disappear. Thus the old child label cannot suffer a
common-B-label loss. The inherited pure-birth/pure-death sign rule
makes the rotation nonpositive. Right rotation is the order reflection.
The own bit is outside im(g1), since g1 uses positive real bits only.
QED.

This is a criterion on an actual source rotation, not a new donor
eligibility graph. In particular it does not assert an unproved
future-depth increase or an additional event after an exact return.

If an access starts at u!=g and its target y satisfies
(g-u)(y-u)>0, its FIRST global-root change satisfies C6. In a zig-zig
the two last root changes move in the target's direction; in a
zig-zag only the final rotation changes the global root. The first
such rotation therefore has its actual unused own bit. No claim is
made when u=g or the target goes away from g.

### 3.2 Aggregation and limitation

Rootward-certified rotations at different actual fine steps have
different physical IDs. Their own bits aggregate by set union even
when returns, B components or recovery descriptions overlap. They
are a SUBSET of the U_t units already counted in C2--C5. Adding
their cardinality again to C5 would double-count credits.

For example, in a fixed-B block, every positive global-root rotation
moves farther from g on the same side. A succession consisting only

many neutral B demands can be associated with one actual rootward
rotation or with a succession of changing B roots. A one-bit event
