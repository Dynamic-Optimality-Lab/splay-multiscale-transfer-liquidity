## 1. U1 — every B decrease has a DISTINCT actual A preparation

For a proper B label C created by a decreasing B rotation delta,
let kappa be the previous B rotation removing that SAME label C
in cyclic order. Such a removal exists by B closure. At kappa,
A is rooted at its target z in C, so the proper C is A-absent.
At delta, C is A-present, by the exact B-decrease definition.

B has no C from just after kappa until delta. Consequently there
is an A SET creation of C in this interval. Let sigma(delta)
be the LAST such creation before delta. It is a real original
A rotation, not a virtual unit or a synthetic inverse operation.
It introduces C while C is not in B, so its sign is zero or
positive, never negative.

Then

    delta -> sigma(delta) is globally injective.       (U1)

PROOF. A rotation introduces at most one new S-label. For a fixed
C, the B-absence intervals ending at successive creations of C
are disjoint, each with one last A creation. Thus neither different
C nor different B runs can select the same sigma. QED.

The proof is uniform over arbitrary source length/support, helpers,
private A populations and cyclic seams. It does not identify sigma
with lambda(delta). Lambda is the original scalar-crossing map;
sigma is a literal label-creation witness. Equating them would be
an unproved ownership change.

### 3.1 A right creator is quiet and zero

a separation impossible. If ceil_S(u)>c, J contains pred_S(c)
and c but excludes ceil_S(u), whereas W contains c and ceil_S(u)
but excludes pred_S(c). These are crossing B labels. If c is
the minimum of S, no J has min J<=v<c at all.

Thus no current B flag is added. A positive rotation would make
a common B label missing and would have to add a canonical flag

## 8. Go beyond the first B double: a proved successor extension

F1 was not used to exclude the known deeper controls permanently.
It has the following rigorous extension F1'.

    y = succ_S(p).

the minimum S key of p's right subtree. The earlier ordinary
splay rotations bring it to that child's position before the

proper path labels between that original child and y have

missing literal classification, not a contracted splay.

For U2's left-creator proof, the additional possible labels

only I's nonempty right/left side and W_sigma, so are unchanged.

For the same-orientation mixed proof, if i has an initial
direct child y_i, use U4. If instead y_i=succ_S(p_i), then:

- Marked u_j=p_j gives y_i=p_j and p_i<p_j. The current I_j
  is contained in I_i, since I_i contains its root p_j. The
  first B hit of I_i is p_j and is inside I_j. No earlier

  succ_S(p_i)<=p_j<y_i, contradicting y_i=succ_S(p_i).

These arguments also handle mixtures of the direct-child and
successor cases. Reflection handles predecessor consumers.

I_j is inside I_i and their prescribed first hits conflict;

Thus U4/U5 and the one-exception quantitative theorem remain

This extension keeps every B operation, including all internal
