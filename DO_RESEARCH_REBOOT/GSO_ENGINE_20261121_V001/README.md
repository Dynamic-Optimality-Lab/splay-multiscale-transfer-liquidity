This implements the first end-to-end slice of the combined proposal. It retains the complete original paired BST states, operation words and costs. Universal Coarse Double remains OPEN. The new mathematical result excludes both declared depth-frontier3 potential grammars for every fixed signed coefficient vector and every finite constant; it does not refute the original aggregate cost bound.

The main mathematical manuscript and all-parameter source proof belong in Notion; the local `UNIVERSAL_SOURCE_PROOF_REFERENCE.json` binds the saved page and relevant code hashes. `run_001` is the primary run. `cold_run_002` is a successful fresh-output reproduction.

## Working commands

From the repository root, before sealing:

```powershell
python -B DO_RESEARCH_REBOOT/GSO_ENGINE_20261121_V001/gso.py research --output run_001
python -B DO_RESEARCH_REBOOT/GSO_ENGINE_20261121_V001/tests.py
```

The `research` command executes or explicitly reuses ten pipeline stages: full graph/teacher, CEGIS, holdouts, symbolic loop and frontier identities, parametric constraints/dual, complete source counterexamples, legacy flow adapter, installed Lean kernel check, independent verification, and typed research registry. Cached stages are identified in `PIPELINE_RUN.json`. On a fresh output name every computational stage runs.

## Modules and trust boundaries

- `kernel.py`: full original source semantics and selected literal rotation records; imports only pinned prior pure helpers.
- `teacher.py`: complete reachable graphs from every common diagonal, exact free-state trial certificates, rational optimum recovery, tight attaining cycles, recurrent-SCC period witnesses.
- `learner.py`: bounded CEGIS in two frozen nonlinear physical feature grammars. Float LP discovers a basis; exact rational inequalities determine finite acceptance.
- `adversary.py`: complete old and parameterized sources, explicitly selected feature rows and holdouts. A finite fit is never universal proof.
- `symbolic.py`: actual rigid-subtree feature identities plus learned affine loop-counter conservation and Z3 induction checks. An opaque subtree query is rejected as an open obligation.
- `parametric.py`: seven complete-source templates; affine constraint extraction; exact dual arithmetic; minimum recorded-template obstruction core. Its universal provenance is the explicit source/spine argument in Notion, not finite interpolation.
- `CertificateKernel.lean`: kernel-checked rotation inorder identities and the conditional telescope/boundary theorem. It does not formalize the whole original BST model or prove the missing universal cost inequality.
- `flow_adapter.py`: working exact original-U flow/min-cut integration with the prior independent cyclic-Pi/LCA checker. This adds no universal theta_1 packing theorem.
- `registry.py`: exact scope/status registry and root gate; finite/conditional evidence cannot close the root. New source-proof records are separate and code-hash bound.
- `verify.py`: independent immutable tree reconstruction, insertion-permutation enumeration, marked-frontier ancestor unions, independent SCC implementation, every graph edge, original source closure, selected bit records, and exact dual/core checks. Imports no current producer/model/teacher.

The new full-X features do not replace the original carrier S or U/Pi definitions. Some obstruction sources have private physical vertices and a small original carrier; these are retained and reported, never projected away. A bad potential row rejects the proposed per-operation certificate, not the corresponding original aggregate cost constant.

## Results and limitations

Complete graphs through six physical keys have exact optima `0, 0, 1, 1, 3/2, 3/2`. Each has an all-edge integer potential upper certificate and, when positive, a genuine original attaining cycle. There are 228428 total edges; fourteen transient edges do not belong to any period and are excluded from closed-period candidate failures. These are finite results only.

The learned finite C=13 candidate is falsified by complete scaling sources. Symbolic source constraints and an exact nonnegative dual exclude both frozen frontier3 grammars for every finite C. Five of the seven recorded template equalities suffice for that contradiction; minimality is only within that recorded constraint set.

The general evolutionary research scheduler, e-graph engine, complete unbounded-tree invariant synthesizer and full Lean source formalization are not implemented. The real working prototype is the bounded teacher/learner/adversary/symbolic-certificate/registry slice. The chosen whole-operation potential family is a sufficient proof architecture, not a necessary condition for the original theorem.

All prior4583 pinned/sealed files and59 selected inputs are byte-checked. All old source files, tests, configuration, Git state and seals remain untouched. See the explicit implementation corrections, budget amendment and verification scopes; source counts are not a universal coverage argument.
