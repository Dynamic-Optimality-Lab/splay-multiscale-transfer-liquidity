# One-event retirement has a source preimage; two-event retirement need not

Mathematical derivation complete for the H1 theorem and the displayed H2
counterfamily. Independent status is in the separate audit receipt. This
is a source-comparison boundary, not universal donor funding.

## IAGS Box

Target: eliminate an anonymous branch by an ordinary comparison when it
retires, without assuming its old contraction commutes with every splay.
Conditions: a marked-root source, designated ordered anchors V, exactly one
anonymous brancher p in the anchor core, and arbitrary inactive anonymous
unary chains and mark-free payloads. The actual operation accesses an
anchor x. In the target all anonymous core vertices are unary. Projection
therefore has a unique anchor endpoint. B processes the same target and
retains its actual source state/cost; p is not a B access.
Inheritance: ordinary bottom-up source rotations, contraction-set definition,
the accepted old fixed-core signed coefficient at its actual domain, and
the marked-core active-frame source reduction.
Ambiguities: this does not specify a dynamically consistent choice at a
nonunary source, repeated/shared physical donors, or global chart ownership.
Bridge: establish an ordinary old source tree with the SAME projected target
and no larger A-event count; use its proved ordinary signed inequality.

## H1 retirement theorem, uniform in support and private population

If the actual anchor access has H=1 and retires p, there is an old source
a in Pi_V(A_source) such that

    S_x(a)=unique_projection(A_target),  H_old=1.

Proof. A brancher not on the actual access path is in an unchanged hanger
and cannot retire. The source root g and target x are anchors, so the
only possible path containing p has length two, with p its middle node.
There is no extra anonymous active path vertex. All off-path projections
are unique, because p is the only anonymous brancher. Denote them by
A,C,D and use E for an empty ANCHOR projection, which may have a physical
mark-free population. There are four ordered orientations; two plus their
literal reflections suffice.

LL: the projected source has form g(p(x(A,E),C),D), x<p<g.
The actual double yields x(A,p(E,g(C,D))). Its unique projection is
x(A,g(C,D)). The permitted contraction choosing x as p's replacement gives
old source g(x(A,C),D). Its ordinary x zig gives that exact target at cost1.
Retirement forces the displayed inner E: otherwise p keeps anchors on
both sides after the access. C is nonempty before the access since p was
a brancher; its precise shape and population are unrestricted.

LR: the source is g(p(A,x(E,C)),D), p<x<g. The actual zig-zag gives
x(p(A,E),g(C,D)), whose unique projection is again x(A,g(C,D)). The
permitted old source g(x(A,C),D) gives the same target by one zig.
Here the source A is nonempty, and retirement forces the displayed E.

Reflection gives RR and RL, with exactly the same event count and all
ordered subtree slots preserved. These source cases are exhaustive by
the path argument. Inactive private unary chains are suppressed only
inside untouched hangers; their projection commutes with these actual
frames. Mark-free hanging BSTs contribute E without deleting any original
operation, key or bit. Thus the theorem is uniform, not a finite test.

At an ordinary signed coefficient D with source-root-compatible minimum
l_b, let d_t be the fixed unique target debt. The old source theorem gives

    2-Q+d_t-D(a,b)>=0, hence 2-Q+d_t-l_b>=0.

Thus no H1 single-branch-retirement edge can by itself contradict the
lower-envelope floor l_b. This is not a signed law for an arbitrary J:
J(A_source,b) may exceed l_b, and its own upper compatibility still needs
proof. No selected ordinary source is silently propagated to later edges.

## Exact failure of the same preimage mechanism at H2

Take ordered keys x<p<v<c<g and arbitrary old anchor BST terms A,W,R in
their permitted gaps, with arbitrary rigid mark-free payloads. Define

    T=g(c(p(x(A,E),v(E,W)),E),R).

Ordinary access x has depth3 and cost2. The LL double on c,p,x followed
by a zig at g yields

    x(A,g(p(E,c(v(E,W),E)),R)).

p is now unary. The unique old projected endpoint is

    Tstar=x(A,g(c(v(E,W),E),R)).

There are exactly TWO old source contractions, because x.right and v.left
have empty anchor projection:

    T_left =g(c(x(A,v(E,W)),E),R),
    T_right=g(c(v(x(A,E),W),E),R).

Their ordinary x results are respectively

    x(A,c(v(E,W),g(E,R)))          [cost1],
    x(A,g(v(E,c(W,E)),R))          [cost2].

Neither equals Tstar. In the first the right root is c rather than g;
in the second g.left has root v rather than c. The named keys are
distinct, so this argument is uniform over every permitted A,W,R.
The failure is ENDPOINT geometry, not insufficient comparison cost.

## Changed proof obligation

H1 single-branch retirements have a complete uniform preimage proof.
Extending that preimage rule to all H2 LOW departures is refuted. A new
H2 comparison may need an old shadow OUTSIDE the source contraction set,
or a separately justified potential correction/source repayment. The
earlier outside-frame comparison already permits such an outside shadow;
its physical owner/eligibility and arbitrary repeated/shared extension
remain open. Neither this counterfamily nor the three B-guided selector
failures refutes unrestricted full-geometry debt or the original CD goal.
