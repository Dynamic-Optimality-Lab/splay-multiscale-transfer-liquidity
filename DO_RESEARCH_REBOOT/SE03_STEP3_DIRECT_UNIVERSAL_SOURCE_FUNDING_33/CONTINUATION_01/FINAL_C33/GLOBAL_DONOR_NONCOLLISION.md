# One simultaneous injection, including shared paths

Conditions: ONE actual period, ONE jointly source-licensed repair, all
original eligibility/retirement data, and the frozen input of the parent.
No union of separately legal but incompatible repairs is used.

Independent comparison: h0 has disjoint natural inventories. A seed map
b:R->S injective on literal `(t,j,b)` IDs has image disjoint from im h0.
Therefore h0 union b is injective globally, even when source descriptions
share helpers, ancestors, source intervals, charts, or recovery words.
Only the actual IDs decide equality.

Owner extension: unique incoming comparison and owner edges force every
unpaid-root path to be disjoint. Its terminal is outside im a0. Distinct
roots have distinct terminals; neither overwrites an old owner. For the
weaker quotient route, a matching in J yields disjoint augmenting paths,
which expand to disjoint actual components. Endpoint-neighbor Hall alone
does not guarantee this; the shared-relay countermodel in the minimal
obstruction document shows the missing constraint explicitly.

Both endpoints undergo the SAME occurrence bijection into I. A source
occurrence described across a symbolic seam is represented exactly once.
No event from the prior or next copy is borrowed. Reflection relabels the
same maps and does not manufacture a second donor. All chart/full-erased
corrections remain attached to their actual source receipt.

This is a uniform noncollision theorem GIVEN a compatible source plan.
The existence of that plan for every hard source remains OPEN.
