## Definition and inactive-unary invariance

Let Pi_K(T) be the SET of distinct ordered BSTs on K obtained by recursively
contracting non-K vertices. A mark-free term contributes the empty gap.
A K-root v contributes v(L,R) for every pair of child projections. At a
non-K root, combine the two projected child trees by ALL order-preserving
BST joins. For disjoint consecutive key ranges, Join(L,R) is defined by
choosing root(L), then Join(L.right,R), OR root(R), then Join(L,R.left),
recursively, deduplicating identical anchor trees.

Join(empty,R)={R} and Join(L,empty)={L}. Therefore suppressing ANY unmarked
unary marked-core vertex leaves Pi_K(T) EXACTLY unchanged, not merely its
cardinality. The suppressed mark-free side can contain an arbitrary private
BST. Repeating suppression does not depend on private population size.
This is a definition of a proof representation; no original key is deleted.

For any fixed old coefficient D_K, define the contraction spectrum to be
the multiset [D_K(a,b):a in Pi_K(T)], with each DISTINCT projected anchor
tree counted once. Equality of Pi sets proves equality of the whole
spectrum, including repeated debt values. Its value SET is invariant too.
Thus a function F(b,spectrum) or F(b,value-set) explicitly ignores inactive
private unary inventories; a function with additional inventory dependence
requires its own separate proof and is not covered by this assertion.
