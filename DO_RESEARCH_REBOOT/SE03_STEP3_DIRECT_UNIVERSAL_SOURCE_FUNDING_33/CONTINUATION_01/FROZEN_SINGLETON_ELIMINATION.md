# Exact elimination of prescribed source states

This is an algebraic compression theorem, not a new funding certificate.
Let every source inequality be w+J(t)-J(s)>=0. Some states have prescribed
values d (here, singleton anchor contractions retaining the old D10 value).
For all remaining states keep mutable labels, initially nonnegative.

There are exactly four cases. A fixed-to-fixed inequality is a literal
check; in this source domain its complete uniform proof is the local
unary-endpoint packet lemma of UNARY_BOUNDARY_SOURCE_CREDIT_THEOREM.
Fixed-to-mutable gives the seed lower bound J(t)>=d(s)-w. Mutable-to-fixed
gives the upper bound J(s)<=w+d(t). Mutable-to-mutable keeps the original
edge inequality. These substitutions are logical equivalences. No source
state, physical event or demand is deleted from the mathematical problem.

In a monotonically increasing lower-label construction, a satisfied fixed
seed never needs reprocessing. A mutable upper bound retains its exact
source edge, so every future violation has an explicit source derivation.
All parent-update identities are retained; changing their state IDs is an
injective renaming. Every countercertificate can still be reconstructed in
the original actual A/B source states. Full contraction-set features may
identify distinct physical A states; that remains a hypothesis of the tested
formula class, never a claim of an actual concatenated source path.
