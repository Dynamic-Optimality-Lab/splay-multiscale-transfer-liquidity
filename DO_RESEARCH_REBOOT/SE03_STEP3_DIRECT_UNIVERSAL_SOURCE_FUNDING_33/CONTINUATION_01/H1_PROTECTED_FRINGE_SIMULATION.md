# Arbitrary-support protected-fringe H1 simulation

MATHEMATICAL THEOREM. This is an arbitrary-length source simulation, not a
finite-population extrapolation. Its distinct algebra audit is recorded in
protected_fringe_H1_independent_audit.json. No unconditional Gate U follows.

## Frozen Box

Let V be ANY finite ordered anchor set, |V|>=2. Start an actual A interval
with root in V and every anonymous ancestor of V unary in the V-core.
All accesses in the interval target V. Every positive ordinary bottom-up
A access has exactly one StepEv; arbitrary zero repeats and KEEP/DELETE
kinds remain present. Unaccessed anonymous populations, depths and ordered
subtrees are arbitrary finite. No final unary condition is imposed.

Target: execute the EXACT same ordered access word on the ordinary anchor
tree initially obtained by pruning mark-free terms and contracting unary
anonymous ancestors, preserving the actual A-event count at EACH occurrence.
Inheritance: ordinary two zigs/four doubles and ordered BST source semantics.
Ambiguity: positive accesses to anonymous keys and H2 accesses are excluded;
they are the next explicit activation gap, not silently removed operations.
Bridge: source-generated protected-fringe tags and the induction below.

## Spine lemma

A single BST rotation changes membership in the whole-tree right spine
only for its two participating nodes; the same is true for the left spine.
Indeed a right rotation of h(z(A,M),R) to z(A,h(M,R)), at a right-spine
position, adds z to the right spine and removes no other node. At a position
off that spine, its existing left-turn ancestor persists, so neither local
subtree enters the spine. The inverse left rotation removes only h. Mirror
these statements for the left spine. Arbitrary subtrees and nodes INSIDE
them keep their spine membership. This proof is independent of population.

## Protected anonymous branches

An anonymous branch p has tag L if its ACTUAL left child is an anchor j,
j is the adjacent V predecessor of p, j.right is V-free, and p is NOT on
the whole-tree right spine. Tag R is the exact mirror: right child j is
the adjacent V successor, j.left is V-free, and p is not on the left spine.
Tags are assigned when a branch is born and removed when it becomes unary.
They are source witnesses, not an assumed function of the debt multiset.

Contract unary anonymous nodes as usual. At an L-tagged branch replace
p(j(A,E),B) by j(phi(A),phi(B)); at an R-tagged branch replace
p(A,j(E,B)) by j(phi(A),phi(B)). E means a V-free physical subtree. At
anchors preserve both projected children. This phi is an ordered anchor
contraction and preserves every anchor once. Tags make its choice explicit.

Initially there are no anonymous branches, so all conditions hold. For a
positive H1 access x, the actual path has one or two edges and its root
and target are anchors. There is at most ONE anonymous path operand p.
If there is none, ordinary source substitution commutes with phi. All
existing anonymous branches lie inside unchanged hanging terms; their
fringes remain unchanged and their non-spine guards persist by the spine
lemma, since no such branch participates in a rotation.

If p is unary, the two zig-zag frames leave it unary. A right-right frame
g,p,x can create an L-tagged branch with left fringe g and new marked root
x>p supplying the non-right-spine guard. The V-free old p.left forces g
to be the adjacent predecessor of p: any intervening V key would have to
belong to that empty V interval. The left-left frame creates the mirrored
R tag. If the new other side is V-free, the node is simply unary instead.

If p is already L-tagged and occurs on this length-two path, it is a child
of the current marked root g. Since p is not on the right spine, g>p;
hence p is g.left. Accessing its fringe j makes p unary. Accessing its
right marked child x preserves the same L fringe (unless that branch
becomes unary), and the new marked root x>p again guards it. No deeper
marked child is accessible in H1. The R-tagged cases are mirrored.

These are all eight private-path frames: four unary-parent orientations,
L retirement/survival, and R retirement/survival. Literal substitution in
each gives phi(S_x A)=S_x(phi(A)); the old access is exactly H1. Full free-
term identities are stored in protected_fringe_H1_local_forms.json. If an
anonymous branch does not participate in the event, the spine lemma and
its rigid local fringe preserve its tag, including under nested branches.
Thus the invariant holds SIMULTANEOUSLY for every anonymous branch.

Induction proves phi(A_t) is the exact ordinary anchor execution of the
original word, with identical 0/1 event costs at EVERY occurrence. There
is no bound on word length, repeated accesses, number of branches, or
private populations. Reflection is already included in the eight cases.
If the final actual core is unary, phi there is the unique contraction:
this proves arbitrary-length H1 unary-return erasure, extending the
separately checked two-genuine-packet theorem.

## Exact source/funding interface

Each original positive event keeps its literal (t,1,b) bits. All zero
operations and their original KEEP/DELETE kinds remain. A positive terminal
DELETE followed by a zero-event KEEP is preserved with those same kinds.
The simulation creates no physical credits. It changes no B operation.
Where full/erased B have their certified anchor backbones and rigid private
gaps, their original states, demands and charts are therefore unchanged.

An applicable POINTWISE ordinary-anchor source-credit license can be
transported through this comparison: actual H, Q, selected event ordinals
and natural h0 owners are identical. Its debt/working-bank bound retains
its original hypotheses; it is NOT a new universal bound. For an actual
closed interval with unary start/end, the anchor A comparison closes.
Any required erased recurrence, legal cut, period correspondence, common
owner retirement and frozen fE exchange still use their original licenses.
No unproved smaller-support receipt is invented for the comparison.

This proves a uniform geometric/source bridge for arbitrary support.
