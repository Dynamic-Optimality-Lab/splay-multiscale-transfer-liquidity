# Scope of the exact model and reservation statements

The feasibility model is exact for the UNCHANGED C14 certificate/exchange
route. It is not a completeness claim for every conceivable replacement
invariant. A static pair-eligibility reduction of the entire licensed
problem is not proved; the counting relaxation is explicitly weaker.

Natural-reservation safety is a conditional universal path fact: IF a
valid complete h extending h0 ends at an h0 unit, its natural claim is
either the root or already frozen-funded. No new concrete source exhibiting
that release pattern is claimed. The checked core9 terminals are both
outside im(h0). A permanent exclusion of all h0 units cannot be assumed an
equivalent model without a separate source theorem justifying that stronger
restriction on the original exchange interface.

The core9 two-root analysis uses an ARCHIVED30-owner stage to check the
model against an accepted proof. Its CURRENT map has32 owners and no unpaid
root. The H2 control now has a certified full18-owner map; W199 already has
58. None is a current unfunded source.

A positive control, inventory identity or matching algorithm does not
prove universal source expansion. A partial-library failure or a geometric
counterexample does not prove all-route infeasibility. Outcome E requires
a legal original source, legitimate current owner input and a proof that
every original licensed Bank25 completion fails. None is exhibited here.

Natural h0 is the unchanged independent own comparison. The final effective
g preserves common and earlier successful ACTUAL values through the original
exchange; it need not also equal every raw h0 pair when common normalization
overrides that pair. Simultaneously freezing conflicting raw/common values
would be a new inconsistent model. Historical raw h0 receipts are not edited.

Likewise releasing a bit from the independent comparison's working buffer
does NOT erase an old actual a0 owner. Only final a0-free terminal bits are
new actual payments. The two ledgers and their source-ID correspondence
must remain explicit.
