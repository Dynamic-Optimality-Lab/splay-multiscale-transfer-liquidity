## Exact data

Fix ANY finite original paired-closed source at any r>=7, with arbitrary
private trees, anonymous A ancestors, real changing charts, and a legitimate
frozen a0 on ONE original aligned period I. Use the original natural h0.

A source block B is a consecutive union of COMPLETE natural macros, with
literal operations retained. Its A bits U_B and full demands D_B have
sizes 2H_B and Q_B. No other period copy contributes an event.

The block is chosen by a specified source rule, with a proof from original
rotations/marked-core history that

    2 H_B >= Q_B.                                            (SB1)

An assumed whole-period CD inequality is NOT an admissible proof of SB1.
Choosing the entire period and testing the desired conclusion would be
circular as a proposed universal source license.

Let h be an independently certified injective partial comparison extending
h0, and assume block closure: every edge incident to U_B or D_B has BOTH
endpoints in that block. All mandatory extra Gamma reservations in B are
either among its retained comparison assignments or separately licensed
for release. Physical frozen a0 is NOT h; its nonlocal occupied bits are
handled later by the original full comparison exchange, not called free.

## Augmentation theorem

Keep h_B=h|D_B unchanged. List missing demands D_B\dom h_B and unused
comparison bits U_B\im h_B in their actual source ordinal order. Pair the
kth missing demand to the kth unused bit. These literal bits exist because

    |U_B\im h_B| - |D_B\dom h_B| = 2H_B-Q_B >= 0.

The inequality is a consequence of the independently proved LOCAL source
condition SB1, not an assumed global total. All original h0 values and all
accepted h_B values remain fixed. Block closure makes the new assignments
disjoint from every h edge outside B. Thus this extends the independent
comparison and fills ALL of the block's previously missing demands.
If at least one was missing, independent coverage strictly increases.

This is a source-defined ordinal construction: source block rule, proved
local capacity, exact unused ordinal range, and literal actual pair IDs.
It does not create an unowned terminal by calling a comparison spare free.

## Trace with physical peak2

Before admitting B, the source rule and its accepted static block license
fix every pair of the completed h_B. For each ORIGINAL A StepEv in B:

1. Admit its two distinct actual bits (t,j,0),(t,j,1), once.
2. If a bit is selected by the completed h_B, emit that predetermined
   assigned pair under the source block license. Release an unselected bit.
3. Proceed only after both bits have been resolved.

Unassigned bank states are exactly 0 -> 2 -> 0. Every assigned demand is
emitted once because h_B is injective. No released bit is reread later.
Precomputed pair IDs are assigned proof output; no unassigned bit is hidden
there. All source operations still occur in their original physical order.
This is the accepted STATIC block convention, not chronological endpoint
storage and not a new permission to pay across an unlicensed block.

For original type B take c_B=H_B and D constant0 on these block boundaries.
Then every event pair is selected, every natural unit is included, and
`2c_B-Q_B+Delta D = 2H_B-Q_B >= 0`. The coarse sufficient bound
`K+2 max c<=25` is not invoked: the explicit trace proves working2 even
when H_B grows with support. This is why large c alone is not a bank
counterexample under the actual source-output convention.

For an arbitrary old trace this construction is not inserted while ignoring
its carried tokens. A splice is licensed when the old independent bank is
empty at BOTH B boundaries, all old edges incident to B are block-closed,
and the source block rule permits these output times. The old outside
trace is then unchanged, so the new peak is max(old outside peak,2).
Without those hypotheses use the earlier explicit headroom theorem; no
claim of a universally available reset is made.

and the static block license, complete each block by the same rule, starting
with its original natural h0. Disjoint U_B and D_B prove one simultaneous
full comparison. The actual bank closes empty at EVERY block boundary and

arbitrary finite repeated/shared descriptions: the actual block partition
assigns each operation, event and demand to one block only.

The original full h/a0 exchange then appends distinct genuinely a0-free
terminal bits, leaving every a0 value literal. Its output paths are proof
data, not a second unused bank. Original common/N retirement, source/chart
eligibility and both-endpoint transport remain required. The auxiliary
Step1 cut is not changed; an internal full block cut transports onto I by
the original bijection. A wrapping block has one representative of every
event in I, never two copies.
