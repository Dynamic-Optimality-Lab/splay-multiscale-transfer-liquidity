# Source-exact unary padding and hypothetical deficit translation

Let an original local packet P lie on a GIVEN closed full-B marked cycle.
Suppose an A hanging term T is never entered by ANY actual search in P.
It may contain marked keys accessed elsewhere in the period. Insert an
ordered unary context of ell new unmarked keys above T, respecting T's
search interval. Put these same new keys into the corresponding mark-free
B gap terms, so no marked B path enters them. Every physical key is present
in every tree; this is source construction, never physical DELETE.

The ordinary source identities carry the substituted A term intact. All
actual operations in P, its actual A paths/events and full-B doubles remain
unchanged. For each marked y inside T, at BOTH endpoints its A depth grows
by ell and its hypothetical B depth is unchanged. Other marked depths stay
unchanged. Consequently, for ell=2m,

    delta'_y=delta_y-2m,

and for ell=2m+1,

    delta'_y=delta_y-2m-2*I[old depth_A(y) is even].

These identities follow directly by splitting old depth into2z and2z+1 in
the ORIGINAL ceil(depth/2) event formula. The odd case is not silently
replaced by an even translation. In particular its endpoint difference has
the additional exact correction

    2*(I[source depth is even]-I[target depth is even]).

All actual H,Q of P remain fixed: the extra nodes are off its paths. The
enlarged B word is still closed because the new gap terms are rigid. The
uniform A-realization corollary then embeds the enlarged A shadow and this
unchanged P in an actual common-diagonal, paired/erased/chart-closed source,
with all additional preparation/reset operations OUTSIDE P and fully charged.
This proves source admissibility for arbitrary finite padding, assuming the
stated ordered context and B gap placement. Reflection commutes with the
construction. No finite private population is a substitute for this proof.

For a capped-deficit candidate, if every marked coordinate in T is already
<=-k at both endpoints, ANY further unary padding preserves both capped
inputs, because each displayed correction is nonpositive. Thus its local
candidate margin is unchanged. If a coordinate is not saturated, its exact
even/odd correction must be used; signed preservation is NOT automatic.

This theorem gives no physical donor from a hypothetical delta and no
universal preparation cost lower bound. It constructs valid source families
and supplies exact profile-transformation rules. The original source word
under positive study cannot be assumed to contain our chosen preparation.
It does not prove C33, unrestricted Coarse-Double or a new debt formula.
