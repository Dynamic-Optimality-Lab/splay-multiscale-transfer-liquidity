# Global injection — PARTIAL construction, no full Step2 certificate

For an arbitrary six-key source W with an actual certified auxiliary map
on the aligned interval, the following construction IS proved:

1. Identify every actual A-bit and every full/aux double demand, including
   root repeats and signed negative interference.
2. Form the fixed common owner injection l from actual fE.
3. Build h0 from the first min(Q,2H) demands and own physical bits of each
   actual full packet. Transport BOTH endpoint IDs to the fixed interval.
4. Run physical_exchange.py. Keep every l value fixed, add disjoint free
   endpoints, and record ALL blocked roots and common owners explicitly.
5. Assign each remaining unpaid root a distinct actual excess-demand-slot
   anchor in R. Let Wstar be the actual units left unused.

No claim that step6 is possible has been proved:

6. Construct source-derived DISTINCT Wstar donors for all remaining roots.

The existing partial map is total on common demands and successful roots,
injective, period-valid and universal in source length/private population.
It is complete for full-core6 and for the explicitly repaired word families.
It is NOT complete for arbitrary core7..11 histories.

For a complete map f, original definitions give |D|=QF and |U|=2A, so
injectivity would imply QF<=2A. We do not reverse this implication or
assume its conclusion to choose donors. Stating |Pstar|<=|Wstar| would
repackage the missing inequality and is not a source repayment proof.

No FULL_PROOF.md of CD6 is published. Completion gates J3,J5,J7,J8,J9,
J11,J13,J14 cannot all be passed from this partial construction. In
particular, same-agent independent checking of the COMPONENTS is not an
independent certificate for a universal map that has not been constructed.
